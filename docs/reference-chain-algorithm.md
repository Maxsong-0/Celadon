# 参考链算法：Gullfoss Master、Invisible Limiter G2、The God Particle

2026-09-28。对象是本仓库的 Balance、Color Glue 和 Limit。三款插件的合体是产品方向，不是把它们的专有模型搬进来。下面只根据厂商手册和公开说明，写清各自在做什么，以及这次在 Celadon 里用自己的式子补上的缺口。

## 公开能力

### Gullfoss Master（Soundtheory）

手册把处理定义成实时的听觉解掩蔽，而不是把频谱拉向一条预设轮廓：

- Recover 抬起被别的成分盖住的部分，Tame 压下过于主导、正在掩蔽别人的部分。两个旋钮都会在不同频段有升有降，用来保住原来的动态和感知响度。
- Bias 决定哪些频段交给 Recover、哪些交给 Tame。Brighten 在解掩蔽的多种可行平衡里偏向更亮或更暗。Boost 按等响曲线改低中高的听感比例，同时仍补偿感知响度。
- 感知模型大约每秒更新 1000 次，均衡大约每秒更新 300 次。标准版和 Master 的决策窗大约 20 ms。Master 把听觉模型调得更细，尤其是很小的均衡量，内部精度更高、底噪更低，没有单独的质量档。
- 频段范围可以裁掉没有有用信息的两端。侧链只驱动分析，主输入被均衡。

Celadon 的 27 段仍然是「相对本曲抹平轮廓的偏差」，不是 Soundtheory 的听觉模型，也没有 20 ms 的决策延迟。

### Invisible Limiter G2（A.O.M.）

G2 继承前作的砖墙算法，并把控制交给用户：

- 过采样用来看见采样点之间的峰。官方写明它是为声音服务的真峰值处理，不保证符合某一套真峰值测量标准。把侧链高通、手动 Attack、非 100% 湿声或 M/S 打开后，会进入允许输出越过 Ceiling 的压缩器状态。
- 释放和攻击的形状可以弯（Sigmoid / Bend），用来换掉笔直的增益斜坡。自动时间是默认；手动时间是专家选项。
- 侧链高通把低音从包络检测里拿开，减轻低音泵浦，或做成简单的嘶声抑制。通道联动可调。

Celadon 已经有前瞻、8 倍真峰值检测、0.35 dB 重建余量、快慢双包络，以及持续低频上的周期释放。它承诺的是采样点硬钳位加经验真峰值余量，所以不能照搬「侧链高通之后允许破顶」。

### The God Particle（Cradle）

公开说明把它写成 Jaycen Joshua 的母带总线：三段均衡和增益目标、Amount 缩放的音色链、低中高三段动态、谐波激励，以及一个保住瞬态和动态的自适应限幅。侧链只进音色段里的动态，不进限幅器。默认是一套固定开箱设置，混音往这个目标里送。

Celadon 的对应物是 Color 的 Glue 与 Heat，加上后面的限幅。Glue 原来是 100 Hz 高通侧链之后的一整段同一个增益：人声一响，低音跟着躲。

## 这次改的算法

### Balance：上行掩蔽转移

只在 Recover 和 Tame 同时大于 0 时启用。已经被 Tame 压下去的主导段，按上行扩展把一部分削减让给更高、仍有内容、间隙不超过 16 dB 的邻段。两端和 6.3 kHz 以上不接收这种新的提升。自动 Recover 的许可原样保留：没有缺口证据的自动份额不会凭空抬频段。

提升沿 hop 做约 180 ms 平滑，再用 A 计权把参与频段的净增益拉回 0 附近，幅度封在 ±0.45 dB。谱本身已经平、没有深于 0.8 dB 的削减时，目标与原来逐位相同。粉噪收敛、电平阶跃和扫频的原门槛都还在。

### Limit：三角攻击沿，短过载不按住慢包络

攻击仍在原来的前瞻长度内走完，峰值那一刻的增益与原来的矩形滑动平均同时到位。矩形窗换成两级滑动平均，拐角连续；恒定增益仍精确回到 1。

连续过载短于约 70 ms 时，结束后的半个窗口里慢包络不允许低于快包络，鼓点后面按快释放回来。持续过载仍由慢包络压住。手动 Release、低频周期释放和真峰值硬边界都没有改。

### Color Glue：低、中、高分开施压

表和统计仍是原来的联动包络（100 Hz 高通、2:1、6 dB 拐点），所以稳态方波的压缩量读数不变。低（约 180 Hz 以下，攻击 36 ms）和高（约 5 kHz 以上，攻击 8 ms）若自己更轻，增益最多比联动增益高 3.2 dB，也可以比联动再深 0.6 dB。中频跟联动攻击。三路差为 0 时退回原来的单增益乘法。Glue 关掉时检测器和音频分裂滤波器照常走，重开不用冷状态。

## 刻意没做的

- 不实现 Gullfoss 的专利均衡、Bias/Boost 新旋钮，或 20 ms 决策延迟。
- 不把限幅侧链高通做到可以越过用户 Ceiling。G2 自己把那种模式标成压缩器状态。
- 不把 Heat 换成另一套激励曲线，也不把 God Particle 的三段增益目标画进界面。
- 不宣称听感已经等于这三款插件。合成信号只能证明方向、边界和没有退回旧的安全问题。

## 验证

Linux Release 无头测试全套 **129281 passed / 0 failed**。其中：

- 限幅独立 16 倍重建最坏仍低于 Ceiling 0.0461 dB；低于内部阈值的信号仍是 null。
- 12 ms 过载后 45 ms 的尾部，比 280 ms 持续过载后的尾部高 6.6 dB（−18.3 dB 对 −24.9 dB）。
- 508 Hz 主导音与 640 Hz 邻音同时打开 Recover/Tame 时，邻音比只开 Tame 少被压，并且高于主导音；只开 Tame 不会单独抬它。
- Glue 100 时 90 Hz 变化 +0.66 dB，同时的 2.5 kHz 变化 −2.92 dB。6 kHz 方波的联动压缩量仍落在原来的静态曲线上。

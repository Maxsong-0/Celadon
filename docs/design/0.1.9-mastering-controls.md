# 0.1.9 母带控制与青瓷界面

## 使用流程

保留默认的一旋钮流程：调 GLAZE，比较处理前后，需要时进入「高级」。主界面的处理顺序是 BALANCE → CLAY → COLOR → LIMIT。卡片按真实顺序排列，参数区从 202 增高到 248 个逻辑像素，增大文字、旋钮和按钮；中央装饰带压缩到 260 个逻辑像素，主旋钮显示为 200 个逻辑像素；主旋钮保留柔和青釉和细开片，减少碎面高光与背景粒子。

高级面板分三个页签。它们使用宿主参数，支持自动化、撤销手势及工程保存。原声、LIMIT 差值和发行归一化预听属于临时监听状态，彼此互斥；主窗口持续显示可点击退出的提示。关闭编辑器关闭这些临时监听状态，离线导出也禁用归一化预听。实时录制或实时导出无法与正常播放区分，开始前必须退出预听。

## 推响不刺

- 自动：处理量随 GLAZE 与「强度」联动；GLAZE 0 时新增自动处理为零。
- 关闭：停用额外的刺耳控制与起音保留。
- 手动：强度不依赖 GLAZE，允许在 GLAZE 0 时工作。
- 起音保留：瞬态到来时放松刺耳频段压低，减少打击乐起音被削平。它不是一个独立增益增强器。

刺耳控制和目标频谱在 BALANCE 内执行，BALANCE 旁通时不生效。处理复用 BALANCE 的 27 段分析，集中约 2–8 kHz，使用有界、平滑的额外修正。不增加音频链延迟，不进行动态内存分配。音色是否合适仍需对自己的音乐做等响听音判断。

## 目标频谱

模式为关闭、自动、温暖、中性、明亮和参考。自动随 GLAZE 联动；显式风格及参考是手动选择，「强度」控制趋近目标的程度。目标曲线以相对频谱为依据，不复制参考曲的总响度，也不追求逐频点完全一致。

「学习参考」只读取宿主的可选立体声侧链输入。将参考曲单独送到 Celadon 的 sidechain，播放至少 10 秒有效非静音音频，并等待学习完成（最后一帧有短暂分析尾）。没有侧链或没有有效声音时保持等待，不使用主输入冒充参考。取消保留上一份已完成的参考；清除移除它。学习完成的归一化 27 段数据随工程保存。学习计算在多个音频回调中分片，避免整帧 FFT 阻塞小缓冲；分析尾不增加主输出延迟。界面显示学习进度和实际频段修正。

参考曲不进入主输出。参考学习时才运行额外频谱分析；平时使用保存的目标。若最后不足一帧的片段无效，会保留其后已收到的样本，改用完整帧重试；因此需要的是至少 10 秒有效音频，极端情况下会额外收集不足一帧，而不会反复处理短片段造成积压。

## 发行安全

- 归一化预听：选择 -24 至 -8 LUFS 的监听目标，默认 -14 LUFS。它使用预听前的输出响度计算衰减，避免读自身衰减后的信号形成反馈。只用于比较音量，不改变处理链的母带目标；离线导出自动关闭，实时导出前需手动退出。它也不替代完整曲目响度测量。
- 编码余量：0 至 1.5 dB，默认 0 dB。LIMIT 开启时实际收紧限幅器输出上限，为后续有损编码预留空间。**没有进行 AAC/MP3 编解码或编码后真峰值检测，不能保证任意编码器不超峰。**
- 抖动：默认关闭，可选 16-bit / 24-bit TPDF 加最终整数位深量化，放在最终主输出级。仅在自己负责最终位深量化时启用；宿主或后续处理器已加抖动时保持关闭。原声、差值试听及宿主旁通不加抖动。

## 兼容与验证边界

加载不含新参数的旧工程时，新增刺耳控制、目标频谱、编码余量和抖动均关闭，保持旧声音。新实例的自动功能仍遵循 GLAZE 0 中性。

验收涵盖：实际音频的功能差异、GLAZE 0 与旧状态中性、参考学习缺输入/取消/完成/恢复、预听互斥与离线出口、抖动数值性质、不同块长及重复 prepare/reset、音频线程分配和已有链路回归。界面用真实组件离屏渲染检查中文/英文、70% 缩放和高级页签，再对组件发送鼠标事件核对参数与状态。

验证结果以本分支最终构建日志和测试报告为准；此文件描述设计和验收要求，不代表所有验收已通过。未执行的 DAW 实际操作、编码器测试和歌曲听音不得由合成信号测试替代。

# Celadon：自适应听感与统计一致性修订

2026-09-26；对外版本 v0.1.6.2，内部算法版本 6。

本轮在用户认可的 colour-render 版本上继续实现五项优化。旧源码、测试和基准已备份到 `/private/tmp/celadon-intelligent-20260926-180305`，旧试听包保留。

## 实现范围

- 限幅：在既有快慢双包络上增加持续低频周期约束，保留瞬态和手动释放路径。
- Heat：检测并收敛新增高频残差，原声干路保持原样，立体声采用共同保护量。
- 段落：仅缓慢收回和恢复方案中的自动 Heat/Glue 份额，手动部分与长期响度目标保留。
- Balance：复用既有频谱，为有可靠谐波支持的峰降低自动 Tame 力度，保留独立共振处理。
- 保护统计：链按保护层实际 10 ms 时隙边界切片，避免把整块均值/最大值分摊到不同时间段。

## 处理规则与成本边界

限幅新增的检测器只工作在 1× 控制路径，左右分别观察低频以保留纯 Side 低音的证据。连续的周期一致性与能量稳定条件成立后，快释放从原 30 ms 向约四个低频周期调整，上限 140 ms；手动 Release 不受影响。固定前瞻与最终真峰值保护保留。

Heat 采用 4 kHz 一阶互补分频分析新增 M/S 残差，以其高频能量相对原声能量的比例限制过量染色。30 ms 能量平滑、15 ms 收敛、250 ms 恢复，残差高频增益最低 0.35；原声干路、64 样本延迟与现有 8× 链保持。该比例是染色预算，不是对输出 THD 的承诺。

段落跟随只回收计划中的自动份额，Heat 最多 50%、Glue 最多 35%；每秒最多回收 10%、恢复 4%，有 2.5% 回差。手动参数、长期画像和响度目标不随该路径重写；证据不足、静音或旁通时冻结。执行快照保存当前真正使用的比例，旧缺字段为中性。

Balance 的新保护只是一种保守的谱线关系证据：利用已有 FFT 识别可靠 1:2:3 关系，且至少一个声道中须同时存在完整组。以 60 ms 进入、300 ms 退出，最多回收 75% 自动 Tame 许可，仍保留手动处理与少量自动处理。它不识别人声或乐器，也不会保护所有乐音。未增加 FFT。

Guard 仍使用 10 ms 时隙均值的 p95 近似，不是逐样本 p95。新增链内切片让真实模块统计不跨时隙，宿主整块仍使用同一组执行参数，新的控制量在下一宿主块应用。静音/旁通丢弃不足一个时隙的未完成统计，已完成历史与保护量保持。报告延迟保持不变，实时堆分配检查通过；CPU 数据见下方整处理器实测。

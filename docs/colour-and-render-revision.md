# Celadon：低频保真染色、声像保护与渲染一致性

2026-09-26；对外版本仍为 **v0.1.6.2**。本轮接续 `adaptive-preview`，保留默认 GLAZE 35%、Auto、逐频段起音保护、段落明暗跟随和整链等响 Listen。新包另用 `colour-render-preview` 后缀。

## 实现

### 保留低频主体的 Heat

原声经过固定 64 样本延迟完整保留。染色支路先做 150 Hz 二阶高通，只把过采样非线性产生的残差加回原声，减轻低音对中高频的互调。仍复用现有 8× 半带 FIR 链，没有增加 FFT 或第二条工作过采样链；支路高通保持连续运行，空闲重开时恢复 FIR 历史。

Heat 0 保持等延迟直通。旋钮、干湿和旁通继续平滑。修复特殊块长下把“本块尚未处理的样本”提前计为空闲历史的问题，避免淡出后过早跳过 8× 处理。

### 声像保护

染色支路编码为 Mid/Side。Mid 保留温和的非对称谐波，Side 使用更轻且严格奇对称的曲线，再解码并加回左右原声。目标是减少纯侧边信号经偶次谐波产生中央内容，不是固定宽度器，也不做自动无限增宽。不同声像比例和输入电平仍会有不同的音色变化。

### 学习、校准与导出

实时和离线使用相同的样本时间学习、校准和安全反馈。新实例从头离线也正常分析，切换离线标志不再停止学习或撤回正在生效的校准偏差。对导出时仍报告停止播放的宿主，将持续送入的离线音频视为渲染进度。

在正式画像之外保存独立 `EXECUTION` 快照，包含当前实际方案、参考条件、正在施加的校准偏差、保护退让及运行中的 Tone/Tame 增量。候选画像仍不是正式画像，进行中的校准仍不是有效校准。快照参数、采样率或算法条件不匹配时失效。未完成的学习在重开后先保持已保存的处理方案，再重新积累有效证据。

宿主 reset 也采用相同的执行快照入口，保留已经听到的控制量和学习累计。已经完成的校准若尚未施加完目标，首块恢复实际值后继续按原有 1 dB/s 平滑追完；保护吸收改写过计划时，保留当前声音并重新验证，待验证状态经再次保存与重开仍成立。

执行快照不保存音频延迟线、滤波器、检测器及完整学习窗口历史。因此，保证的范围是相同快照、相同输入起点、相同处理块时间线下实时与离线的可复现性；不把重开后的冷启动与从未中断播放的音频尾部等同。跳转到另一个位置、改变块长或宿主重置带来的历史差异仍需区别。

### 标定和兼容

引擎算法和出厂标定版本升至 **5**；插件显示版本仍为 **0.1.6.2**。新的 Heat 在相同类音乐素材上完成五个入口真峰值电平 × 九个 Heat 量的 45 点标定，更新自动规划的响度和峰值查表。参考素材以低频为主，新曲线几乎不替低音削峰，因此主要增响仍由限幅器承担。

旧 Heat 模型的画像和手动旋钮保留，自动方案与校准按新模型重算，不把旧曲线补偿直接叠到新 DSP 上。升级后的染色声音会改变；此前的试听包单独保留。

## 验证记录

最终完整回归 **109975 passed / 0 failed**；Color 专项 **623 passed / 0 failed**，Controller 专项 **2052 passed / 0 failed**。保留原有混叠、真峰值、零分配、GLAZE 0、自动化、立体声、空闲恢复与音频逐位对照门槛。

首轮完整回归为 109960 passed / 1 failed，定位到原实例 reset 与执行快照恢复的语义不同，已统一。第二轮为 109960 passed / 2 failed，两条旧 Tone 断言仍要求 reset 清除已听到的音色；按新语义改为记录 reset 前的值并要求恢复后相等，原有音频逐位断言保留。随后补修“首块正确但已完成校准永远不追完”的续行缺陷，以及保护改写后二次重开的待验证状态，最终全套通过。

### 声学对照

- 冻结旧 Heat 模型，以 6 kHz 的 H2+H3／基波比匹配：旧 Heat 60 对应新 Heat 59.912，谐波比相差 −0.011 dB；加入 60 Hz 低音后，互调由 **3.5425% 降到 0.1778%**，约改善 **25.99 dB**。这是同一合成输入的对照，不是对所有歌曲的统计。
- 40/60/100 Hz，在 44.1/48/96 kHz、−12/−0.5 dBFS、Heat 30/100 下，低频基波变化均在 **±0.25 dB** 内，低频失真小于 1%。
- 纯 Side 的 Mid 残留低于 −120 dBFS；左右交换、双单声道与 mono 的逐位一致测试通过。所测正常 M/S 信号比例变化为 −0.059～+0.553 dB，在预定 ±0.75 dB 内。
- 333 样本块长、20 ms 淡出、短关后立即重开以及长期关闭后重开，与禁用空闲跳过的处理逐位一致。

### 真实处理器渲染

真实 `CeladonAudioProcessor` 的渲染验收 **21 项通过**，参数默认值和旧工程恢复 **8 项通过**。55 秒同源播放中，从头离线与实时逐样本相同，第 5 秒切离线也不改变音频。学习第 5 秒、校准进行中和响副歌三个快照，恢复前／后调用 prepare 两种宿主顺序的首块七项实际参数误差均为 0，两份恢复的实时／离线输出逐样本相同。

每个快照另以 64 样本实时／1024 样本离线渲染 60 秒：最大整体响度差 **0.001181 LU**、最大 3 秒窗口差 **0.013693 LU**、结束时最大 Gain 差 **0.006462 dB**。跨块不是逐位保证；保护层接收模块的整块统计，极端短峰、不同宿主块安排和其他素材仍可能改变闭环触发时机。

### CPU 和延迟

本机 Apple M2 Pro、交流电、低电量模式关闭；Release/LTO、完整处理器、无界面，预热 45 秒音频，每档三遍、每遍 4 秒。下表取最快一遍的平均处理耗时占音频块时长，**不是整机 CPU 百分比**。

| 采样率／块长 | 改前 Auto100 | 改后 Auto100 | 改后默认 Auto35 |
|---|---:|---:|---:|
| 48 kHz / 64 | 1.247% | 1.335% | 1.317% |
| 48 kHz / 512 | 1.197% | 1.256% | 1.234% |
| 96 kHz / 64 | 2.438% | 2.671% | 2.596% |
| 96 kHz / 512 | 2.343% | 2.469% | 2.419% |

满量平均开销增加 0.059～0.233 个百分点。Auto100 P99 为 1.433%～4.381%；包含所有轮次的最坏单块为 37.119%，这类瞬时值会受系统调度影响。所有档位 nonFinite=0。整链 48/96 kHz 延迟仍为 **282/378 样本**，Color 为固定 64 样本。预热结束画像已取得，校准仍在进行，不能把 CPU 预热等同于校准完成。

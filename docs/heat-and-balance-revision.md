# Celadon 0.1.6.2 试听修订

用户反馈：Heat 持续高频刺耳、砂砾感和挤压；Tame / Brighten 作用保守；自动模式缺少歌曲与段落适应。

## 实施

- Heat 改为全范围渐进的并联染色：drive 1→2、asymmetry 0→0.04、湿路 0→25%。保留 8 倍过采样、20 ms 平滑、DC 阻断及 64 样本延迟。原来 Heat 10 即全湿、满档 drive 10。
- Brighten 独立于 Recover / Tame，满档每 decade 3 dB 的频段目标。27 个峰值滤波器相互叠加，不能将目标误称为最终实测频响。
- Tame 中高档力度增加：基础强度 t，额外 t² 仅作用于当前局部谱峰，动态压制上限 8t dB；保留静音门、原有跟踪时间与限速。曲线显示范围同步扩展到 ±8 dB。
- 自动风格不再被尚未积累完的 60 秒 LRA 置信度整体压向 Clean；LRA 仍独立约束动态特征。
- 学习结束后继续复用 Balance 频谱帧计算短期突出证据，按证据增强自动 Tame，并保留持续性与平滑。既有画像与响度目标不因这一调节重写。
- 出厂 Tame 权限增加；Heat 换算表按新 DSP 重新测量，限幅器承担更多增响份额。并联 Heat 的削峰份额改为可选贡献，其能力不足不再锁死仍有余量的限幅器；最终模块预算照常检查。算法与标定版本更新为 3。

## Heat 修改前后实测

48 kHz，立体声，块 512。1 kHz 正弦峰值 −0.5 dBFS，后 1 秒稳态，THD 计算第 2～12 次谐波。

| Heat | 旧版 THD | 新版 THD | 旧版基波变化 | 新版基波变化 |
|---|---:|---:|---:|---:|
| 10 | 15.336% | 0.144% | −4.276 dB | −0.043 dB |
| 50 | 33.884% | 1.033% | −11.380 dB | −0.330 dB |
| 100 | 39.756% | 2.688% | −14.789 dB | −0.935 dB |

60 Hz（幅度0.75）+7 kHz（幅度0.18），满Heat时7 kHz±120 Hz旁带合成相对载波：旧版 +2.464 dBc，新版 −22.379 dBc。高频载波衰减由 −18.632 dB 降至 −1.184 dB。该结果验证了过强互调改善，不等同于真实歌曲主观音质评分。

Brighten 的实际粉噪频响：30 档时 100 Hz −1.28 dB、10 kHz +0.94 dB，两端相对变化 2.22 dB；满档两端相对变化 7.42 dB。测试为 Recover=Tame=0，说明提亮已能独立工作。

## 兼容边界

本版有意改变 Heat、Tame 和 Brighten 的声音，旧工程不能保证逐位或听感相同。旧 Heat 标定模型须在恢复状态时更新，并用保留的歌曲画像重算自动方案，避免沿用旧失真器的大补偿增益。旧试听包保留。插件格式、参数 ID 和延迟不变。

## 验证记录

原始测量及可复现诊断代码保存在 `docs/validation/2026-09-26-heat-revision/`。全套回归 108262 passed / 0 failed；之后仅修复自定义 Heat-only 分配的 Infinity×0 边界，GlazePlanner 补测 3421 passed / 0 failed。涵盖热输入、互调、自动化连续性、静音、延迟、参数恢复、音频线程零 C++ 分配、低频防泵、实时/离线 Tame 一致性、旧模型迁移以及输出真峰值。前两轮的失败与编译记录保留供追溯。AU / VST3 Release arm64 构建成功，均显示 0.6.2，codesign 深度/严格校验通过；VST3 已在测试宿主实际实例化并处理音频。AU 尚未在用户 DAW 里验收。合成素材通过不能替代真实歌曲同响度试听；目前没有用户歌曲素材可作针对性判断。

## CPU 实测

本机 Apple M2 Pro、交流电、关闭低电量模式，无插件界面。Release / LTO；Auto、GLAZE 100，预热45秒音频，每档3次4秒音频测量，采用基准工具的平均计时口径。下表百分比为处理耗时除以单个音频块时长，是单音频线程预算占比，不是整台电脑CPU使用率。

| 采样率 / buffer | 原版平均 | 新版平均 |
|---|---:|---:|
| 48k / 64 | 1.262% | 1.301% |
| 48k / 512 | 1.160% | 1.217% |
| 96k / 64 | 2.503% | 2.618% |
| 96k / 512 | 2.352% | 2.435% |

新增开销为0.039～0.115个百分点（约3%～5%的相对增加）。处理器输出nonFinite=0，延迟仍为48k时282样本、96k时378样本。全轮最坏块预算占用17.556%，未超过100%；该指标会受操作系统调度影响。预热时profileReady=1、calibrationValid=0、phase=3，代表已取得画像、校准仍在进行，并非宣称已完成校准。

直接加载成品 VST3 的宿主计时：48k/64为1.152%，48k/512为1.079%，96k/64为2.288%，96k/512为2.091%。该宿主没有绘制界面、不是用户 DAW；实际工程仍需试听。

版本标记更新为0.1.6.2；DSP代码与0.6.2试听版一致，上述音频与CPU测量沿用同一实现的验证结果。

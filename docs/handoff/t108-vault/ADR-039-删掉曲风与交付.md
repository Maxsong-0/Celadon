# ADR-039 删掉曲风与交付（连参数与声音处理一起）

## 背景

- [[ADR-026-曲风与交付拆成两个开关]]（T-038，2026-10-01）加了「曲风」（通用 / Deep House / Tech House / Melodic-Progressive）与「交付」（标准 / 流媒体 / 俱乐部）两个选择。House 三类换主段模型（4/4 型）、音色目标、低切、限幅跟拍并开落差守门；流媒体把目标响度定在 −10 LUFS、有效 Ceiling 封在 −2 dBTP，俱乐部 −7 LUFS；[[ADR-033-交付档允许自动增益为负]] 让这两档可以往下压。
- 2026-11-13 Max 看 T-107 效果图后说「直接删掉，不用再搞曲风这些的了」，追问后定「连声音处理也删」（T-108）。T-107 已经把面板上的两个选择删了（PR #91，`fa381f2`）。
- T-108 调查多查出两件任务书没写的：① 落差守门只在 House 开、PSR 守门出厂四个曲风都关，删了曲风这两个守门在出厂常数下永远不跑；② 流媒体的 −2 dBTP 封顶与 House 的限幅跟拍都不看 GLAZE，所以存着这些档的 GLAZE 0 旧工程也会变声，和 [[ADR-035-旧工程与GLAZE0的变声政策]] 冲突。

## 决定

1. **只剩今天「通用 + 标准」那一条路**（Max）。在通用 + 标准下，任何 GLAZE、任何风格，输出和删之前逐位相同（验收硬门，比任务书严，Claude 定）。
2. **交付固定按「标准」**（Q1，Max）：目标响度照风格（−8.5 / −9 / −10 LUFS），只往上推、不往下压。删掉流媒体 −2 dBTP 封顶、俱乐部目标响度与放宽限幅预算、ADR-033 的负自动增益、T-089 的最少推响量封顶。
3. **曲风一起删**：主段模型只留 `loudness`（删 `fourOnFloor`，连今天就没人用的 `passive`）；House 的音色覆盖（Tone 参考斜率、往亮上限、低切 25 Hz、不自动加宽、「目标频谱 = 自动」的 House 斜率）、限幅跟拍 `beatReleaseCapMs`、House 反相提示（`housePhaseHint`）、MusicAnalyzer 的 House 学习残留都删。
4. **守护族连代码一起删**（Q5 = A，Max）：`ContrastGuard`、`PsrGuard`、守门开关、`GuardCause::contrast / psr`、G_trim「有退让量就冻结」那一支。「1 s 内改过参数就冻结」照旧（ADR-036 决定 3 的其余部分、[[ADR-038-G_trim换误差口径]] 不变）。[[2026-11-12-落差守门退让量来回摆-任务书]] 作废。
5. **两个参数从参数表删掉**（Q3，Max，推翻任务书原推荐「留 ID」）：`glaze_genre` / `glaze_delivery`。ID 字符串留在 `ParameterIds.h` 的 `legacy` 里只给读旧工程用，不得再给别的参数。这两个参数本来就不可自动化，宿主里其余参数的自动化不受影响（JUCE 按 ID 哈希定位）。
6. **旧工程**（Q2，Max）：`setStateInformation` 交给 APVTS 之前把这两个 PARAM 节点摘掉；其中有不是默认值（通用 / 标准）的，本次打开在左下角琥珀提示一次「曲风与交付已取消，已改回通用 + 标准，声音会变」/「Genre/delivery removed, now General + Standard; sound changes」，不进工程（存回去就没有了）。和「旧的聆听结果已丢弃」同时出现时各占一行。存着通用 + 标准的旧工程不提示、输出逐位不变。**这是 ADR-035「GLAZE 0 不改」的一次例外**：存着 House / 流媒体 / 俱乐部的 GLAZE 0 旧工程也会变（限幅跟拍、−2 dBTP 封顶没了），写进更新日志。
7. **存档兼容**（Claude 定）：外层格式版本不升。读：画像格式 3 的 `HouseGateSummary`、校准参考与标定快照里的曲风 / 交付字段、T-097 的 `CONTRAST` / `PSR` 守门节点都认得、读进来丢掉。写：照旧写两个空的守门子节点（`legacyContrastGuardStub` / `legacyPsrGuardStub`），0.1.8.10 打开新存的工程不报错，缺的两个参数按默认读。
8. **界面字**（Claude 定）：「交付峰值」（`GuardCause::deliveryPeak`，其实是限幅 GR 超限）改成「限幅」/「Limiter」。帮助、状态句、CLAY 卡片里的曲风 / 交付 / House 提示全删。
9. **出口电平跟踪器的 100 ms 子块切片留着**（Claude 定，偏离计划）：它决定各片执行哪份设置，属于 ADR-038 的读数，删了 GLAZE > 0 不再逐位（实测差到 0.12 LU）。入口那份跟踪器只给守门用，删。
10. **LiveProfile 的低频门留作通用机制**（Claude 定）：开不开看 `loudness.lowGateFactor > 0`，出厂 0（通用今天就不开）；成本估算与 `newProgramRange` 也留着（旧工程恢复的窗口可能投票数 2）。
11. **渲染工具与门禁**（Q4，Max；细节 Claude 定）：删 `--genre / --delivery / --live-model / --selftest-house / --streaming-target-lufs` 与 House 追加列；删 `house_gate.py`、`calibrate_house.py`、`codec_tp_check.py`。留 `--listen-from-bar / --bpm / --meter / --segments-csv / --no-align`；合成 House 曲（`make_synthetic_house.py`）留作普通素材；House 门禁 ①「先听中段、再从头导出」改成通用档的 `listen_start_check.py`（从第 1 小节与第 N 小节播，第一遍末方案增益差 ≤ 0.5 dB），其余 House 门禁项与 0.1.8.11 门槛里的 House 项撤掉。
12. **版本**（Q6，Max）：进 0.1.8.11，和 T-106 一起发。版本号与更新日志在发版那一步写，不在 T-108 里升。

## 备选方案与放弃原因

- 留参数 ID、只藏起来（任务书原推荐）：这两个参数本来就不可自动化，留着宿主参数列表里照样看得见，什么也没藏住 → 放弃（Q3）。
- 留下落差守门、开给所有歌（Q5 = B）：要重新标定门槛、会改通用 + 标准的声音，等于新功能 → 放弃。
- 交付改成只留「流媒体 −2 dBTP」一个开关：又回到选择器；用 Ceiling −2 dBTP 或编码余量就做得到 → 放弃（Q1）。
- 旧工程照旧读出 House / 流媒体的声音（留一条只读路径）：两套处理并存，正是要删的东西 → 放弃（Q2）。

## 后果

- 插件少了两个选择、两个守门和 House 一整套分支；源码约 −14000 / +2500 行（118 个文件，含官网与工具），`Source/dsp/` 删 `ContrastGuard`、`PsrGuard` 四个文件。
- **变声**：只限存着非默认曲风 / 交付的旧工程（含 GLAZE 0）。House 档的音色、主段判断与限幅跟拍，流媒体的 −10 LUFS 与 −2 dBTP，俱乐部的 −7 LUFS 都没了，统一回到通用 + 标准。更新日志素材（0.1.8.11）：「去掉了曲风与交付两个选择。存着 House 曲风、流媒体或俱乐部的旧工程打开后改回通用 + 标准，声音会变（GLAZE 0 也会），左下角提示一次。要出流媒体版，把 Ceiling 设到 −2 dBTP 或打开编码余量；要更响，开大 GLAZE 或选冲击。」
- 官网中英相关页（glaze、install、faq、interface、limit、clay、meters、listening、advanced、controls、quickstart 与算法页）改成现行口径，「曲风与交付（已取消）」一节说明旧工程会怎样。
- 作废：T-098 第 8 条（播放中换曲风）、「House 组死代码」「规格追认取消 House 反相提示」（都被 T-108 吃掉）、落差守门退让量来回摆任务、0.1.8.11 门槛的 House 项。
- 四份规格加「已被取代」指针、原文不删：[[设计规格-曲风与交付]]、[[设计规格-曲风-House学习方式]]、[[设计规格-实时GLAZE-曲风]]、[[设计规格-实时GLAZE-主段与增益]] 第 4 节的守门部分。

### 2.1 左栏「GLAZE 此刻在做什么」

- 表头一行（body 11，三级灰）。
- 状态：8 px 圆点 + 阶段词（display 22 半粗）。阶段词就是 V4 标题行里的标签：全手动 / 受手动 / 导出 / 受限 / 预热 / 保持 / 跟随。下面是状态句的其余部分，不截断，最多两行（留 32 高）。
  - 受手动 / 导出 / 受限拿到橙色时，圆点、阶段词、状态句用橙；没拿到时用中性色。预热时圆点呼吸。
- 四行，每行 33 高：序号 + 名字（88 宽）、56 × 4 的紫色出力条、GLAZE 此刻加在各项上的量（等宽 11，紫字）。CLAY 不画条，写「自动 / 手动 / 自动 N 项」。旁通的模块整行 0.55 透明并去色。内容与口径同 T-107 左侧板。
- 末行：把握 · 本段是 / 不是主段 · 保护。
- T-086 的「预算到顶」数据到位后加在各行条尾，本规格不含。

### 2.2 右栏「交付」

## 3. 展开与收起

- 同一时刻最多展开一个模块；新工程默认全部收起。
- 点模块行的一块：没展开就展开它；它正展开着就收起；展开着别的就直接换成它（面板不先关再开）。
- 收起有三个入口：再点同一块、面板右上角的收起键、频谱上的「放大频谱」。
- 模块行不动，所以鼠标停在同一个位置能反复开合。
- 展开的是哪一个、停在哪一页，随工程存：状态树属性 `uiOpenModule`（0 = 都收起，1 ～ 4）和 `uiOpenPage`，存法同 `uiZoom`。它们不是参数，不进自动化，不改声音；旧工程没有这两个属性，按都收起。

## 4. 状态胶囊、警示与监听

顶栏正中的状态胶囊**平时不出现**：稳态的状态已经在左栏用 22 px 的阶段词写着。它只在下面几种时候出现，文字和 V4 相同。

| 情形 | 胶囊 | 同时亮的地方 |
|---|---|---|
| 异常音频块 | 橙 | — |
| 真峰值超限 | 橙：「真峰值 −0.7 dBTP · 超出上限 −1.0」 | 右栏真峰值读数、输出表 |
| GLAZE 受手动 / 导出 / 受限 | 橙：状态句全文 | 左栏圆点、阶段词、状态句；受限时 LIMIT 的限幅衰减（模块行那一块和面板里） |
| 听原声 / 试听差值 / 归一化预听 | 白底、深色字、深色圆点 | 主区左下的退出提示（深色底白字）；对应按钮的选中态 |
| Debug 构建 | 橙 | — |

- 橙色归谁照 `glazestatus::attentionOwner` 不变。CLAY 守护灯和旧工程提示拿到橙色时不出胶囊（V4 也不出），只在源头亮：CLAY 是模块行那一块的三盏灯和面板里那一行，旧工程提示在主区左下。
- 监听退出提示开着时藏起操作提示（同 V4）。
- 模块旁通：模块行那一块的内容 0.55 透明，第二行换成「已旁通」，电源键变灰；左栏对应的行同样变淡；展开面板的内容 0.55 透明，仍然可调。

## 6. 动效

| 动作 | 多常做 | 动不动 | 做法 |
|---|---|---|---|
| 展开 / 收起模块 | 偶尔 | 动：频谱上缘一下跳 174 px 会像坏了 | 频谱上缘 200 ms，曲线 `cubic-bezier(0.23, 1, 0.32, 1)`；面板不透明度 0 → 1 加上移 6 px，180 ms 同曲线；收起 160 ms。过程中频谱贴缓存图缩放，结束时按新尺寸重画一次 |
| 换到另一个模块 | 偶尔 | 只淡入 | 面板内容 120 ms 不透明度；接面板的短线直接跳过去 |
| 面板里切页签 | 较常 | 不动 | 立即换 |
| 状态胶囊出现 / 消失 | 偶尔 | 动 | 不透明度加下移 4 px，160 ms；消失 120 ms |
| 按模块行的一块 | 常 | 只给按下态 | 按下立即换底色，松开 120 ms 退回；不缩放 |
| 拖旋钮、滑条 | 很常 | 照旧 | `DialMotion` 不改 |

- 开着「减少动效」时以上全部立即完成。
- 展开到一半又点了别的：从当前位置接着走，不从头播。

## 7. 缩放

- 整个画布等比缩放，规则不变。70 % 时最小的字（micro 9）约 6.3 px，和 V4 同一水平；200 % 全是矢量。稿子见画布上「70 %」「200 %」两张。
- 没做：小屏紧凑模式（都收起时把窗口缩矮）。「画布比例固定」是现行前提，要做得另议。

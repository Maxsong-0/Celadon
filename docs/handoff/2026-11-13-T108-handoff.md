## 5. Mac 上编译（Max）

前提：仓库和 JUCE 9.0.2 同级摆放（`../JUCE`），见 `docs/BUILDING.md`。

1. 切到分支。先确认 Mac 上的仓库没有没提交的改动：

   ```bash
   git status --short
   ```

   ```bash
   git fetch origin && (git switch claude/t108-remove-genre-delivery-v2 2>/dev/null || git switch --track origin/claude/t108-remove-genre-delivery-v2) && git pull --ff-only && git log --oneline -1
   ```

2. **必须用 Projucer 重存一次工程。** T-108 删了 `ContrastGuard`、`PsrGuard` 四个源文件，又加了 `LegacyState.h`。`Builds/` 不进版本库，不重存的话 Xcode 还会去找删掉的文件，编不过。重存前先关掉开着的 Projucer 窗口，并且不要保存：

   ```bash
   ../JUCE/Projucer.app/Contents/MacOS/Projucer --resave Celadon.jucer
   ```

   核对一下，下面应该打印 `0`：

   ```bash
   grep -c -E 'ContrastGuard|PsrGuard' Builds/MacOSX/Celadon.xcodeproj/project.pbxproj
   ```

3. 编 Release 通用版（与 `docs/BUILDING.md` 同一条命令）：

   ```bash
   xcodebuild -project Builds/MacOSX/Celadon.xcodeproj -scheme "Celadon - All" -configuration Release -destination 'generic/platform=macOS' ONLY_ACTIVE_ARCH=NO build
   ```

   Release 会把 VST3 和 AU 拷进 `~/Library/Audio/Plug-Ins/`，**覆盖你现在装着的 Celadon**，版本号也同为 0.1.8.10。如果你还用 pkg 往 `/Library/Audio/Plug-Ins/` 装过一份，宿主会看到两份：

   ```bash
   ls /Library/Audio/Plug-Ins/VST3 /Library/Audio/Plug-Ins/Components | grep -i celadon
   ```

4. 重开 DAW。Logic 如果还显示曲风 / 交付两个选择器，就去插件管理器里对 Celadon 点「重新扫描」。

**要换回 main 版**：`git switch main && git pull --ff-only`，然后重复第 2、3 步。

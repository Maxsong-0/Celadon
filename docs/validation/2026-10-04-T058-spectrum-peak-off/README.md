# T-058 · 频谱仪 PEAK 关着时别因峰值保持下落每帧重建、重画（2026-10-04，DGX Spark 本机）

## 结论

`SpectrumView::setSpectrum` 在 PEAK（峰值线）关着时仍比较峰值线：峰值保持往下落的那几秒（停播后约 6 ～ 7 s）每帧判「变了」、重建四条路径、重画曲线区，屏上什么都没变。
改后只比看得见的曲线，**PEAK 关时重建曲线数减少 74 ～ 94 %、设备像素减少 73 ～ 91 %、频谱仪 CPU（推进 + 重画）省 31 ～ 69 %**（×1 倍省 31 ～ 42 %、×2 倍省 52 ～ 69 %）；PEAK 开着时 12 / 12 个组合的曲线帧 / 脏帧 / 设备像素与改前完全相同；
`--deterministic` 30 张出图与 main 逐字节相同；`--only check` 87 → 93 条全过。

## 实现（`Source/ui/SpectrumView.{h,cpp}`，设计细节见 `SpectrumView.h` 文件头 T-058 段）

1. 只比看得见的曲线：PEAK 关着不比峰值线；IN 没有曲线时不比 IN。
2. 计算器此刻的值每帧拷进 `latest*`（只拷不比）；任何重建（`setSpectrum` 判变了、换斜率 / 打开 PEAK 后在 `paint` 里）都先换成它，`inputDashesValid = false` 挪进 `buildCurvePaths`。读数（换斜率、悬停、定时刷新）用此刻的值；光标圆点照旧画在画出来的曲线上。
   不这样改的话，PEAK 关着停播后 OUT 与平均线停在约 0.3 s 时的样子，曲线静止时换斜率会把压在底边下的旧值抬出来画一帧。
3. PEAK 一律经 `setPeakShown`：打开那一刻 `curvePathsValid = false`，`paint` 按此刻的值重建并按 R-02 ① 把画出的区域并进旧区域。
4. R-02 ②（`curveRegion` 不论开关都算峰值线 / IN 线）代码不动，注释改写为「第二道保险」。

截图工具（`tools/ui-snapshot`）：S8 的逐帧推进抽成 `SpectrumRig` / `DirtyRun`；新增六条检查（S9 残影、S9「PEAK 关、只剩峰值保持在落时 0 帧重建」、播放、S10a / b / c）与 `--only spectrum-peak-bench`，见该目录 README。

## 口径变化（待 Max 知悉）

任务书写的「撤 R-02 ② 应失败、放回应通过」在新代码上**做不到**：打开 PEAK 时按此刻的值重建、① 把画出的区域并进旧区域，峰值线已经盖住，② 成了第二道保险（红绿表第 3 行：只撤 ② 全绿）。

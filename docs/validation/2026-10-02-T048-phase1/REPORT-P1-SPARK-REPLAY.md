**机制**：回看重判下，参考（S_ref 或 lowRef）一跳升（更响或低音更满的素材进来），窗口里原来的主段（多是前奏）按此刻的参考被重判出局，主段质量 M 塌到只剩新段。c = 1 − exp(−M ÷ M0) 从低处重新爬，M0 = 8 小节，要约 1.61 × M0 ≈ 13 个主段小节才回到 0.8。改前（5a67051，进账时定 m）前奏的质量留在 M 里，c 不掉。

### 7.2 (b) M2 口径

口径定义：

- M2：计入的小节 j ≥ 16（规格原文）；
- M2b：j ≥ d + 4；
- M2c：j ≥ d（从第一个 drop 起）。

d 是第一个标为 drop 的小节，不含交界小节，真正的第一个 drop 小节多半是 d − 1。每种口径都是「逐首中位 → 各首的中位 / P90 / 最大」，另给全部小节合在一起的分布。

| 口径 | HEAD 4/4 型 | 5a67051 4/4 型 | HEAD 响度型 |
|---|---|---|---|
| M2 j ≥ 16 | 0.23 / 0.79 / 2.47 **达标** | 0.32 / 1.57 / 2.65 不达标 | 0.54 / 1.41 / 3.27 不达标 |
| 　全部小节合在一起 | 0.25 / **1.06** / 10.11 | 0.32 / 2.04 / 10.19 | 0.50 / 2.09 / 10.19 |
| M2b j ≥ d + 4 | 0.23 / 0.73 / 1.28 **达标** | 0.31 / 1.46 / 2.47 不达标 | 0.51 / 1.18 / 2.89 不达标 |
| 　全部小节合在一起 | 0.23 / 0.80 / 7.79 | 0.30 / 1.53 / 8.20 | 0.46 / 1.51 / 8.30 |
| M2c j ≥ d | 0.23 / 0.73 / 1.47 **达标** | 0.32 / 1.47 / 2.47 不达标 | 0.54 / 1.21 / 2.98 不达标 |
| 　全部小节合在一起 | 0.23 / 0.86 / 8.00 | 0.30 / 1.63 / 9.02 | 0.47 / 1.66 / 9.02 |

- **HEAD 下三种口径按逐首汇总都达标**。只有改成「全部小节合在一起」时，j ≥ 16 的 P90（1.06）过不了。
- **差在前奏长的歌**：38 首里 27 首的第一个 drop 在第 16 小节之后。
  - 这 27 首：M2 0.24 / 0.85 / 2.47，M2b 0.23 / 0.79 / 1.28；d ≤ 16 的 11 首：M2 0.21 / 0.38 / 0.79。
  - 逐首中位对前奏不敏感，只要前奏不到第 16 小节起计入小节的一半。
  - 最突出的是 tech 0200569（d = 59）：2.47 / 1.28 / 1.47，第 16 小节起的 64 个计入小节里 41 个是前奏，前奏比 drop 轻约 2 LU 且被当主段；其次 deep 1086373（0.80 / 0.70 / 0.71）。

证据：`P1R/replay/*-m2-variants.csv`、`extra.md`。

### 7.3 第 3 条为什么做不到：δ4 拆两半

- δ4 = I_{d+3} − I_end = (I_{d+3} − D4)「跟踪误差」+ (D4 − I_end)「歌自己变了」。
- D4 = 第 d … d+3 小节（标为 drop、已听）的输入段响度能量平均，与 D 同口径。
- 后一半是第一个 drop 之后歌自己变了多少：最终值由后面的 drop 决定，第 d + 3 小节时任何只看已播部分的估计都还没听到。

| 标签 | 第 3 条达标 | \|D4 − I_end\| ≤ 1 的首数（跟准第一个 drop 就够） | 跟踪误差 \|I_{d+3} − D4\| | 不达标里：跟踪误差 > 1 / 只因歌自己变了 |
|---|---|---|---|---|
| HEAD 4/4 型 | 21 / 38 | 24 / 38 | 0.40 / 1.76 / 2.80 | 7 / 10 |
| 5a67051 4/4 型 | 13 / 38 | 26 / 38 | 1.19 / 2.75 / 3.29 | 18 / 7 |
| HEAD 响度型 | 13 / 38 | 25 / 38 | 1.50 / 3.06 / 4.15 | 18 / 7 |

- **14 / 38 首**第一个 drop 头 4 小节就离最终 I 超过 1 LU；12 首的 D4 比全曲 drop 的 D 轻 1 LU 以上（第一个 drop 往往没开满，或后面的 drop 更大）。按现在的写法，第 3 条在这些歌上任何因果估计都做不到。
- **HEAD 不达标的 17 首**：
  - 跟踪误差 > 1 的 7 首：tech 0268597、0331159、0343381、0200569，melodic 0921855、1062232，deep 0155328。原因是前奏比 drop 轻得不到 ΔG，或低音重的前奏定住了 lowRef。
  - 其余 10 首只因歌自己变了：melodic 1033705、1118385、0647576、0560109、1034807、1122111，deep 1089928（标签）、0769505、1086373、0728914。
- **改用「跟踪误差 ≤ 1 LU」的口径**：HEAD 28 / 38、改前 17 / 38。

证据：`P1R/replay/*-m4-split.csv`。

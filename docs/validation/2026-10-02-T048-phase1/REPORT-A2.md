### 2.2 每一份画像怎么算（带遗忘的离线门控）

记号：e = 段的有效时长；「比 i 新」= 窗口里排在第 i 段之后的段。

1. **参考**
   - S_ref = 窗口各段段响度的 `referencePercentile` 分位（0.1 LU 一格、取格中心）。
   - 权重 r_i = e_i × ρ_i，其中 ρ_i = exp(−Σ_{j 比 i 新} e_j ÷ τ_ref − Δ参考时钟_i)。
   - lowRef = **按此刻 S_ref 算响度因子 ≥ 0.5 的段**的 lowShare 同分位，权重同上。
2. **重判**
   - 每段的 m′ 按此刻的参考、同一套软斜坡重算。
   - 冷启动不用特例：窗口只有一段时，参考就是它自己（出厂常数下 m′ = 1）。
3. **主段权重**
   - f_i = m′_i × exp(−Σ_{j 比 i 新} m′_j e_j ÷ W_mem,j − Δ主段时钟_i)。
   - M = Σ f_i e_i；c = 1 − exp(−M ÷ M0)。
4. **合并**
   - 各特征按 f 加权求和，套 House 画像那一族函数的公式；求和顺序同 House。
   - I 的两遍门限都逐块做。4/4 型用 f；响度型 / 被动型用全部段权重 a_i = exp(−Σ_{j 比 i 新} e_j ÷ W_mem,j − Δ参考时钟_i)。
   - LRA 照旧按曲风分口径：4/4 型用 f，响度型 / 被动型用 ρ。

**主段时钟为什么按此刻重判的 m′ 推**（任务书交我定）：

- breakdown 的段 m′ = 0，不推时钟、也不进任何和。只要参考格不变，画像、M、c 都与 breakdown 之前**逐位相同**（用例 b 逐份核对）。
- 被重判出局的前奏不再推时钟。
  - 若改按进账时的 m 推：前奏进账时（m = 1）推过的时钟收不回来；
  - 进账时被低频门挡掉、后来重判成主段的 drop 也推不动时钟。
- 按 m′ 推，权重就是窗口的纯函数：存档只存段与印记，读回重算逐位相同。

### 2.3 进账判断与事件

- **进账判断**：一段进账时，先按**上一份已发布画像的参考**算一次 m（冷启动以自己为参考）。
  - 长时间无主段只看它；换歌看「段响度 − 上一份的 I」与它的低频因子。
  - 不用这一份的 m′，是因为事件要在算这一份的参考之前定下，否则循环依赖。
- **事件**进两个对数时钟：
  - 换歌：主段、参考两个时钟各加 ln(1 ÷ keep)；keep = 0 时记 800。
  - 无主段：只给主段时钟加「超出的秒数 ÷ noMainDecaySeconds」。
  - 事件乘在事件之前的全部段上（触发的那一段自己不乘），之后重判不撤销。
- **换歌的票**：
  - 1 = 比 I 响 newProgramLu 以上；
  - 2 = 4/4 型轻 newProgramLu 以上、且进账低频因子 ≥ 0.5；
  - 0 = 都不是，这一串清零；
  - 3 = 读不出，不计也不清零。
- **触发**：这一串累计满 newProgramSeconds 之后，每来一段就往回量最近 newProgramSeconds 的那一截。
  - 全是票 1 → 触发（「响」的那一支不变）；
  - 有票 2 → 段响度起伏 ≤ `newProgramRangeLu` 才触发。
  - 起伏记进提交记录。
- **「响」的那一支在回看重判下基本用不上**：更响的新素材一两小节就当上 S_ref、成了主段，I 立即跟上。用例里用冻结参考把 I 钉住来考这一支的规则。

### 2.4 时间：网格、分片、发布

- **网格与分片**：网格点 = 5 ms 的整数倍（绝对样本）。每个网格点至多一片，一片按工作量估计做到 8 µs 为止。
- **发布**：第 k 段在 D_k = max(段尾 + publishDelaySeconds, D_{k−1}) 发布。
  - advanceTo 报告的时间 ≥ D_k 时，这一遍没做完就在这次调用里补完（`catchUps` 计数），然后发布、回调监听者。
- **为什么结果与块长无关**：一遍的结果只取决于窗口，分几片、几时做都一样。所以已发布的画像只取决于段序列与时间。
  - 前提：段在 D_k 之前交来。分析器定稿延迟约 0.1～0.3 s，小于 0.5 s。
- **防误用**：交来的段超过 32 段还没发布时，就地发布最早一段（`forcedPublications` 计数；内容不变）。
- **流结束**：`flush()` 把交来的段全部按序发布。
- **时间只增不减**：比上一次早或相同的 advanceTo 什么都不做。reset / prepare / 读档后，时间轴回到「不知道」。

### 2.5 老段：直接丢弃（不进「老账」）

下表是丢掉的那一截占无限记忆权重的比例（出厂常数，稳态估计；φ = 主段小节占比）：

| 域 | 丢掉的尾巴占比 |
|---|---|
| 主段（W_mem = 48 小节） | 约 exp(−10.4 φ)：φ = 1 时 3e-5；0.5 时 0.6 %；0.25 时 7 % |
| 参考（τ = 180 s） | 约 exp(−993 ÷ 180) ≈ 0.4 % |
| 全部段（τ = 90 s） | 约 1.6e-5 |

- 不做老账的理由：
  - 老账要另存一份不再回看的累计（试算直方图又是 0.58 MB）；
  - lowRef 要按此刻 S_ref 选段，老账里的段没法重判；
  - 误差与丢掉同一量级，复杂度却翻倍。
- 诊断报最老一段的份额（`oldestMainShare` / `oldestReferenceShare`）。600 段混合素材实测：1.1e-4 / 4.8e-5。

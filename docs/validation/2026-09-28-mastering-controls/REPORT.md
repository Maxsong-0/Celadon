## 音频回调性能

`tools/perf/mastering-bench.mm` 链接本轮实际 Release `libCeladon.a`；主输入与侧链使用不同预生成合成素材。GLAZE 45，刺耳自动/50、目标自动/35、抖动关闭；每组预热至少 1 秒，测量至少 8 秒，48/96/192 kHz × 32/64/512 样本，主路及参考学习各三遍。共 **54 组、787,500 次回调，0 非有限输出**。三遍全部保留，场景顺序交替，不选择最短一遍。

初版集中 FFT 在 192 kHz / 32 样本下，学习路径 p99.9 168.333 μs、最大 1139.208 μs，48,000 次中 49 次超过 166.667 μs 块预算。改为双缓冲采集与按样本分摊窗口/FFT/频段累加后，最终三遍最差 p99.9 **66.042 μs（预算 39.625%）**，144,000 次中 **19 次**越界。均值主路 12.237 μs、学习 13.750 μs，学习增量 1.513 μs，约块预算的 0.908 个百分点。

最终学习路径仍测得最大 **1383.375 μs**（192k/32）；整个矩阵最大 **2425.583 μs**（96k/32 学习）。整个矩阵学习共 33 次、主路 16 次越界。全部组的最差 p99.9 为块预算的 49.025%。这些最大值未删除，后台服务及其他应用当时存在明显 CPU 负载，但本记录不能把所有峰值归因于系统调度。

## 尚需实际使用判断的内容

真实 DAW 的侧链路由、自动化、实时播放及歌曲等响听音仍由实际使用验证。编码余量并未执行 AAC/MP3 编码检测；预听在离线导出自动关闭，实时导出前需要手动退出。参考学习需要至少 10 秒有效音频，尾段无效时可能额外收集不足一帧。

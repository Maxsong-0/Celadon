## 2. 关键设计取舍

1. **Clay 与电平方案彻底分开**（规格「响度与峰值模型不改」）：`planClay` 只看画像的 5 个标量特征 + 逐段立体声统计、GLAZE、风格权重（`ctx.sc`，与其他各项同一份 `plan.weights`）、标定快照；不看手动值、`maxGainDb`、强度 κ，也不进前向链模型。反过来 1～7 步完全不看 Clay 特征——**画像多了 Clay 特征，方案其余字段逐位不变**（测试 7 随机场景核对）。
2. **中性 = `ClayPlan{}` 逐位**：收单为 0 时 `monoHz` 保持默认 80（GlazeTypes.h 冻结注释「monoHz 在 monoAmount = 0 时无意义」）；A2 的 `resolveClayParams` 与 A6 的存取（PLAN 缺字段按 `ClayPlan{}` 读）都按同一约定，已核对。
3. **c 沿用现有口径 `trustOf`**：特征置信度 ÷ `fullConfidence`（0.8）钳到 1（与 Tone、Glue 低频风险同一口径）；无效 / 非有限值 / 置信度 0 → c = 0 → 该项中性。收单 c = 两特征较小者；低切只用 `subShareDb`；加宽只用 `highSideToMidDb`（上限也由它反推，`highCorrelation` 不是所需特征）。
4. **规格斜坡 `clayRamp`**：`clamp((x − x0) / (x1 − x0), 0, 1)`，x1 < x0 即反向（相关度 0.6 → 0、高频侧中比 −10 → −18）。现有 `ramp` 对 hi ≤ lo 当阶跃，**不能直接用**；新函数对跨度为 0 / 非有限（坏快照，或旧快照两端都读成 0）返回 0（「不需要」）。
5. **旧快照全 0 → 三项全中性的约定**（GlazeConstants.h clay* 段写明）：`clayGlazeFullAt ≤ 0` → 不自动清理（低切、收单 0）；`clayWidthMaxDb ≤ 0` → 不加宽；地板 ≤ 0 或风格目标 ≤ 地板 → 不低切；退化斜坡 → 不需要。于是旧工程（快照缺 clay* 字段）即使配上新画像，Clay 自动值也是 0（测试 9 核对）。
6. **分频点**：候选 Balance 段 0～6，从高往低找第一个「bandStereoConfidence > 0 且（S/M > −15 或 ρ < 0.3）」的段，上沿 = `BalanceModule::getBandCentreHz(b)`（标称中心）× 2^(1/6)，钳到 [clayMonoMinHz, clayMonoMaxHz]；没有 → clayMonoDefaultHz；最后再钳进 ClayModule 的 40～300 Hz。只看画像逐段统计与常数，与 GLAZE / 风格 / 置信度大小无关——收单开着时分频点不随 GLAZE 挪（测试 3、4 核对）。
7. **单调性的数值保证**：三项都是「与 g 无关的非负量 × g 的单调函数」再与「与 g 无关的上限」取小。低切的幂 `地板 · (f_t/地板)^k` 在 double 里算再回 float（powf 只保证误差、不保证单调；double 结果在相邻 k 之间的差远大于 double 误差，回 float 保序）。
8. **加宽上限在 dB 域算**：`w ≤ 10·log10(k) − 高频 S/M dB`，k = (1 − ρmin)/(1 + ρmin)（0.25 → 0.6）；极窄高频不会让 10^(dB/10) 下溢。ρmin ≥ 1 或 NaN → 0（不加宽）；ρmin ≤ −1 → 不设上限；结果与公式值取小后下限 0。**数学性质**：出厂常数下要加宽须 S/M < −10 dB，此时上限 > 7.8 dB ≫ 1.5 dB，上限碰不到；测试 5 用相关度下限 0.94 的快照让它起作用。A2 的 `allowedWidthDb` 用同一公式（A2 报告第 2 节第 3 条）。
9. **置信度封顶（makePlan）**：`limitPlanTo` 对 Clay 三项逐项取小（`reference` 那次与方案本身相同、取小是空操作；「自动且权重没锁」那次用置信度拉满后重判的权重——低置信度偏通透，通透的低切目标与加宽系数最大，与 v0.6 F-05 同理封顶）。**Clay 的 5 个特征不进「拉满」列表**：Clay 本来就随自身可信度单调，拉满只会更大、取小恒取本份，白算；加进去反而会让「只有 Clay 特征不满」的画像也去算封顶方案，把 Tone 的 −0 归成 +0，破坏第 1 条的「其余字段逐位不变」。`bandStereoConfidence` 更不能拉（没有统计的段 S/M、ρ 记 0，拉满会被当成宽段）。
10. **xmlio 加 double 的 optionalField**：5 个 ClayGuard 时间常数是 double，要「缺字段按 0 读」必须有这个重载（Reader 的 `element` 是私有的，只在 .cpp 里绕不过去；这是 xmlio 的自然扩展，字段表仍只列一次）。注意：Writer 调用时**默认值字面量类型必须与字段一致**（float 写 0.0f、double 写 0.0），混用会二义性——已在头文件注释写明；现有全部调用（含 A6 GlazeProfile.cpp 新写的 `optionalField ("clayLowCutHz", plan.clay.lowCutHz, neutralClay.lowCutHz)`）都是 float 配 float，已核对无二义性。
11. **出厂 version 6 → 7**：按头文件「调常数时 version + 1」的惯例；注释写明 7 = 加入修坯常数。

## 3. 与规格 / 任务书的偏差及理由

1. **分频点的「中心」取标称值**（40、50、63、80、100、125、160 Hz，`BalanceModule::getBandCentreHz` 公共接口），不是 Balance 划段用的精确 2^(n/3) 中心（私有）。差别最多 1.6 %（如 100 Hz 段：112.25 vs 111.36 Hz），对 2 阶高通分频点无关紧要；好处是不复制 BalanceModule 的划段公式、数字与规格表 / 界面一致。
2. **额外钳制到 ClayModule 参数范围**（低切 10～60、分频点 40～300、宽度 ≤ min(clayWidthMaxDb, 3)）与 **s_w 按 0～1 用**：出厂常数下都不起作用；只防标定改坏时出界（任务书「各项不超上限」）。
3. **退化斜坡返回 0**（不是阶跃）与 **clayGlazeFullAt ≤ 0 视为「不清理」**（不是「立即给满」）：为「旧快照缺字段按 0 读 → Clay 自动值 0」服务（任务书、GlazeConstants.h 冻结注释的要求）。
4. **低切另要求 k > 0**：门槛被标成负数的坏快照时，特征无效（k = 0）也不许开到地板频率；门槛 ≥ 0 时与规格「k ≤ clayLowCutMinK → 关」等价。
5. **Clay 特征不进 makePlan 的「拉满」列表**（第 2 节第 9 条）：规格没写这一层；取舍理由见上，性质「置信度低不比拉满时多」仍成立（测试 8 核对）。

## 4. 不确定点 / 需要其他线注意

1. **收单需要的两支在同一份数据上是冗余的**：同样 6 段的时间平均下 ρ = (1 − r)/(1 + r)（r = 侧中比线性值），出厂阈值下 S/M 一支到 −8 dB（ρ ≈ 0.73）已满，相关度一支（ρ < 0.6 才起）永远不会比它大。实现照规格两支取大；Max 标定时可知这一点（只调 S/M 阈值就够）。
2. **出厂常数下加宽相关度上限碰不到**（第 2 节第 8 条）：它是给标定改阈值时兜底的。
3. **反相保护介入而方案收单为 0 时，分频点是默认 80 Hz**（中性约定的直接结果，A2 同样这样用）。若希望保护也用逐段统计选出的分频点，要改 GlazeTypes.h 的冻结约定——不建议，只提示。
4. **依赖 A4 的口径**：`bandStereoConfidence > 0` = 这一段有立体声统计；五个标量特征的 `confidence` 为 0～1（含代表性）；`subShareDb` 为负 dB。若 A4 口径不同（例如置信度到 1 才算充分），c 的满值点会变，需要对表。
5. **ρmin 非有限时决策器与 ClayGuard 处理略有不同**（决策器 → 不加宽；A2 → 按 0 读、k = 1）：只在坏快照时出现，且决策器给 0 时保护只会更小，合起来仍是 0。可选的后续：把「ρmin → k」收成一个共享小函数，两处共用。
6. 与本线无关但看到的：A2 报告第 4 节第 1 条「端到端 100 ms 内 a = 1」可能受 A4 的 300 ms 平滑影响，需主进程裁决。

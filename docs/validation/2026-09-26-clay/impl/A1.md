## 2. 关键设计

1. **逐样本一条路径**：① L/R 各两级 RBJ 高通（Q = 0.54119610014619698 / 1.3065629648763766 取自 1/(2cos(π/8))、1/(2cos(3π/8))）→ 按 `cutMix` 选择 / 线性淡化 → M = (L+R)/2、S = (L−R)/2 → ② S 过 2 阶高通（Q = 1/√2），S' = (1−a)·S + a·HP2(S)（a = 0 / 1 取端点、不做乘法）→ ③ S' 过 2 kHz RBJ 高架（A = 10^(dB/40)，alpha = sin(w0)/2·√((A+1/A)(1/S−1)+2)，S = 1 时恒为 sin(w0)/2·√2，prepare 时算一次）→ L' = M + S''、R' = M − S'' → 旁通线性交叉淡化。系数、状态、中间量全 double；转置直接 II 型，乘积落具名变量（同 Balance / Color），频率钳在 0.45 fs 以下。
2. **平滑与网格**：六个斜坡（低切频率 / 低切输出选择 / 分频点 / a / widthDb / 旁通）都是 20 ms（`lround(0.02·fs)` 样本）。频率在对数域、a 与 widthDb 线性。斜坡值按「目标改变以来的样本数」直接算（语义同 `juce::SmoothedValue` 线性型：改后第 1 个样本已走 1 步，第 N 个样本精确落在目标），不逐样本累加——任何切块方式下同一绝对样本位置的值逐位相同。系数只在从 reset 起每 64 样本的固定网格上按平滑值重算（值没变不重算）；a、低切选择、旁通是逐样本取值。状态归零 / NaN 清洗也只在网格上做。
3. **影子运行**：三级滤波器一直在跑，**旁通时也跑**（见第 3 节偏差 1）。低切关着时截止频率停在上次开着的频率（从没开过 = 10 Hz）：再开同一频率时状态现成，只做 20 ms 输出淡化；开到别的频率时频率同时在对数域滑 20 ms。
4. **逐位直通**：某样本上「低切选择在干路（cutMix = 0）、a = 0、高架系数逐位直通（widthDb 精确为 0 → A = 1 不经 pow，b == a 逐位，推导同 ColorModule::designShelf）且状态为 0」→ 该样本**逐位取输入**（M/S 来回一趟在 double 里不保证逐位还原 L）。高架直通且状态为 0 时直接取 S'、不跑滤波器（对有限样本数值相同；±Inf 也不会把它的状态弄成 NaN，直通不会被一个坏样本打断到下一个网格点）。段首判定整段都如此（或完全旁通且静止）时，只推进影子滤波器、**不取写指针、不写回**——与逐样本路径逐位等价，所以这个捷径不破坏块长无关。
5. **高架余振归零**：widthDb 回到 0 后系数直通，余振按极点（48 kHz 半径约 0.83 / 样本）衰减，但有信号时舍入可能让它在信号 ulp 量级徘徊；系数直通时归零门槛放宽到 1e-10（同 Balance 的 `zeroGainStateSnapThreshold`），拧回 0 后几毫秒就恢复逐位直通。其他状态门槛 1e-30（防非正规数）。
6. **NaN 自愈**：网格点上发现任一级状态非有限就整级清零（影子滤波器吃了 NaN 不会永远卡住；链的 NaN 保护照样整链 reset，A7 已在 `reset` 与 `restartWithFadeIn` 里都调 `clay.reset()`）。
7. **标量实现，不做 NEON 打包**：测试服务器是 x86_64，打包路径在那里既编不到也测不到；每立体声样本 6 次双二阶（高架空闲时 5 次），标量估算约 15～20 个周期 / 样本，48 kHz 下约 0.03 % 单核，远在 0.15 pp 预算内。两声道走同一串表达式，左右互换对称、L = R 两路逐位相同不依赖乘加融合方式。
8. **0 分配**：没有任何暂存区（干路就是当前样本的输入），process 只按 64 样本网格切段，所以样本数超过 prepare 块长也照常；prepare 也不分配（全是定长成员）。

## 3. 与规格的偏差 / 解释（请审核确认）

1. **旁通时滤波器照跑**（规格第 4 节写「未旁通时一直在跑」）：任务书明确要求更保守——解除旁通时低切高通同样没有起跳。用例 11 验证解除旁通 20 ms 后与从未旁通的模块逐位相同。
2. **「静止」不含频率平滑**：头文件文件头与 `isPassThrough()` 注释写「平滑与淡化都已静止」。实现里只看影响输出的量：某级不作用时它的频率怎么滑都不影响输出（例如 a = 0 时 monoHz 变化，A2 的 resolveClayParams 也有意在比例为 0 时固定交 80 Hz），不打破逐位直通。A7 的链测试也按这个口径写（A7 报告第 57 行）。
3. **`isPassThrough()` 按头文件定义**：三项为 0 且静止、未在旁通淡化；**完全旁通但三项非 0 时返回 false**（虽然此时输出也逐位等于输入、process 也不写回）。单声道模块（prepare 1 声道）只看 ①（② ③ 对单声道不存在）。
4. **三级都不作用时旁通淡化也逐位取输入**：处理后 = 输入时任何混合比例的结果本来就是输入；这样 GLAZE 0 下宿主旁通来回切，Clay 输出始终逐位不变（用例 11(d)）。
5. **参数清洗**：低切 ≤ 0 或非有限 → 关；0 < lowCutHz < 10 → 10 Hz（头文件「否则钳到 10～60」）；a、widthDb 非有限 → 0；**monoHz 非有限 → 保持原值**（没有「中性」频率可回退，它只在 a > 0 时起作用）。
6. **超过 2 声道**：prepare 声道数钳到 1～2，多出的声道原样不动（插件只支持 1 进 1 出与 2 进 2 出）。prepare 为立体声、某块只给 1 声道时按单声道只做 ①。

## 4. 不确定点

- 「块长一致（扫动时容差写明）」：我按「参数在同一样本位置改变时任何块长逐位相同（容差 0）」测（用例 9b，测试驱动在改参数的位置切块）。宿主按块自动化时块长不同、参数到达时刻本身不同，那部分差异不属模块，未设容差用例。如审核认为需要宿主式自动化的容差用例，请提出口径。
- 无咔哒用例的度量照规格：4 kHz 以上 5 ms 能量相对静止参考不突起 > 1 dB。Python 原型：各扫动约 0.001 dB；阳性对照 0.5 单样本咔哒约 +3.6 dB。这个度量对纯低频台阶（硬切低切）并不敏感（原型估算 < 1 dB），它主要抓高频爆音；低切 / 旁通的连续性另由用例 11、12 的「线性淡化包络 + 淡化后逐位」覆盖。
- 线性淡化包络检查允许一个样本的相位差（第 k 个样本的比例在 k/N 与 (k+1)/N 之间，容差 1e-6）：规格只定「20 ms 线性」，不定相位。

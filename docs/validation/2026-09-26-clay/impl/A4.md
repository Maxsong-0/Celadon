## 2. 关键设计取舍

1. **超低频（1.2）挂在起音的组网格上**：逐样本 M = (L + R) / 2（单声道 M = 该声道，与「单声道按左右相同的双声道」逐位一致；多于两个声道只取前两个），两级 RBJ 低通（double，TDF-II，`1 − cos w0` 写成 `2·sin²(w0/2)` 保 192 kHz 下的精度），本组的 Σ低通² 与 ΣM² 逐样本累加，在 `processGroup` 里与起音**同一个条件** `inside && effective` 整组计入。有效时长直接就是 `onsetEffectiveSamples`（同一批组），脏标志复用 `onsetDirty`。组网格从重启起算、与块边界无关 → 块长无关；重启时低通清零，起始瞬态落在 250 ms 预热里（最慢的极点时间常数约 14 ms）。
2. **subShareDb 取值**：E_全 = 0（R = −L）→ 无效；比值钳在 [1e-15, 1]（−150 dB ～ 0 dB，下限 = `noDataDb`，上限挡起始瞬态造成的略超 1）；有效 = 有效音频 ≥ 1 s；置信度 = min(有效秒 / 10 s, 代表性)。
3. **立体声画像（1.3）挂在 `accumulateEvidence`**：与频谱证据同一批帧（学习区间内、帧门限之上、1 s 平均已稳定）、同一逐段门权重 `gate[b]`（1 s 平均电平 −60 dBFS、门上 6 dB 淡入），累计 Σg·P、Σg·X、Σg。逐段：有统计（Σg > 0 且 ΣgP > 0）才给数，否则 0 且可信度 0；可信度 = min(Σg·hop / 10 s, 代表性)，与 `bandConfidence` 同式。组：按组内各段的和；观测 = 每帧组内最大门权重之和 × hop（组里有内容的时间）；有效 = 观测 ≥ 1 s 且功率和 > 0。
4. **封底**：S/M 的 P_M、P_S 各按 P 的 1e-12 封底 → S/M ∈ [−120, +120] dB（纯单声道读 −120，满足验收 ≤ −100）；ρ 钳 [−1, 1]；逐帧 X 先钳 [−P, P]（Balance 已钳过，读者再钳一次防舍入；非有限按 0）。
5. **实时视图（1.4）**：只在帧门限之上的帧更新（学习与否都更新；帧门限就是 `consumeFrame` 现有的 `music`，与 liveTame 同口径）；本帧只计段功率 ≥ −60 dBFS 的段（硬门）；低频组 ΣX、ΣP 与高频组 ΣP_M、ΣP_S 各做 τ = 0.3 s 的一阶功率平滑，系数 exp(−hop / fs / 0.3) 按 hop 换算，运行均值起步；帧门限下（静音）**冻结**（值与有效性都不动）；`restartSpectrum`（不连续点、丢帧、hop 变化、Balance reset）**清空并置无效**，与现有 liveTame / 斜率同一规则（A6 依赖这一点做保存重开 / 宿主 reset 的同一起点，已在其报告里核对）。
6. **实时有效性判在平滑值上**：`valid = 重启后已平滑满 300 ms（48 kHz 29 帧） && 组内平滑功率 ≥ 1e-6`。判在平滑值而不是本帧上：间歇的底鼓之间不来回翻有效性（ClayGuard 的保持期计时不被切碎）；内容停了之后比值保持最后的内容，平滑功率约 ln(P / 1e-6) × 0.3 s 后落到门下才无效（−23 dBFS 的低频约 2.6 s）。
7. **宿主旁通**：分析器不知道宿主旁通（入口照常流过），所以「宿主旁通时冻结」由 ClayGuard 的 seconds = 0 做——A6 已按 `musicActive && ! paused && hostPlaying()` 累计秒数，A2 按 seconds ≤ 0 整体冻结，三方口径一致。

## 3. 与规格的偏差及理由

1. **1.2「按有效音频门（musicActive）累计」→ 用样本流自己的有效门（起音那一份）**。`musicActive` 按 100 ms 子块判定、读到子块时才知道，直接套在样本上结果随宿主块长变（违反「分块无关」）；要逐位对齐表的子块网格，还得跟踪表的网格起点（表 reset、响度计量重开都会挪网格），复杂且脆弱。起音那一份是同一设计在样本流上的实现（400 ms 电平、绝对 −70、相对 −20，样本精确、组网格与块边界无关），也正是任务书「与现有起音包络同一套边界规则」的字面意思。差别：不加权 dBFS vs K 加权 LUFS、相对参考是学习区间平均功率而不是 I，另有重启后 250 ms 预热；对能量比的影响可以忽略（门下的段落本来能量就小）。
2. **bandStereoConfidence**：任务书写「观测充分度 10 s × 代表性」，实现按同一句里的「与现有 bandConfidence 同口径」= min(观测充分度, 代表性)（现有 bandConfidence 就是 min）。满观测、代表性 1 时两种写法都是 1；A5 的决策器只用「> 0」判断有无统计。
3. **实时视图多一个有效条件「重启后平滑满 300 ms」**（任务书只写「仅当门上有内容」，「仅当」是必要条件）：重启后头几帧只有一两帧的估计，低频组只有约 4 个 bin，单帧 ρ 的散布很大（不相关噪声约 ±0.35），会让反相保护误触发；与 liveTame「稳定 1 s 才给」同一思路，这里只等一个时间常数。
4. 「300 ms 功率平滑」按一阶时间常数 τ = 0.3 s 实现（不是 300 ms 滑动窗）。

## 4. 不确定点 / 需主进程裁决

1. **【需裁决】验收第 6 节第 5 条「歌曲中途插入 2 s 反相低频，100 ms 内 a = 1」与 1.4 的 300 ms 平滑冲突**（A2、A6 报告已提）。量化（本测试 B 段就是这个场景）：等功率由同相切到反相，ρ̃ 在窗中心越过切换点后 τ·ln2 ≈ 208 ms 过零，加半个 FFT 窗约 230 ms；插入的反相内容比原同相内容强 α 倍时过零 = τ·ln(α / (α − 1))：α = 2 → 208 ms、α = 4 → 86 ms、α = 10 → 32 ms。所以「从插入时刻起 100 ms 内 a = 1」只在反相内容压过原内容 ≥ 6 dB 时成立。可选：(a) 验收改成「实时相关度 < 0 起 100 ms 内 a = 1」或「插入后 0.4 s 内」；(b) 改规格 1.4，低频相关度单用 50 ～ 100 ms 平滑（代价：散布大，宽立体声低频上误触发多）。我按任务书与规格 1.4 实现 300 ms，未擅改。
2. 静音冻结时 `liveLowCorrelation.valid` / `liveHighValid` 保持冻结前的值（通常 true）。ClayGuard 靠 seconds = 0 冻结，不依赖它；若别的读者要「静音即无效」，需另议。
3. 测试里「S/M ≤ −100 dB」「高频 P_M 逐块衰减正好是 r」依赖 Balance 的 `bandCross` 在左右逐位相同时 = `bandPower`、R = −L 时 = −`bandPower`（逐位）。已核对 A3 当前代码（`crossPowerOfBand` 与 `measureBandPowers` 同 bin 权重、同求和顺序，两个 float 的乘积在 double 里精确，单声道直接拷贝）——成立；A3 若后续改求和方式，这几条会先报。
4. 决策器要注意：逐段没有统计时 `bandSideToMidDb = 0`、`bandCorrelation = 0`，看上去像「很宽」，必须先看 `bandStereoConfidence > 0`（A5 已这样做，并且不把它拉满）。

## 5. 可能编不过的地方（逐行自查结果）

- `-Wshadow`：新形参 / 局部变量与 `Impl` 成员、`juce::UnitTest` 成员都不重名（`makeLowpass` 的采样率形参特意叫 `rate`，避开成员 `sampleRate`；没有叫 `name` / `category` / `runner` 的局部变量）；兄弟作用域里的同名 `rig` / `p` / `k` 不构成遮蔽。
- `-Wconversion`：double → float 全部显式 `(float)`；int64 → double 显式；`size_t` 下标显式。
- 未用函数 / 常数：逐个 grep 过，全部至少一处使用。没有新增 switch。
- 嵌套结构体 `LowpassCoefficients` / `LowpassState` 定义在所有用到它们的成员声明与静态成员函数之前；它们嵌在 `Impl` 里，不在匿名命名空间，不触发 GCC 的 `-Wsubobject-linkage`。
- 测试：`juce::String tag (cond ? "true mono" : "identical stereo")` 两个字面量长度不同但都退化为 `const char*`，合法；`expectWithinAbsoluteError` 三个实参类型一致（float×3 或 double×3）；`const auto enteredSilence = view;` 是 `ShortTermView` 的拷贝。
- 风险最高的一处（仍认为合法）：`static_assert (... highStereoLastBand == numBands - 1, "中文消息")` 放在匿名命名空间里——文件里已有同样写法的 `static_assert`。

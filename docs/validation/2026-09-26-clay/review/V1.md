### V1-01 · high · 「快降慢升」的 60 ms 快路在长期相关度明显为正的常见素材上误触发反相保护（阶段 2 引入）

- 文件：`Source/dsp/MusicAnalyzer.cpp:218`（`liveFastLowSeconds = 0.06`）、`:1578-1579`（对外取快慢两路较小者）；触发在 `Source/dsp/ClayGuard.cpp:153`。

### V1-02 · low · 决策器 c 的口径与规格字面不同（trustOf：置信度 ÷ 0.8 再钳 1）

- 文件：`Source/dsp/GlazePlanner.cpp:1049`（`trustOf`）、`:1161 / :1176-1177 / :1192`（planClay 三项）。
- 现象：规格 §2 记号「c = 对应特征的置信度（沿用分析器口径 = min(观测充分度, 代表性)）」；实现用现有 `trustOf` = clamp01(confidence / fullConfidence)，fullConfidence 出厂 0.8：置信度 0.4 → c 0.5，0.8 起就算满。所以 8 s 观测（充分度 0.8）就给满量自动值，而不是 10 s。
- 证据：代码阅读；`GlazePlannerTests::testClayFormulas` 自己就按 0.4 → 0.5、0.8 = 满断言（已过），A5 报告 §2 第 3 条声明了这一取舍。
- 建议：这与 Tone / Glue 等特征同口径，不算缺陷；在规格 §2 的记号里补一句「c = trustOf（到 fullConfidence 算满）」即可，标定时知悉满值点是 8 s 观测。

### V1-03 · low（未坐实）· 实时立体声视图的冻结门与 ClayGuard 时钟的门不是同一个

- 文件：`Source/dsp/MusicAnalyzer.cpp:1247`（视图按帧门 `music` 更新：总功率 −70 dBFS 绝对门 + 学习中相对门）、`:820`（`musicActive`：100 ms K 加权子块，绝对 −70 LUFS + 学习后相对已学 I −20 LU）、`Source/dsp/GlazeController.cpp:2186`（ClayGuard 只在 `musicActive` 时推进秒数）。
- 现象：两个门口径不同（不加权总功率 vs K 加权；帧 vs 100 ms 子块；学习后相对门只有子块那边有）。淡出、间奏边缘可能出现「视图已冻结（保持最后一帧的 ρ 与 valid = true）但保护时钟仍在走」——保护按一份过期的 ρ 继续攻击 / 消耗保持期；或反过来视图在更新、时钟停了。A4 报告 §4 第 2 条也指出「静音冻结时 valid 保持冻结前的值」。
- 证据：只做了代码阅读，没有构造出可听后果，故为 low / 未坐实。
- 建议：若要一处真源，让分析器在帧门下把 `liveLowCorrelation.valid`（或一个 `liveStereoFrozen` 标志）置为「不可用」，ClayGuard 现有的「视图无效 → 该路冻结」就自动对齐；或在编排器里用帧门那一份 `music` 推进 Clay 的秒数。不改也不违反规格。

### V1-04 · low · 设计性质提示：拍频 / 失谐的立体声低音在任何口径下都会被保护长期收单

- 文件：规格 §3（触发条件 `liveLowCorrelation` < 0）、`Source/dsp/ClayGuard.cpp:153`。
- 现象与证据（`ReviewV1Analyzer`）：单声道低音 + 左右失谐 0.5 Hz 的低音（P_d / P_c = 1.0，理论 ρ(t) 最低 0、从不为负），实测长期 ρ 0.50，300 ms 慢路的 ρ̃ 仍有 22.6 % 的帧 < 0（最低 −0.22；单帧内共同分量与失谐分量的交叉项让瞬时 ρ 过零），ClayGuard 在 30 s 里 94.7 % 的时间 a ≥ 0.5（P_d / P_c = 1.5 时 95.2 %）；快路只把占比再提高 1 个百分点。ρ 0.3 的独立噪声素材也是任何口径都间歇触发（慢路 10 %）。
- 说明：这是规格触发条件本身的性质，不是实现偏差——「故意做宽的低音」正是 ADR-009 给三态「关」的理由，但默认是「自动」。建议写进版本档 / 帮助文案（自动态下拍频式宽低音会被收到分频点以下单声道，想保留请把「单」设「关」），或标定时考虑阈值略负（如 −0.1）加最短持续帧数；不在本版硬改。

## 已核对无问题的项（都有测试或数值证据）

- **Balance 加交叉功率前后 G 与输出逐位不变**（验收 §6 第 1 条 Balance 部分）：`ReviewV1Balance` 把 v0.1.6.2 的 `BalanceModule.cpp` 与新版编进同一个测试程序，44.1 / 48 / 96 kHz × 立体声 / 单声道 × 拆片开 / 关 × 块长 512 / 随机 1～1500 / 4096 共 36 组、每组 3 s 富信号（Recover / Tame / Brighten / 自动份额都在动，|G| 最大 2.5～5.2 dB）：输出、每块 27 段 G、每帧 `bandPower` / `bandPowerDb` / `endSample` 全部逐位相同（36 × 3 条断言 0 失败）。A3 只留了摘要日志，这里补上真正的旧新对照。
- **`crossPowerOfBand` 口径**：与 `measureBandPowers` 同 bin 表、同权重、同求和顺序；float × float 在 double 里精确，所以左右相同时 X == P 逐位、反相时 X == −P 逐位（A3 / A4 的紧断言依赖此，round 5 已过）；钳 [−P, P] 保证 P_M、P_S ≥ 0；单声道 / 立体声 prepare 只送 1 声道时直接拷 bandPower。
- **ClayModule 滤波器设计**：RBJ 高通 / 高架公式逐项核对（b0 + b1 + b2 = 0 精确，直流被精确阻断）；Q 0.54119610 / 1.30656296 = 1/(2cos π/8)、1/(2cos 3π/8)；S = 1 时 α = sin(w0)/2·√2；A = 1 时高架系数 b == a 逐位直通的推导成立。`ReviewV1Clay` 实测 25 Hz 低切在 12.5 / 6.25 / 18 / 50 Hz 的增益与 4 阶 Butterworth 解析值（双线性）差 < 0.001 dB（−24.099 / −48.165 / −11.716 / −0.017 dB）；a = 0.5 时 2 fc 处侧声道 −0.766 dB（规格「约 −0.8」），60 / 120 / 160 Hz 三个分频点都与解析值一致。
- **逐位直通**：三项为 0 时不取写指针、不写回，与逐样本路径逐位等价；`ReviewV1Clay` 补测 44.1 / 96 kHz、块长 1 / 333 / 4096 下三级全开 → 全关后 100 ms 内逐位 = 输入且 `isPassThrough()`；加宽 +1.5 dB → 0（其余关）后最后一个不同样本在 21.1～21.5 ms（48 k / 192 k、−18 / −60 dBFS 粉噪），即 20 ms 斜坡 + 约 1.5 ms 余振，识别系数与状态归零门槛（1e-10）工作正常。旁通 + 三级为 0 也逐位取输入（ClayTests 11(d)）。
- **块长无关**：斜坡按「目标改变以来的样本数」直接算、系数在 reset 起每 64 样本的绝对网格重算；`ReviewV1Clay` 在 8 次参数改动落在奇数样本位置（含旁通来回、全 0、各级开关）下 1 / 64 / 512 / 4096 块长逐位相同。
- **无咔哒**：分频点 80 → 160 Hz 与 a 0 → 1 同时变（resolveClayParams 在比例离开 0 时把分频点从 80 交到方案值的真实情形）、三级同开 / 同关：4 kHz 以上 5 ms 能量相对静止参考最坏 +0.001 dB（ClayTests 的阳性对照 0.5 单样本咔哒 > 1 dB 已证明度量灵敏）。
- **M/S 编解码**：M = (L+R)/2、S = (L−R)/2、L' = M + S''、R' = M − S''；纯 M 输入 S 精确为 0（不经 pow 的直通、零状态）；单声道模块只做①，与立体声 L = R 同一串运算（ClayTests 7）。
- **参数清洗与非有限值**：低切 ≤ 0 / 非有限 → 关，0 < f < 10 → 10；a、widthDb 非有限 → 0；影子滤波器吃到 NaN 在下一个网格点整级清零（ClayTests 16）。实时安全：process 无分配、无锁、无系统调用（ClayTests 15、ClayGuardTests 17、MusicAnalyzerClay 无分配用例，round 5 已过）。
- **ClayGuard**：攻击 = phaseFloor 以 1/0.1 s 线性升、保持 2 s 从条件最后成立的块末起算、同一块跨过保持期末尾只用剩余时间释放（块长无关）；宽度上限 w_allow = 10·log10(k·P_M/P_S)、k = (1−ρmin)/(1+ρmin)（0.25 → 0.6）与决策器共用 `clayWidthPowerScale`，下限 0（从不收窄），P_S = 0 → 不限；只增 mono、只减 width、lowCutHz / monoHz 原样；seconds ≤ 0 / 视图无效分路冻结；active = false 回中性。`ReviewV1Analyzer` 里全反相参照 98.7 % 时间 a ≥ 0.5、全同相 0 次触发，与单元测试一致。
- **resolveClayParams 三态**：自动（GLAZE ≤ 0 / NaN 取中性）/ 关 / 手动（GLAZE 0 也生效，手动收单 = 分频点以下全收）；比例 0 时分频点固定 80 Hz，避免用不上的 monoHz 打破模块静止（与 ClayModule 的「频率平滑不计入静止」互为保险）。
- **决策器 planClay**：① k = ramp(subShareDb, −30, −18)·c·min(1, 2g)，lowCutHz = 10·(f_t/10)^k，k ≤ 0.001 → 关；② need = max(ramp(S/M, −20, −8), ramp(ρ, 0.6, 0))，分频点取 40～160 Hz 里最高的宽段上沿（中心 × 2^(1/6)，钳 [60, 160]，无则 80）；③ 1.5·ramp(S/M, −10, −18)·c·s_w·g 与 10·log10(0.6) − S/M 取小、钳 [0, 1.5]——公式逐项与规格 §2 一致；g = 0 / 无画像 / 特征无效 → ClayPlan{}；随 g 单调（低切的幂在 double 里算再回 float）；limitPlanTo 对三项取小、收单为 0 时分频点回 80；旧快照 clay* 缺字段按 0 读 → 三项中性；风格常数 20 / 25 / 28 Hz、0.4 / 0.6 / 1.0 按方案权重线性混合。GlazePlannerTests 的 14.1421 / 15.8114 / 16.7332 Hz 等期望值手算复核无误（含主进程改正的 16.733201）。
- **分析器口径**：立体声画像与频谱证据同一批帧（学习区间内、帧门上、1 s 平均稳定后）、同一逐段门权重；组特征按组内功率和，有效 ≥ 1 s、10 s 充分、置信度 = min(充分度, 代表性)，逐段可信度同 bandConfidence；S/M 的 P_M / P_S 按 P 的 1e-12 封底（纯单声道 −120 dB）；超低频用 M 过两级 RBJ 低通（1 − cos 写成 2 sin²，192 kHz 不丢精度）挂在起音的组网格上、与起音同一有效门、同一学习边界，块长无关；`formatVersion` 默认 2、旧画像格式 1 读入后新字段无效。低频组 = 段 0～5（40～125 Hz）、高频组 = 段 17～26（2～16 kHz）与规格一致。
- **`clayWidthPowerScale`**：ρmin ≥ 1 / NaN → 0，≤ −1 → +∞，否则 (1−ρ)/(1+ρ)；决策器与 ClayGuard 同一处。
- **规格 vs 实现的已声明偏差**（A1 / A2 / A4 / A5 报告）逐条核过，都更保守或等价：旁通时影子滤波器照跑；「静止」不含频率平滑；比例 0 时分频点交 80 Hz；视图无效分路冻结；超低频有效门用样本流那一份而非子块 musicActive；退化斜坡 / 全 0 常数按「不需要」。

## 2. 关键取舍

1. **资格期不存档**（任务书许可的做法）：`ClayGuardState` 已冻结且随执行快照保存，资格期计时放在 ClayGuard 自己的私有成员里，
   `setState` / `reset` 后从 0 起算。后果只有一条：恢复时若反相正在持续，要再连续 0.15 s 才重新把保持期拉满；下限与剩余保持期照快照
   接着走（保持期 2 s ≫ 0.15 s），输出不变；实时 / 离线、保存重开 / 宿主 reset 都从同一起点，逐位可复现不受影响。不提接口变更请求。
2. **资格期里按「未触发」走**：保持期照耗、释放照走；满资格才重置保持期、开始（或从当前下限继续）攻击。所以保持期里 < 0.15 s 的瞬态
   不会把保持期续满（「去掉瞬态」同样适用于再触发）。
3. **冻结时资格期保持、不清零**：慢路无效（静音 / 帧门下 / 刚重启）或 seconds ≤ 0 时整路不动——「连续」按有效音频算，静音既不算打断
   也不算成立；与分析器「帧门下两路标无效」、保护时钟冻结同一口径（审核 V1-03）。
4. **快路无效 = 没有加速证据**：只按慢路那一支判定，不冻结（慢路是有效的，判断得了）。
5. **Status mask 在编排器里就按三态过滤**（任务书口径），界面 `clayReadoutFor` 再按它读到的三态滤一遍（两边一致，P3 报告说界面滤过
   即可，重复无害）。
6. **气泡代价说明的两处细化**（规格只给了单一动作的模板）：
   - 同时有「跳过」与「减量」时写「本曲试过：收单、加宽会抬高峰值，已自动跳过收单，减量加宽」；单一动作时就是规格模板原文。
   - **该项保护介入时不写该项的代价**：反相保护会把被代价否决的收单拉到 100 %，第 2 行写「反相保护中」，第 3 行再写「已自动跳过收单」
     就自相矛盾；宽度保护同理。「跳过 / 减量」按量化读数判（显示 1 % 的收单算减量，与灯亮一致）。
7. **mask 在过渡两端逐位原样**：`blendClayPlans` 的 t ≤ 0 / ≥ 1 分支原样返回 from / to（含各自的 mask），0 < t < 1 取 to 的。

## 3. 与规格的偏差及理由（请主进程裁决第 1 条）

1. **根治修订 4(c)「整体反相低频 → 从音频起 250 ms 内 a = 1」与 3.4 自相矛盾，无法实现**：3.4 规定条件须连续成立 0.15 s 才开始攻击、
   攻击 0.1 s——**从条件成立起就已经用满 0.25 s**；条件本身还要等分析窗（2048 点 = 42.7 ms + hop + 发布）与慢 / 快路平滑。109 上按同一
   分析口径（2048 点 Hann、hop 512、同一 27 段权重、300 ms / 120 ms 一阶平滑、运行均值起步、按块推进的保护）复算：
   | 场景 | 条件成立 | a = 1 |
   |---|---|---|
   | 右声道底鼓 + 贝斯整体反相（等功率），反相落在拍点 | 48 ms | 293 ms |
   | 同上，反相落在拍后 130 / 290 ms（底鼓已衰减，要等下一拍） | 302 / 259 ms | 547 / 505 ms |
   | 用例 4 的 25 倍功率 50 Hz 纯 S 段 | 37 ～ 57 ms | 283 ～ 302 ms |
   即使去掉资格期，等功率翻转在慢路门内那一支也要约 129 ms + 分析 55 ms + 攻击 100 ms ≈ 0.28 s。我按 3.4 与 ADR-012 第 3 条实现，
   测试这样写：ClayGuardTests「资格期 d」直接量**从判定起 0.25 s 到 1**（0.24 s 时 0.9、0.25 s 时 1）；ClayGlazeTests 用例 11 量整链
   **从反相音频起**，断言 ≤ 推导上限（资格期 + 攻击 + 分析滞后 + 5 ms 过渡 + 稳态平滑时间 129 ms + 4 块 ≈ 0.48 s）且 ≥ 0.25 s，并把实测
   记日志。可选的改法：(a) 把 4(c) 改口径为「从判定起 250 ms」（与旧版验收第 5 条「判定起 100 ms / 音频起 250 ms」同一种拆法），整链另给
   推导上限；(b) 缩短 `clayGuardPhaseMinSeconds`（常数，改一个数即可；代价是瞬态更容易触发）。
2. **气泡代价说明**：见第 2 节第 6 条（混合情形的措辞、保护介入时不写）。
3. **「GLAZE 0 且抽屉默认：整链输出与改动前平移 D 逐位相同」**：P1 报告第 3 节第 1 条指出 Glue / 限幅器的自适应释放在从 reset 起每 32
   样本的网格上按信号重算，D = 574 ≢ 0 (mod 32)，Color / Limit 在工作时字面平移不成立。ClayGlazeTests 用例 1 因此改成两条：①忙碌设置
   下整链 = 「旧三模块链在 Clay 的位置插一段 D 样本 float 纯延迟」逐位相同（Clay 的真实契约）；② Color / Limit 不动作（Balance 照样工作、
   素材压低 6 dB 让限幅器不动作）时 = 旧链输出平移 D 逐位相同。

## 4. 不确定点

1. 集成测试的阈值依赖 P2 分析器的实现细节（P99 线性插值、0.25 s 预热、候选按各自延迟对齐、有效块满 10 s）。我按规格与已读到的 P2 代码
   注释用 numpy 复算、留了余量（第 6 节）；若 P2 最终口径不同，先看用例 2 / 9 / 12 日志里打印的代价。
2. 用例 12（次声 + 音乐）比「限幅器入口峰值」（每块 GR − 实际 Limit Gain 的最大值）而不是原始 GR：两条链各自校准、保护层按各自 GR 退让，
   Limit Gain 可能不同，原始 GR 会被自适应搅浑；入口峰值口径把增益差扣掉。原始 GR 记日志。用例 9（已限幅底鼓）照规格比原始 GR：那里自动与
   全关几乎一样（低切被否决、收单不需要、加宽只作用在几乎为 0 的高频侧声道），自适应不会分叉。
3. 用例 10 从第一块起计数（含 2 ～ 3 s 聆听期），素材不循环 31 s。
4. 聆听时长：`confidentConstants` 从 10 s 改 12 s——代价要有效块满 10 s，候选先预热 0.25 s，只听 10 s 时代价差一点不够、三项全中性。
5. 用例 11 的反相放在「下一个拍点」起（确定性）；落在拍间时实测会慢到 0.5 s 以上（第 3 节表），那是条件要等下一拍的底鼓，不是保护慢。

## 7. 可能编不过的地方（逐行自查过，剩余风险）

   返回类型按成员上下文做访问检查，合法。

   两边同型。

## 2. 决策器（根治修订 3.3）落地口径

- **代价系数** `f = clamp01((代价 − clayCostZeroDb) / (clayCostFullDb − clayCostZeroDb))`：出厂 0.1 dB → 1、0.4 → 0.5、0.8 → 0；0.2 dB 正好 1（x/x 精确），0.6 dB 正好 0；负代价（峰值变低）→ 1。
- **低切**：`k = ramp(subShareDb, −40, −28) · c · min(1, g / 0.5) · f(lowCutPeakCostDb)`，其余照旧（地板 10 Hz、门槛 0.001、`10·(f_t/10)^k`）。
- **收单**：`need = ramp(monoLossDb, −0.5, −3.0)`，`monoLossDb = 10·log10((1 + ρ)/2)` 在 double 里算；ρ ≤ −1 → −∞ → 给满，ρ 非有限 → NaN → 0。`c = trust(lowCorrelation)`（低频 S/M 不再参与）。分频点照旧（`monoCrossoverHz`）。代价 = `monoPeakCostDb` 在分频点的 ln(频率) 线性插值；`monoAmount = need · c · 强度 · f`。
- **加宽**：原公式（含相关度上限与 [0, 1.5] 钳制）算完后 `× f(widthPeakCostDb)`。
- **costLimitedMask**：某项「代价之前就会动作」且 f < 1 → 置位（减量与否决都置）。低切的「会动作」= k 过门槛且风格目标高于地板；收单 = need·c·强度 > 0；加宽 = 原公式 > 0。
- **中性**：GLAZE ≤ 0 / 无画像 / 需要度特征无效或不可信 / 代价用不了 → 该项中性且不置位。
- 单调：f 只看画像与常数、与 g 无关，三项仍随 GLAZE 单调不减；f = 1 时乘 1 精确，与不乘 f 逐位相同。
- 0 分配：只加定长算术与几次 log / pow。

## 3. 关键取舍（任务书让自定的地方）

1. **「代价无效 → 该项中性」按「该项的值中性」理解**（不是「f 当 1」）：与「所用两点任一无效 → 收单中性」同一口径，也符合「先试后用」——没试过就不用。这种情况**不置位**（位的意思是「试过、会抬高峰值」，界面那句话不能在没试过时说）。
2. **代价常数退化**：只认真正的反向斜坡（两端有限且 `ZeroDb > FullDb`）。旧快照读成 0 / 0、两端颠倒、非有限 → 返回「判断不了」，按代价无效处理（中性、不置位）。理由：v0.1.6.2 快照本来 Clay 全中性；v0.1.7.0 开发期快照有旧口径的 clay* 却没有代价常数，照做就会按旧口径次声占比去低切，正是要根治的「帮倒忙」。两端颠倒会变成「代价越大越照做」，同样拒绝。
3. **收单插值只用权重 > 0 的点**：分频点正好落在候选点上（默认 80 Hz、钳到 60 / 160 Hz 两端）只用那一点，否则用相邻两点。没参与插值的点无效或是 NaN 不影响结果，也不会让 NaN × 0 污染结果。
4. **代价的置信度不参与**，只看 valid + 有限：分析器满 10 s 有效块才给 valid，需要度一侧已经按置信度收紧。
5. **`limitPlanTo` 的代价位取与**：两份方案的代价与分频点相同，所以 f 相同。位不一样只可能是某一份「代价之前就不动作」，取小后那项正是被它压成 0 的，原因不是代价。
6. **常数快照版本仍为 7**：ADR-012 的改动在 v0.1.7.0 发布前，与「算法 7 / 画像格式 2 不升号」同一口径。开发期快照靠第 2 条自然中性，不靠版本号区分。
7. **画像格式 2 的代价字段严格读**（缺一个整份拒收），与格式 2 现有规则一致；规格说「不涉及已发布存档的兼容」。后果见第 7 节第 5 条。
8. **位掩码的存取**：方案（CommittedState 的 PLAN）读回不校验位，保证原样往返；执行快照沿用它「取值越界整份拒收」的做法，只许三个已定义的位。
9. `xmlio` 加 `std::uint8_t` 重载（`GlazeConstants.h` 归我）。已核对重载决议：现有 float / double / int / bool / uint32 / Style 调用都是精确匹配，不会歧义；新调用传的都是 `std::uint8_t` 左值。

## 4. 与规格的偏差及理由

- 规格「所用两个点」→ 实现「权重 > 0 的点」（第 3 节第 3 条）：落在候选点上时插值只用到一点，结果完全相同，只是不因另一个用不到的点无效就否决。
- 规格没定义常数退化与颠倒的情况 → 按「判断不了 = 中性、不置位」处理（第 3 节第 2 条）。
- 规格「因代价被减量或否决」→ 代价无效（没试过）不算，不置位（第 3 节第 1 条）。

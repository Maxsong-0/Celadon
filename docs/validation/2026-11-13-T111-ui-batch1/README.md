## 3. 橙色规则（4-06）

同一时刻只有**一件事**用橙色；同一件事可以在源头和顶部胶囊两处亮。谁拿到橙色由 `glazestatus::attentionOwner` 决定，先后与胶囊一致：

异常音频块（NaN / Inf）> 真峰值超过上限（3 s 内）> GLAZE 受限 / 受手动 / 导出冷启动 > CLAY 守护灯 > 旧工程提示

- 没拿到橙色的：GLAZE 阶段标签变灰；CLAY 守护灯按「在处理」的颜色画；旧工程提示用常规灰字；右侧板最大真峰值不写橙字；OUT 表 GR 段与 LIMIT 限幅衰减只在 GLAZE 受限拿着橙色时染橙。
- 听原声、试听差值、归一化预听是**模式**，不是问题：深色圆点、深色按钮，不用橙。
- 例外（写进规格）：频谱图例的橙色块（它是图例本身）、右侧板历史里过去的守护刻度（过去的记录）、设置里「超出屏幕」（用户自己打开的那个设置）。

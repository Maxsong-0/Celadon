一、本机编截图工具的前提
  本机缺 libxext-dev / libxcursor-dev / libxi-dev 的头文件（X11/extensions/XShm.h、X11/Xcursor/Xcursor.h、X11/extensions/XInput2.h），
  ~/.cache/celadon-spark/guidev 里只解了 freetype / fontconfig / x11。所以这里一律用
    CELADON_CXX_FLAGS="-DJUCE_USE_XSHM=0 -DJUCE_USE_XCURSOR=0 -DJUCE_USE_XINPUT=0" spark-test.sh <树> build celadon_ui_snapshot
  三项只影响 JUCE 的 X11 窗口层（共享内存贴图、ARGB 光标、XInput2 多点触控）；离屏出图与直接发给控件的鼠标事件不经过它们，
  改前改后都用同一套开关编，对照公平。运行：xvfb-run -a -s "-screen 0 1280x1024x24"，HOME 指到代理自己的临时目录（不碰 ~/.config/Celadon）。
  main 基线（同一套开关）：--only check 85 条全过。

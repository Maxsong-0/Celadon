## 口径

- **原始输入**：读入后立体声化（单声道复制成双声道、多声道取前两个）的原曲，用同一套量法，作对照。
- **LUFS（对齐前）**：插件自己的 BS.1770-4 表（`celadon::LoudnessMeter`，与界面 OUT 表同一算法）量整段成品（已去掉链延迟、含 0.3 s 余振）。
- **对齐增益**：`--match-lufs` − 对齐前 LUFS；成品只乘这一个增益，不再限幅。
- **真峰值**：插件的 8× 真峰值检测器（与限幅器、表同一算法），对齐前；默认 Ceiling 下应 ≤ -1.0 dBTP（验收口径容差 +0.01 dB）。
- **PLR**：真峰值 − 整体响度（与对齐增益无关）。
- **限幅 GR 平均 / 最大**：第二遍每个宿主块读一次 `getAndResetLimitGainReductionDb()`（块内最大压缩量）；平均 = 各块读数按块长加权（是「块峰值」的平均，比逐样本平均偏高；静音段计 0），最大 = 全曲最大。
- **低频相关度 < 125 Hz**：左右各过 4 阶 Butterworth 125 Hz 低通后 ρ = 2ΣLR / (ΣL² + ΣR²) = (P_M − P_S) / (P_M + P_S)，与分析器 lowCorrelation 同一口径：1 = 单声道，0 = 不相关，−1 = 反相；左右电平不等时比皮尔逊相关系数低。
- **真次声 < 16 Hz**：M = (L + R) / 2 过 8 阶 Butterworth 16 Hz 低通后的能量 ÷ M 全频能量（dB），与分析器 subShareDb 同一定义（ADR-012；这里整段计，不设有效音频门；静音段能量可忽略）。只看 M：侧声道里的次声不计入。
- **低切 / 收单 Hz / 收单量 / 加宽**：成品末尾 `getGlazeStatus()` 的 clayLowCutHz / clayMonoHz / clayMonoAmount / clayWidthDb（上一块交给 ClayModule 的实际值）；低切「关」= 0；收单量为 0 时收单 Hz 无意义。
- **保护介入**：第二遍里反相保护 / 宽度保护介入的时长占比（每块读一次状态）。
- **GLAZE 状态**：成品末尾的阶段与「校准有效」；风格为「自动」且 GLAZE > 0 时附此刻偏向的风格。第一遍（聆听）结束时的阶段在 metrics.csv 的 listen_phase 列。
- **成品文件**：`<歌名>__g<GLAZE>_clay-<auto|off|replay-off>_<风格>.wav`。metrics.csv 的 audio_hash 是对齐前成品（原始输入行是立体声化的输入）的 FNV-1a 哈希：同一首歌、同一组设置跨版本哈希相同 = 逐位不变。
- **同决策重放（clay-replay-off，ADR-016）**：每组 GLAZE > 0 的修坯「自动」之后，另起一条 GLAZE 0 的链，逐块照搬「自动」链那一块实际交给模块的全部参数（含自动增量、校准偏差、保护退让），只把修坯换成「关」。两条链的决策一模一样，差别只剩修坯本身——修坯门槛比的是「自动 vs 重放全关」，不再比两条各自跑 GLAZE、方案会分岔的链。阳性对照：修坯用「手动」照填自动链的实际值再重放一遍，应与「自动」逐位相同（metrics.csv 的 replay_check：ok / mismatch / n/a）。重放行的 GLAZE 状态列没有意义（写 replay / 空）。
- **有效音乐**：原曲 K 加权 100 ms 子块在 −70 LUFS 绝对门以上的总时长（与校准器同一门限；歌尾静音不算），metrics.csv 的 music_seconds。门槛只要求有效音乐 ≥ 30 s 的歌在成品末尾「已锁定 + 校准有效」。

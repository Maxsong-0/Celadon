- 频谱仪右上角的响度小窗拿掉了（`LoudnessHud` 整个类删掉，功能搬进右侧板）。

1. **两个选择器挪不挪**：方案（各外移 66 px 当侧板表头，`compare/5-layout-choice.png` 上半）还是备选（一个像素不动、侧板 454 宽，下半）。推荐方案：备选那版旋钮两侧只剩 30 px，粒子基本看不见，表头也被挤到选择器外侧。

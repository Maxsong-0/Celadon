# T-020 · 修坯分频点切换改为分摊预热（+ 低通 O(1) reset）· 2026-09-27 ～ 28

会话「bench 补 Clay」（Opus 5.5，单线、不派代理）。Max 2026-09-27 10:45 在两种摊薄做法里选「分摊预热」。

## 1. 改了什么

- 改前备份：`Celadon-releases/source-baseline-2026-09-27-T-019-before/`（SHA256SUMS 含改前散列）。
- `Source/dsp/ClayModule.{h,cpp}`：
  - 切换开始时新低通只 reset，并记下欠 4(L − 1) 个历史样本；
  - 处理循环里每个实时样本除本样本外再按时间顺序补喂 2 个（`lowpassCatchUpRate`），2(L − 1) 个样本后追上；
  - 追上后的下一个 64 样本网格点才开始 20 ms 淡化；预热或淡化中来的新目标等这次切换走完；
  - 单声道不跑低通，但预热照同样速度记账，切换不会卡住；
  - 删掉不再用的 `sideHistoryIndex`。
- `Source/dsp/LinearPhaseLowpass.{h,cpp}`（2026-09-28 补）：
  - reset 不再清历史环（O(1)）：reset 后头 length 个样本把「length 个样本之前的输入」直接当 0，与清零后读出逐位相同；
  - 重算只加写过的格。
- `tests/ClayTests.cpp`：
  - 切换用例的「稳定」时刻加上追赶时间；
  - 新断言：追上之前输出与旧分频点逐位相同（3 个用例）；
  - 块长无关的扫动用例加块长 1。
- 新低通吃到的输入序列与「一次喂完」完全相同，追上后的输出逐位一样；只是淡化晚开始最多 2(L − 1) + 64 个样本（192 kHz / 40 Hz 约 12 ms）。

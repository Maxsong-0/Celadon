### R8-01 · 预听退出时监听增益单样本阶跃：Listen 关着关预听、预听中切原声 / 宿主旁通 / 试听差值都不交接增益，直接落到 1.0
- 严重度 / 优先级：medium / P1 → 核验 medium / P1；工作量 S；改输出：是；核验判决：confirmed
- 位置：`Source/dsp/CeladonChain.cpp:152`
- 证据：CeladonChain.cpp:147-156：`else if (previewActive && ! nextPreview && releaseAllowed && ! offline && newParams.limit.listen) listenGain.setCurrentAndTargetValue (releaseSafety.getCurrentPreviewGain());` 只在 Listen 开着时交接；紧接着 `if (! releaseAllowed || (previewActive && ! nextPreview)) releaseSafety.reset();`（ReleaseSafety.cpp:24-29 把 previewGain 直接置 1.0）；干路 / 差值路径上 `releaseSafety.process` 不再被调（CeladonChain.cpp:294-296）。107 实测（链接本工作树 Release 目标文件）：稳态预听 −6.00 dB，Listen 关着关预听 / 切原声 / 宿主旁通 / 试听差值四种情形切换样本处增益比跳变均为 0.4990（0.501→1.000，6.00 dB）；Listen 开着的对照组为斜坡（相邻对比样本 ≤ 0.0057）。现有测试 AdvancedMasteringTests.cpp:784-804 只覆盖 Listen 开着的交接。

- 研究修法：CeladonChain::setParams：把交接条件改成「只要 previewActive && !nextPreview && !offline」——先 `listenGain.setCurrentAndTargetValue ((float) releaseSafety.getCurrentPreviewGain())`，再 `releaseSafety.reset()`；随后已有的 updateListenTarget() 让 listenGain 在 20 ms 内平滑到目标（Listen 关或干路 = 1.0，Listen 开 = 等响增益）。applyListenGain 在干路、差值路径上都无条件执行（processListen 每块调用），斜坡能落地。伪码：`const bool leaving = previewActive && ! nextPreview; if (leaving && ! offline) listenGain.setCurrentAndTargetValue ((float) releaseSafety.getCurrentPreviewGain()); if (! releaseAllowed || leaving) releaseSafety.reset();` 保留 offline 分支立即归一。
- 核验理由：CeladonChain.cpp:147-155 退出预听只在 releaseAllowed && !offline && newParams.limit.listen 时把当前增益交给 listenGain，其余情形 :155 releaseSafety.reset()（ReleaseSafety.cpp:24-29 直接置 1.0）；:295 干路 / 差值路径不再调 releaseSafety.process，且 ReleaseSafety.cpp:76-81 关掉后走精确旁通提前返回——前一块乘 0.501、这一块不乘，阶跃落在块边界。applyListenGain（:383-392）在 processListen（:395-479）里对含 hostIsBypassed 的所有路径无条件执行，研究修法的承接前提成立。不是已定取舍：规格高级母带控制 §6（:76-79）写「增益 50 ms 平滑」「与 Listen 交接当前增益」，没写关闭立即归一；代码 :154 注释只为旁通 / 离线辩护；docs/design/0.1.9 与 ADR-020 都没提退出方式；TASKS 待认领写明三种临时监听还没在 DAW 走过。现有测试 AdvancedMasteringTests.cpp:782-804 只覆盖 listen = true。界面路径补充：PluginEditor.cpp:724-731 / 743-750 切原声、差值时先关预听再写 compare / audition 两个原子量，界面上的「预听中切原声」多退化为「Listen 关着关预听」+ 下一块进干路，阶跃照发；宿主旁通不经界面（PluginProcessor.cpp:601-603），研究测的分支真实可达。

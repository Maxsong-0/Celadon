瓷器上釉之前要先修坯。CLAY 在 BALANCE 之后、COLOR 之前：清理赶在所有非线性 / 动态级之前（Glue 检测、Heat、Clip、限幅器都吃到干净的低频），而画像仍只看链入口的原始信号，不随 GLAZE 变。

## 信号处理

M = (L + R) / 2，S = (L − R) / 2；输出 L' = M' + S'，R' = M' − S'。

![三级：低切在 L/R；收单与加宽只在 S；峰值守护只盯低切与收单，加宽的增量在守护之后加回](figure:clay)

| 级 | 作用对象 | 滤波器 | 参数（实际值） |
|---|---|---|---|
| ① 低切 | L、R | 4 阶 Butterworth 高通（两级 RBJ，Q = 0.5412 / 1.3066） | 0 = 关，否则 10 ～ 60 Hz（对数刻度） |
| ② 低频收单 | 只对 S | 线性相位低通取「低频 S」并减去：S' = (1 − a)·S + a·HP(S)，HP 由线性相位低通构成，不转相位 | 分频 40 ～ 300 Hz（对数刻度）；a ∈ [0, 1] |
| ③ 加宽 | 只对 S' | RBJ 高架，f0 = 2 kHz，斜率 1 | −3 ～ +3 dB（自动只给正值且 ≤ +1.5；负值 = 收窄，只能手动） |

- 精度：系数与状态 double；每 64 样本按平滑后的参数重算系数。频率参数在对数域 20 ms 平滑，a、widthDb 线性 20 ms 平滑。
- 影子运行：未旁通时三级一直在跑，输出端按实际值选择 / 交叉淡化（20 ms），任一级从 0 开到非 0 时滤波器状态已就绪，没有低频起跳瞬态。
- 逐位直通：三项实际值都为 0（且不在淡化中）时输出 = 输入。
- 单声道兼容天然成立：② ③ 只动 S，L + R = 2M 完全不变；① 删的是 30 Hz 以下能量。
- 收单用线性相位（延迟 D = 2(L_max − 1)），分频点切换采用分摊预热（尖峰从 +11 降到 +0.125 个百分点）。

## 先试后用

自动态不是「决定了就做」：**先在这首歌上试一遍，会抬峰值就减量或否决**。决策器按画像给出候选值；渲染一段试算峰值代价；代价过高的项按代价减量，减到 0 就跳过；界面第 3 行写「本曲试过：低切会抬高峰值，已自动减量」。

## 峰值守护

**低切与收单从不让峰值变高**。守护只管 ① 低切与 ② 收单：在 8 ms 前瞻里比较「这两级处理后」与「处理前」的相关峰值，会抬峰值的瞬间按需让开（g 路径静止在全 1 时走快路），并把「不经守护时会超出多少 dB」作为压力反馈交给编排器：播放中若一直抬峰值，自动项会逐步减量。守护对手动的低切 / 收单也生效（手动值不被改写，只在峰值处让一点）。

③ 加宽不经守护（0.1.8.6 起）：高架只用来算增量 δ = HS(S') − S'，在守护输出上加回（L + δ、R − δ），加宽按标称值生效——以前守护会把大部分加宽收回去（宽声场粉噪上 +3 dB 只剩约 0.3 dB）。自动加宽仍由先试后用把关（最多 +1.5 dB）；手动大幅加宽时峰值可能略高（宽素材 +3 dB 时实测最多约 +1 dB），由后面的 LIMIT 管住。加宽为 0 时与旧版逐位相同。

按 64 样本段重写后，输出逐位不变，修坯一级快 1.3 ～ 2.0 倍（x86）。

## 自动态的三条规则

| 项 | 自动态做什么 |
|---|---|
| 低切 | 只在这首歌真有听不见的次声（16 Hz 以下）、且试过不会抬高峰值才切 |
| 收单 | **不收单**（2026-09-27 试听后拿掉），只在低频反相时亮琥珀灯提醒——收单只减立体声低音、单声道回放不变，听感不自然 |
| 加宽 | 只在高频偏窄、且试过不会抬高峰值时适度加宽（最多 +1.5 dB），并盯住相关度防止发虚 |

三态语义：自动 = 决策器 + 实时保护，GLAZE 为 0 时不处理；关 = 永远不处理；手动 = 严格按手动值，GLAZE 为 0 也生效、自动与保护都不改它。

## 门槛（怎么证明它没帮倒忙）

22 首真歌的「同决策重放」对照：渲染工具逐块记下「自动」链实际交给模块的参数，另起一条 GLAZE 0 的链照搬这些参数但把修坯关掉——两者只差修坯，比较入口峰值与响度。2026-09-28 全量：0 失败、44 组阳性对照全 ok；其中一首在 GLAZE 70 时，自动链与重放（修坯全关）的入口峰值相差 +0.000 dB。

## 延迟

Clay = D + G：线性相位收单 D = 2(L_max − 1) + 峰值守护前瞻 G = round(0.008 fs) + round(0.003 fs)。48 kHz 为 574 + 528 = 1102；整链 48 / 96 / 192 kHz 为 1384 / 2584 / 4984。

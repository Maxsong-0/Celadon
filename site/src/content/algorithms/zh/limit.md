前瞻真峰值限幅器 + 可选前置 Clip 级：

```text
× Gain → [Clip 软削波，4× 过采样] → 前瞻限幅（8× 插值检测真峰值、1× 域施加增益）→ Ceiling 硬钳位保险 → 输出
```

原写法「全部在 4× 过采样域内进行，最后下采样」在结构上过不了 null 验收：改为**检测在过采样域、增益在 1× 域**。不限幅时增益精确为 1.0，输出 = 延迟后的输入，逐位。

## 处理流程（每块）

![|x| 与真峰值；需求增益 → 前瞻滑动最小 → 双包络 → 两级移动平均](figure:limiter)

1. **Gain**：乘以平滑后的线性增益（1× 域）。
2. **Clip 级**：自带 4× 过采样（等纹波半带 FIR，整数延迟 60），在 4× 域调用 Saturator 的 `SoftClip` 曲线后下采样。削波阈值随 Clip 从「不削」（+12 dBTP）按 dB 线性降到 Ceiling；Clip = 100 时阈值 = Ceiling。Clip = 0 时 20 ms 淡出到等长延迟的干路，淡出走完后跳过过采样，重开时用最近 256 个输入样本预滚，与一直在跑逐位相同。
3. **真峰值检测**：8 相 × 64 抽头插值（延迟 32 样本），左右取最大（立体声联动），得到 `peak[n]`。
4. **需求增益** `r[n] = min(1, ceiling / peak[n])`。在限幅增益需求处再预留 0.35 dB 重建余量（每样本一次乘法）。
5. **前瞻滑动最小值**：对 `r` 取长度 = Lookahead + 63 的滑动最小值（两缓冲 van Herk 算法，O(1) / 样本；0.1.8.6 起替换原来的单调队列，输出逐位不变），得到 `rMin[n]`。多出的 63 是保持段，让峰值附近插值器看到的 64 个样本增益相同。
6. **释放包络**（向下瞬时跟随、向上指数回升）：
   - 手动：单段，时间常数 = Release（10 ～ 1000 ms，对数刻度）。
   - Auto（双段）：**快段** 直接跟 `rMin`，释放 30 ms；**慢段** 跟 `rMin` 经 50 ms 平滑后的版本，释放 100 ～ 800 ms 自适应——最近 500 ms 的平均衰减越深（12 dB 封顶），释放越慢。`env = min(快, 慢)`。
7. **攻击整形**：原来对 `env` 做长度 = Lookahead 的矩形移动平均；0.1.7.2 起换成**两级滑动平均**（三角攻击沿）——攻击仍在前瞻长度内走完，峰值那一刻的增益与原来同时到位，拐角连续，恒定增益仍精确回到 1。
8. **应用**（1× 域）：音频经 `Lookahead + 62` 样本延迟线后乘以增益。释放包络用 double 计算，限过幅之后也能精确回到 1.0。
9. **硬钳位保险**：`clamp(±ceiling)`（与音频对齐后的 Ceiling）；理论上不触发，只为采样点绝不超标。
10. 更新表：本块最小增益的 dB 值（GR）；输出真峰值由输出表用同一个检测器量。

## 短过载不按住慢包络（0.1.7.2）

连续过载短于约 70 ms 时，结束后的半个窗口里慢包络不允许低于快包络，鼓点后面按快释放回来；持续过载仍由慢包络压住。验证：12 ms 过载后 45 ms 的尾部，比 280 ms 持续过载后的尾部高 6.6 dB（−18.3 dB 对 −24.9 dB）。

## 持续低频的周期释放（v0.1.6.2）

新增的检测器只工作在 1× 控制路径，左右分别观察低频（保留纯 Side 低音的证据）。连续的周期一致性与能量稳定条件成立后，快释放从 30 ms 向约四个低频周期调整，上限 140 ms；手动 Release 不受影响。验证：40 / 55 / 80 Hz + 6 kHz 归一化互调改善约 9.17 / 6.93 / 4.01 dB，RMS 差 −0.058 / −0.019 / −0.002 dB；送出完整延迟尾部后新旧均为 −1.3500 dBTP。

## 编码余量（0.1.8.5）

限幅器 Ceiling = clamp(Ceiling − 余量, −4.5, 0) dBTP，余量 0 ～ 1.5 dB。LIMIT 旁通时读数为 0。没有做 AAC / MP3 编码后测峰。

## 延迟与 Lookahead 去抖

`Clip 过采样 60 + Lookahead 样本数 + 62`（48 kHz、2 ms 时 218 样本）。参数停稳 0.3 s 后才把新前瞻交给限幅器并上报延迟；任何时刻上报的延迟都等于实际延迟。换前瞻那一刻限幅器重启：静音一个延迟长度 + 10 ms 淡入。拖一次 Lookahead，宿主重启从 34 ～ 37 次降到 1 次。

## 等响（Listen）

不是「除回 Gain」：用入口和出口已有的 K 加权能量，补偿 Balance、Color、Gain 与限幅的总体响度提升——1 秒连续能量窗口，静音也纳入累计；边缘瞬态占比过高时暂缓更新。只做衰减；输出表和校准器读取衰减前的母带信号。稳态素材最终监听音频与输入的响度差 0.000 ～ 0.002 LU；Color Output 突变 6 dB 后第三秒末 1 秒差 −0.0241 LU。

## 验收

1. 1 kHz 正弦 +12 dB、100 Hz 方波、单位脉冲、20 ms 突发、采样点间峰值序列 → 输出真峰值 ≤ Ceiling + 0.01 dB。
2. Gain 0、Clip 0、输入峰值 < Ceiling → 差值 < −120 dBFS（null）。
3. 脉冲实测延迟 = 上报延迟；任意输入不出 NaN / Inf。
4. 独立 16× 参考（128 抽头 double Kaiser sinc，48 案例）：最坏 Ceiling − 0.0461 dB，通过 Ceiling + 0.01 dB 门槛。
5. 真峰值块式向量化与逐样本参照 0 失配（arm64 -O1 / -O3、x86 -O2 / -O3；x86 FTZ / DAZ 四种组合）。

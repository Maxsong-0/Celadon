## 信号链

![输入 → BALANCE → CLAY → COLOR → LIMIT → 输出；两块表在入口与出口；GLAZE 编排器读入口特征与模块统计，决定各模块的实际参数](figure:chain)

顺序固定、不可换：**先修频谱问题，再加密度与谐波，最后管峰值**。反过来会互相打架——限幅器先压掉的东西，均衡再想抬也抬不回来。

| 模块 | 做什么 | 延迟（样本） |
|---|---|---|
| BALANCE | 27 段动态频谱平衡（含推响不刺、目标频谱） | 0 |
| CLAY | 低切 / 线性相位收单 / 加宽 + 峰值守护 | D + G（48 kHz：574 + 528） |
| COLOR | Tone → 分频 Glue → 残差 Heat → Mix → Output | 64 |
| LIMIT | Gain → Clip（4×）→ 前瞻真峰值限幅（8× 检测 / 1× 施加）→ 硬钳位 | 60 + Lookahead + 62 |

48 kHz、Lookahead 2 ms 总延迟 1384 样本 ≈ 28.8 ms。

## 设计原则

1. **透明**：任一模块参数归零 / 旁通时，输出与输入零差（null，< −120 dBFS）。GLAZE 一直为 0、曲风通用、交付标准时，整链与没有 GLAZE 的参照链逐位相同（交付选流媒体时 LIMIT 上限仍封顶 −2 dBTP，House 类曲风的 Auto 释放仍跟拍收紧，这两处不看 GLAZE）。
2. **延迟补偿式旁通**：旁通时仍保留该模块的延迟量（干信号走等长延迟线），切换不错位、不咔哒（20 ms 淡化）。
3. **限的峰 = 量的峰**：限幅器与两块表用同一个 8× 真峰值检测器。
4. **音频线程 0 分配 0 锁**：所有缓冲在 `prepare` 分好；测试里替换全局 `operator new` 计数。
5. **逐位契约**：SIMD 与标量、任意块长（17 到 2048）、空闲跳过与一直在跑、预热与冷启动——逐位相同。为此编译器不许融合乘加（GCC `-ffp-contract=off`、MSVC `/fp:precise`、不许 `-ffast-math`），源码里有编译期守卫。
6. **参数 ID 一经发布不改**：宿主工程里存的是 ID；加参数只加不删。

## 分析与执行的分工

- **每块（宿主缓冲）**：读参数 → GLAZE 编排器给出实际参数 → 各模块 `setParams` → `process`。参数经 20 ms 平滑，避免拉链噪声。
- **每 hop（≈ 10 ms）**：BALANCE 的 FFT 分析、GLAZE 的特征更新、修坯的保护统计（10 ms 时隙切片，不把整块均值分摊到不同时间段）。
- **每 64 样本**：CLAY 的滤波器系数重算；BALANCE 每 1/8 hop 重算（48 kHz 也是 64 样本）；中间线性插值。

## 真峰值口径

![采样点之间的真实波形会超过任何一个采样值](figure:truepeak)

8 相 × 64 抽头多相插值（延迟 32 样本），块式向量化（NEON / SSE2）与逐样本参照逐位相同；x86 的 FTZ / DAZ 四种组合都测。插件承诺：输出真峰值 ≤ Ceiling + 0.01 dB（按这个表的口径）。16× 参考检测在白噪、突发、热混音这类宽带素材上会高出 0.1 ～ 0.66 dB，所以另在限幅增益需求处预留 0.35 dB 重建余量——独立 16× 复测最坏为 Ceiling − 0.0461 dB。

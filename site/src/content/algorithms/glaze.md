「大旋钮不能是把所有旋钮调大，你需要根据音乐的整体状态全自动通过算法实现效果以及提高音量。」——GLAZE 先听这首歌，按它的响度、动态、频谱、起音决定怎么处理、推多少响度；旋钮只决定朝这首歌的理想母带推多远。

## 五个关键选择

| 问题 | 决定 |
|---|---|
| 怎么随音乐变 | 先听一段得出整首歌的基准（画像 → 方案），之后只在基准附近做有界的保护性调整 |
| 旋钮含义 | 强度：朝「这首歌的理想母带」推多远；0 = 完全不动（等于手动结果） |
| 手动旋钮 | 算法值为底，旋钮是微调：实际值 = clamp(手动值 + 自动增量)；绝不自动抵消你的修改 |
| 基准何时建立 | 自动学习 + 随工程保存 + 「重新聆听」按钮；不自动重学 |
| 风格 | 四选一：自动（默认）/ 温润 / 冲击 / 通透；自动按歌混合三种风格的权重 |

## 七个单元

| 单元 | 职责 |
|---|---|
| **MusicAnalyzer** 分析器 | 入口特征：M / S / I / LRA、PLR / PSR、频谱正负证据（复用 BALANCE 的 27 段帧）、起音活动、置信度 → 画像 |
| **GlazePlanner** 决策器 | 纯函数：画像 + 风格 + GLAZE + 手动值 + 标定快照 → 方案（7 项自动增量、Clay 自动值、目标响度、风格权重） |
| **GlazeConstants** 标定快照 | 带版本号的全部常数与换算表（风格偏好、各模块约束、Heat 换算表） |
| **GlazeCalibrator** 校准器 | 有结束条件：对齐的输入输出响度差、按方向防饱和；不是持续闭环 |
| **GlazeGuard** 保护层 | 约束持续超出时慢速退让，g_保护 ∈ [−3, 0] dB；只收回自动增益 |
| **GlazeProfile** 存档 | 已提交版本（画像 + 方案 + 校准 + 快照）的保存 / 读取 |
| **GlazeController** 编排 | 状态机、候选 / 已提交版本、跳播 / reset / 离线，每块产出实际参数 |

## 时间线

1. **未学习**：播放后自动开始聆听。未学习时先用低置信度的温和方案。
2. **聆听中**：15 ～ 30 s，攒够置信度就结束（`minListenSeconds 15 / maxListenSeconds 30`）。旧方案（或温和方案）照常生效。
3. **方案过渡**：新方案约 3 s 平滑换过去。
4. **校准中**：校准器把实测响度差对到 effectiveTarget；参考条件不变时 1 dB/s 追完。
5. **已锁定**：之后只有两条变化路径——保护层的慢速退让，与段落跟随（自动 Heat / Glue 份额有界收回）。
6. **重新聆听**：建候选版本，完成后交叉到已提交。

## 决策器的目标与约束

- requestedTarget：风格与 GLAZE 想要的响度；effectiveTarget：经各模块约束后当前允许追求的响度，校准只用它。
- **一旋钮底量**（满强度请求，之后按 GLAZE、置信度、风格上限、模块预算缩放）：增响请求下限 3 dB（已达偏好响度的歌也保留）、自动 Recover 8、自动 Tame 24、自动 Heat 12。
- 已够响的素材请求增益为 0；超限时**降低目标而不是硬压**。
- 自动 Tone 可正向提亮也可负向柔化：与画像按同权重比较，0.35 dB/oct 死区、有效带宽、满强度 0.15 dB/s 跟随、±0.75 dB × GLAZE 的风格上限。风格与响度目标不因短期明暗重选。
- 自动风格不再被没攒满的 60 s LRA 置信度整体压向通透；LRA 仍单独约束动态特征。
- 并联 Heat 的削峰份额是可选贡献：它不足时不锁死仍有余量的限幅器。

## 校准的参考条件

任一改变即失效：手动参数、采样率、算法与常数版本、高级设置（推响不刺 / 目标频谱 6 项，「Mast」段）。

**对数刻度参数按容差比，不进精确哈希**：Limit Release、Clay 低切 / 收单在宿主往返里漂几个 ulp（一次保存重开 = 两趟归一化往返，最多 12 ulp；反复往返最多到相对 1.18e-5 后停在不动点），旧的 `llround(x × 1e4)` 取整哈希在边界翻转，重开工程校准就丢。现在离散量精确哈希 + 三个对数刻度值按相对 1e-4 比；旧存档读回后第一块按 ±16 ulp 邻域升格；「条件连续 1 s 不变」的稳定计时对着稳定开始时的条件比（容差比较不可传递）。

参考条件的手动参数部分按输入缓存：命中 6.6 ns，重算约 110 ns；192 kHz / 32 每块省约 0.1 ～ 0.2 个百分点。

## 执行快照与离线导出

在正式画像之外保存独立 `EXECUTION` 快照：当前实际方案、参考条件、正在施加的校准偏差、保护退让、运行中的 Tone / Tame 增量。候选画像不是正式画像，进行中的校准不是有效校准。快照参数、采样率或算法条件不匹配时失效。

实时和离线用相同的样本时间学习、校准和安全反馈；切换离线不停止学习、不撤回正在生效的校准偏差。宿主 reset 用同一入口恢复。保证的范围是**相同快照、相同输入起点、相同处理块时间线**下实时与离线的可复现性：55 秒同源播放中从头离线与实时逐样本相同；三个快照的 64 样本实时 / 1024 样本离线渲染 60 秒，整体响度差 ≤ 0.001181 LU。

## 保护统计的时隙

Guard 用 10 ms 时隙均值的 p95 近似。链按保护层的时隙边界切片，模块统计不跨时隙；宿主整块仍用同一组执行参数，新的控制量在下一宿主块应用。

## 验收总表

1. 从初始化起 GLAZE 一直为 0：整链输出与参照链逐位相同（90 个场景）。
2. 决策器是纯函数：同输入逐位同输出；随 GLAZE 单调；永不超各模块上限；GLAZE 0 时增量全为 0。
3. 已够响的素材请求增益为 0；超限时降低目标。
4. 最终输出真峰值 ≤ Ceiling + 0.01 dB（8× 表口径）。
5. 重开工程：不重学，从同一起点重渲染逐位可复现。
6. 性能：GLAZE 开着时整插件 48k / 512 增加 ≤ 0.15 %，最坏块增加 ≤ 0.5 个百分点；音频线程 0 分配 0 锁。
7. 合成音乐只调 GLAZE = 50：累计响度提升 6.47 LU；GLAZE 0 / 25 / 50 / 75 / 100 → −23.97 / −20.61 / −17.24 / −13.96 / −10.64 LUFS（单一素材，不是任意歌曲的保证）。

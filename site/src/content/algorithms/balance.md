Gullfoss 的核心动作：实时看频谱，把突出的压下去、把被遮住的提起来。判断标准不用听觉遮蔽模型，改用**这首歌自己的平滑轮廓**做参考——保留歌的整体倾斜和风格，只动局部突出与凹陷。零延迟；分析比音频晚 10 ～ 40 ms 是反应滞后，不是上报延迟。

## 分析（每 hop 一次）

1. FFT 2048 点（48 kHz 以下；96 kHz 用 4096，保持约 43 ms 窗）、Hann 窗、hop 512（≈ 10 ms）。左右声道取平均谱：同一组增益给两声道，声像不受影响。
2. 归成 **27 个 1/3 倍频程频段**，中心 40 Hz ～ 16 kHz（40, 50, 63, 80 … 12.5 k, 16 k），每段能量求和转 dB 得 `L[b]`。
3. **快跟踪** `Lfast[b]`：一阶平滑，攻击 / 释放按 Speed——Slow 200 / 800 ms，Mid 80 / 400 ms，Fast 30 / 150 ms。
4. **参考轮廓** `R[b]`：把 `Lfast` 在频率方向抹平（±3 段加权 [1,2,3,4,3,2,1]/16，约 1 个倍频程），再在时间上慢平滑（Slow 4 s / Mid 2 s / Fast 1 s），最后加 Brighten 倾斜线（对数频率线性，100 Hz → 10 kHz 共 ±3 dB）。
5. **偏差** `D[b] = Lfast[b] − R[b]`（dB）。

## 判断（每 hop）

- 死区 ±1 dB：小偏差不动，避免抖动。
- `D > 1`：`G[b] = −min((D − 1) × Tame/100, 6 × Tame/100)`。
- `D < −1`：`G[b] = +min((−D − 1) × Recover/100, 6 × Recover/100)`。
- 静音门：`L[b] < −60 dBFS` 的段 `G[b] → 0`，不把底噪提起来。
- 速率限制：`G[b]` 每 hop 最多变 1 dB，防自激。
- Tame 中高档加力：基础强度 t，额外 t² 只作用于当前局部谱峰，动态压制上限 8t dB；显示范围 ±8 dB。
- Brighten 独立于 Recover / Tame，满档每 decade 3 dB。

## 执行

27 个峰值滤波器（Q ≈ 4.3，1/3 倍频程带宽），增益 `G[b]`，两声道相同；系数每 64 样本重算一次、中间线性插值。CPU：每 512 样本一次 2048 点 FFT + 54 个双二阶。

## 自动份额（GLAZE）与手动份额分开

手动量保持上面的曲线。自动新增部分另有许可：

- **自动 Recover**：只有内部频段、两侧有能量支持的持续缺口可被提升；150 ms 后渐入、500 ms 达到完整许可。端点、单调自然滚降、静音门下不补。
- **自动 Tame**：需要该段持续局部突出的证据；逐段许可 180 ～ 450 ms 渐入；检测到起音后保护 60 ms；自动新增削减每段最多 2.5 dB。
- **谐波支持保护**：利用已有 FFT 识别可靠的 1:2:3 谱线关系（至少一个声道里同时存在完整组），60 ms 进入、300 ms 退出，最多收回 75 % 的自动 Tame 许可。它不识别人声或乐器。
- **一旋钮底量**（满强度请求，再按 GLAZE、置信度、风格上限与模块预算缩放）：自动 Recover 8、自动 Tame 24。

## 上行掩蔽转移（0.1.7.2）

只在 Recover 和 Tame 同时大于 0 时启用。已被 Tame 压下去的主导段，按上行扩展把一部分削减让给**更高、仍有内容、间隙不超过 16 dB** 的邻段。两端和 6.3 kHz 以上不接收这种新的提升；自动 Recover 的许可原样保留——没有缺口证据的自动份额不会凭空抬频段。

提升沿 hop 做约 180 ms 平滑，再用 A 计权把参与频段的净增益拉回 0 附近，幅度封在 ±0.45 dB。谱本身已经平、没有深于 0.8 dB 的削减时，目标与原来逐位相同。

验证：508 Hz 主导音与 640 Hz 邻音同时打开 Recover / Tame 时，邻音比只开 Tame 少被压，并且高于主导音；只开 Tame 不会单独抬它。粉噪收敛、电平阶跃和扫频的原门槛都还在。

## 推响不刺（0.1.9.0，在 BALANCE 内）

- 只看中心 2 ～ 8 kHz 的 7 个活段（窗口 1.9 ～ 8.2 kHz）；频率权重 2 kHz 为 0.5，2.5 ～ 8 kHz 为 1。
- 超出量 = max(0, 本段 Lfast − ½ ×（下方第 3 段 + 上方第 2 段的 60 ms 快电平）− 1.5 dB)。宽带支撑 = 两个邻段门权重取小：孤立纯音、邻段静音时不动。
- 目标削减 = min(3, 0.65 × 超出量) × h × 支撑 × 频率权重 × (1 − 0.6 × 谐波保护) × 起音许可，其中 h = 力度 × GLAZE（自动）或力度（手动）。
- 起音：本帧段功率 > 上一帧 1.7 倍（约 +2.3 dB）就开 55 ms 窗口，窗口里起音许可 = 1 − p（p = 瞬态保护），已施加的削减也立刻乘 1 − p。
- 包络按 hop：攻击 25 ms、释放 200 ms。每段最多额外削 3 dB，与 Tame 叠加后仍受 −8 dB 限。

## 目标频谱（0.1.9.0，在 BALANCE 内）

- 形状：预设 = 斜率 ×（段号 − 14）/ 3 dB，以 1 kHz 为零点；温暖 −1.5、均衡 −0.75、明亮 0 dB / 倍频程。参考 = 学到的 27 段相对功率，≤ −65 dB 的段不参与。
- 只用编号 3 ～ 25（80 Hz ～ 12.5 kHz）的活段；测量用每段的 60 ms 快功率。
- 测量与目标各减去门权重加权平均：只比形状，不复制参考的总响度；参与段的门权重之和 ≥ 6 才动。
- 误差过 1 dB 死区后 × 0.35，每段封顶 ±2.5 dB，再 × t × 门权重；一阶平滑 2 s，t 回 0 后 0.15 s 回零。

参考学习：只读侧链「Reference」；累计 10 s 有效音频；帧 2^k 点（k 从 13 起，2^k ≥ 采样率 / 6，最多 17）；帧的立体声均方低于 −80 dBFS 或频段内几乎没能量就整帧作废；结果 = 各 1/3 倍频程功率 ÷ 立体声总功率取 10 log10。计算分片摊到多个回调（每个输入样本推进 16 个固定大小的工作单元），小块不阻塞，分析尾不加主输出延迟。

## 验收（自动测试）

1. Recover = Tame = 0 → 与旁通 null（< −120 dBFS）。
2. 粉噪开满 Recover / Tame → 所有 |G| < 0.5 dB 收敛。
3. 正弦扫频 → 任一段增益不出现周期性振荡（相邻 hop 符号反复翻转 < 3 次 / 秒）。
4. 1 kHz 正弦 + 粉噪，Tame 100 → 1 kHz 段 ≤ −3 dB，相邻段 |G| < 1 dB。
5. 粉噪背景中的持续 1 kHz 峰降低 2.503 dB，同时出现的 4 kHz 短起音变化 −0.009 dB（起音保护）。
6. Brighten 30 档粉噪实测：100 Hz −1.28 dB、10 kHz +0.94 dB；满档两端相对 7.42 dB。

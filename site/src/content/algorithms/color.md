固定链 + 三个量旋钮：Tone（倾斜 EQ）→ Glue（总线压缩）→ Heat（饱和，8× 过采样）→ Mix（干湿）→ Output。固定延迟 64 样本（Heat 干路延迟）。

## Tone

高搁架 8 kHz 增益 +Tone、低搁架 100 Hz 增益 −Tone，Q 0.707。一个旋钮做跷跷板。

## Glue：低、中、高分开施压

![侧链联动包络驱动三个分频段，各自有攻击与偏移](figure:glue)

- 侧链：输入经 100 Hz 高通（低音不触发泵），左右取峰值最大（联动）。
- 比率 2:1，软拐点 6 dB，攻击 20 ms，释放自动（50 ～ 500 ms，按最近 500 ms 平均衰减自适应）。
- 阈值由 Glue 映射：0 → 0 dBFS（不压），100 → −24 dBFS。自动补偿 `makeup = (0 − 阈值) × (1 − 1/比率) × 0.5`。
- **分频施压（0.1.7.2）**：表和统计仍是原来的联动包络，所以稳态方波的压缩量读数不变。低（约 180 Hz 以下，攻击 36 ms）和高（约 5 kHz 以上，攻击 8 ms）若自己更轻，增益最多比联动增益高 3.2 dB，也可以比联动再深 0.6 dB；中频跟联动攻击。三路差为 0 时退回原来的单增益乘法。检测器直接用侧链那一次 100 Hz 高通，不再滤第二遍。
- Glue 完全关掉时低 / 高分频停走，只留侧链高通；重开时分频状态从 0 起，压缩量包络也从 0 起，由 20 ms 开关淡入。Glue = 0 彻底关闭。

验证：Glue 100 时 90 Hz 变化 +0.66 dB，同时的 2.5 kHz 变化 −2.92 dB；6 kHz 方波的联动压缩量仍落在原来的静态曲线上。

## Heat：保留低频主体的残差染色

![干路完整保留；染色支路 150 Hz 高通 → M/S 电子管 8× → 残差加回](figure:heat)

- 原声经固定 64 样本延迟完整保留。染色支路先做 150 Hz 二阶高通，把过采样非线性产生的**残差**（湿 − 干）加回原声，减轻低音对中高频的互调。
- 8× 半带 FIR 过采样链（自写块式半带，与 Clip 级共用同系数、同延迟），空闲重开时恢复 FIR 历史；Heat 0 保持等延迟直通。
- 驱动 1 → 2、不对称 0 → 0.04、湿路 0 → 25 %（全范围渐进，原来 Heat 10 即全湿、满档驱动 10）。5 Hz 一阶高通阻断直流。
- **声像保护**：染色支路编码为 M/S。M 保留温和的非对称谐波，S 用更轻且严格奇对称的曲线，再解码加回。纯 Side 的 Mid 残留低于 −120 dBFS；左右交换、双单声道与 mono 逐位一致。
- **高频过量收敛**：4 kHz 一阶互补分频分析新增 M/S 残差，以其高频能量相对原声能量的比例限制过量染色——30 ms 能量平滑、15 ms 收敛、250 ms 恢复，残差高频增益最低 0.35。这是染色预算，不是对输出 THD 的承诺。
- 自动响度补偿：`prepare` 时用 −18 dBFS 正弦对每个 Heat 值预算补偿系数查表；转大不会单纯变响。GLAZE 的 Heat 换算表（45 点：5 个入口真峰值电平 × 9 个 Heat 量）按同一 DSP 标定。

Heat 修改前后（48 kHz，1 kHz −0.5 dBFS，THD 第 2 ～ 12 次谐波）：

|---|---|---|---|---|
| 10 | 15.336 % | 0.144 % | −4.276 dB | −0.043 dB |
| 50 | 33.884 % | 1.033 % | −11.380 dB | −0.330 dB |

## Mix 与 Output

干路经等长延迟后 `out = dry × (1 − mix) + wet × mix`；Output ±6 dB。

## 自动份额的段落跟随

自动 Heat / Glue 份额随段落密度缓慢收回（Heat 最多 50 %、Glue 最多 35 %；每秒最多回收 10 %、恢复 4 %，2.5 % 回差），手动部分与长期响度目标不随这条路径重写；证据不足、静音或旁通时冻结。

## 验收

- 1 kHz −6 dBFS、Heat 100：输出真峰值不超输入 + 3 dB；`Tube` 曲线在 8× 域后混叠 < −80 dBFS。
- Glue 0 与 Heat 0 各自的 null；Mix 0 时输出 = 延迟后的输入。
- 40 / 60 / 100 Hz 在 44.1 / 48 / 96 kHz、−12 / −0.5 dBFS、Heat 30 / 100 下低频基波变化在 ±0.25 dB 内，低频失真 < 1 %。
- 333 样本块长、20 ms 淡出、短关后立即重开、长期关闭后重开：与禁用空闲跳过逐位一致。

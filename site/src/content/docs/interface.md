界面是 1200 × 820 的固定画布，按窗口等比缩放（70 % ～ 200 %）。浅色底、单色青；**青色 = 你的设置，紫色 = GLAZE 此刻的自动加量，橙色 = 需要注意**（真峰值超限、方案受限、NaN……同一时刻最多出现在一处）。

## 顶栏

- 左：品牌与「母带处理」。
- 正中：**状态胶囊**，只写最要紧的一件事，优先级「需要注意 > 正在听原声 / 试听差值 > GLAZE 状态行」。例如「B · 正在听原声 · 已等响 4.8 dB」。
- 右：延迟读数 · 中 / EN · 设置 · 帮助 · 高级。

## 表与频谱仪（上半）

- **IN 表 / OUT 表**：8 倍插值测出的真峰值（dBTP），下面的数字是峰值保持，点数字清零。OUT 不应超过 Ceiling；超了会变橙。
- **GR 表**：限幅器此刻压了多少 dB。长时间超过 6 dB 说明 Gain 推太多。
- **频谱仪**：20 Hz ～ 20 kHz 对数横轴、−84 ～ −3 dB。OUT 填充（听原声时就是原声）、白线 = 平均、深青细线 = 峰值保持、虚线 = IN，三者可开关。显示斜率 0 / 3 / 4.5 dB/oct（绕 1 kHz，默认 4.5）。修坯在处理时画出低切与收单频率。悬停读数「dB | Hz | 音名 + 音分」。
- **响度小窗**（右上）：整体响度、短期（S）、真峰值最大值（TP）、峰响比（PLR）、流媒体归一量（对 −14）、目标响度标记。

## 中层

- GLAZE 标题行与阶段标签：已锁定 / 聆听中 / 校准中 / 未学习 / 已暂停 / 受限 / 关。
- 主旋钮：瓷面上的开片随 GLAZE 变多、釉色变深；数值弧越大越深；紫色薄弧是此刻的自动加量。
- 两侧粒子：左边流线汇向旋钮、右边流出（声音从左进 GLAZE、从右出）；「减少动效」时关掉。
- 一排按钮：风格（自动 / 温润 / 冲击 / 通透）· 重新聆听 | A / B · 等响。
- 左下两行说明（悬停或拖动时换成操作提示）；右下颜色图例。
- 临时监听的退出提示：听原声、试听差值、归一化预听三者互斥，开着时这里一直显示可点击退出的提示；关掉窗口全部退出。

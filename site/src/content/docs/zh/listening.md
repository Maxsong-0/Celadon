母带最难的不是处理，是判断。Celadon 把「听清楚差别」当成功能做。三种临时监听（听原声、试听差值、归一化预听）互斥；开着时主窗口一直显示可点击退出的提示；关掉编辑器就全部退出。**离线导出时它们和「等响」一律自动旁通**：不管开着什么监听，导出的成品都是母带本身。

## A / B

中层那一排「处理后 / 原声」。B = 听原声，与宿主旁通同一条干路：延迟补偿、20 ms 交叉淡化、等响测量冻结。默认听 A 时输出与不装这个功能逐位相同。

状态胶囊会写「B · 正在听原声 · 已等响 4.8 dB」或「未等响（响度差 x dB）」。

## 等响

| | |
|---|---|
| 作用 | 测量整条处理链的响度差，把较响的一边衰减到另一边的响度（听处理后时衰减处理结果，听原声时衰减原声），A / B 对比不受音量差影响；输出表显示试听衰减前的母带。 |
| 建议 | 播放数秒后再比较；只衰减不加大音量，自动处理照常进行。离线导出自动旁通；实时导出前请关闭。 |

它是参数 `limit_listen`，会随工程保存。**离线导出时自动旁通**：等响忘了关，导出的成品也不会被衰减；**实时导出**（边播边录）插件分不出来，导出前请手动关掉。用 1 秒连续能量窗口、K 加权测量，边缘瞬态占比过高时暂缓更新；这是缓慢跟随的等响辅助，切换或编曲突变后的短时间内不能保证完全等响。

## 试听差值

LIMIT 卡片头的耳机。送出去的信号换成 LIMIT 削掉的那部分（增益、削波、限幅一起算，按推响前的电平，不会比原声响）；表、响度与 GLAZE 照常按母带算。听原声、旁通 LIMIT 或关掉窗口时自动退出；LIMIT 旁通时不能开；离线导出时不生效。

## 归一化预听

「高级 → 发行安全」。按选定 LUFS（−24 ～ −8，默认 −14）衰减监听：用**预听之前**的 OUT 整体响度算衰减，只衰减、不放大，不改母带表头、处理方案与 GLAZE 目标。

- 离线导出自动关闭；**实时导出前请手动退出**——插件分不出实时导出和正常播放。
- 与等响交接当前增益，不叠加。
- 宿主旁通、听原声、试听差值时也关。

## 导出前清单

1. **实时导出**（边播边录）前关「等响」、退出「归一化预听」「听原声」「试听差值」（主窗口有提示时点它退出）——插件分不出实时导出和正常播放。
2. **离线导出**不用管这四样：它们都会自动旁通，成品永远是母带本身。
3. 看 OUT 真峰值最大值 ≤ Ceiling；需要的话设编码余量。
4. 若自己负责最终位深量化，开抖动；否则保持关。
5. 离线导出前先把主段播一遍：主段还没听够时导出，状态行会写「导出时主段统计还没热，第一个 drop 可能偏轻：先播放一遍再导出」。通用曲风的主段是最响的那些段落，House 类曲风按四拍舞曲认，见[House 类曲风怎么跟](/docs/glaze#house-类曲风怎么跟)。
6. 同一首歌要出流媒体 / 俱乐部两版时，每次切换「交付」后从 drop 开始播到「目标 … LUFS」读数稳定再导出，见[切换，以及导出两版母带](/docs/glaze#切换-以及导出两版母带)。

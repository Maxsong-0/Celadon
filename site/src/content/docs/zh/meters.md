## 竖表

| 读数 | 作用 | 建议 |
|---|---|---|
| **IN / OUT 真峰值** | 8 倍插值测出的真实峰值（dBTP），比采样点峰值更准；下面数字是峰值保持。 | 点数字清零。OUT 不应超过 Ceiling。 |
| **GR · Limit 压缩量** | 限幅器此刻压了多少 dB。 | 长时间超过 6 dB 说明 Gain 推太多了。 |
| **GLUE GR** | Color 的 Glue 此刻压了多少 dB。 | 1 ～ 3 dB 最自然。 |

## 响度小窗

| 读数 | 作用 | 建议 |
|---|---|---|
| **整体响度（LUFS）** | 从复位开始累计的平均响度，流媒体按它做音量归一。 | 流行 −9 ～ −7；想保留动态 −14 ～ −11。 |
| **短期响度 S** | 最近 3 秒的响度，跟着段落变化。 | 副歌和主歌差 2 ～ 4 LU 比较自然。 |
| **真峰值最大值 TP** | 自复位以来的最大真峰值。 | 应低于 Ceiling。 |
| **峰响比 PLR** | 真峰值最大值与整体响度之差，反映还剩多少动态。 | 越小越「满」。 |
| **归一 · 流媒体 −14** | 若平台归一到 −14 LUFS，你的母带会被调多少。 | 数字很负说明推得比平台会放的响很多。 |
| **重新计量** | 清零整体响度和所有峰值保持。 | 换一首歌或从头播放前点一下。 |

表读的是**试听衰减前**的母带：等响与归一化预听不改变表头。

## 频谱仪

- 20 Hz ～ 20 kHz 对数横轴，−84 ～ −3 dB。
- OUT 填充（听原声时就是原声）按响度上色：越响的地方颜色越亮（灰青 → 亮薄荷青）；白线 = 平均；深青细线 = 峰值保持；虚线 = IN；三者可开关。
- 显示斜率 0 / 3 / 4.5 dB/oct，绕 1 kHz，默认 4.5——粉噪在 3 dB/oct 下是平的，多数母带在 4.5 左右看着最舒服。
- 修坯在处理时画出正在生效的低切频率与（手动）收单频率；悬停显示「dB | Hz | 音名 + 音分」。
- 采样口在链的出口。频谱跟着屏幕刷新走（60 Hz 屏每秒 60 帧、120 Hz 屏 120 帧，最多 120 帧）；起音几乎一帧到位、回落约 0.1 秒，窗口 8192 点（低频分辨率不变）。悬停与「最响的峰」读数约 0.27 秒换一次。表与响度读数仍是 30 Hz。

## 修正曲线（BALANCE 卡片）

27 个频段此刻被提起（向上）或压下（向下）了多少 dB，范围 ±8 dB。大部分贴着中线、只在少数频段起伏最自然。紫 = GLAZE 自动份额。

## 当前目标修正（高级 → 目标频谱）

从左到右低到高，向上提升、向下衰减，刻度 ±6 dB；这不是参考曲的原始频谱。没有目标或没有有效输入时曲线是平的。

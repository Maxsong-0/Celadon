BALANCE 是动态频谱平衡：27 个 1/3 倍频程频段实时看频谱，把突出的压下去、把被遮住的提起来。参考不是别人的曲线，是**这首歌自己抹平后的轮廓**——保留歌的整体倾斜和风格，只动局部突出与凹陷。零延迟。

## 控件

| 控件 | 作用 | 建议 |
|---|---|---|
| **回补 Recover** | 把被其他声音遮住的频段提起来，细节和空气感出来。 | 从 20 ～ 40 起；超过 60 可能把底噪也提起来。 |
| **抑制 Tame** | 把突出刺耳或发闷的频段压下去，箱音和刺耳感减少。 | GLAZE 的自动部分保护起音与有明确谐波支持的音色；手动从 30 ～ 50 起。 |
| **提亮 Brighten** | 再加一道倾斜：往右高频提、低频压（偏亮），往左相反。 | 独立生效：整体发闷时往右 20 ～ 40，偏刺耳时往左；不必先打开回补或抑制。 |
| **速度 Speed** | Balance 跟随音乐变化的快慢：Slow 稳、Mid 均衡、Fast 灵敏但可能听出起伏。 | 大多数歌用 Mid；节奏密的电子乐可试 Fast。 |
| **电源键** | 只关掉 Balance；它没有延迟，切换没有咔哒。 | 对比修正前后时用。 |

## 修正曲线

卡片上的 27 根小柱：每个频段此刻被提起（向上）或压下（向下）了多少 dB。大部分贴着中线、只在少数频段起伏最自然。显示范围 ±8 dB。

紫色的部分是 GLAZE 的自动份额：自动 Recover 只在两侧有能量支持的持续缺口上抬，150 ms 后渐入、500 ms 达到完整许可；自动 Tame 需要该段持续局部突出的证据，检测到起音时暂缓 60 ms，每段最多额外 2.5 dB；有可靠 1:2:3 谐波支撑的峰会少压。

## 「高级」里两项也在这里执行

推响不刺（2 ～ 8 kHz 刺耳控制）与目标频谱（温暖 / 均衡 / 明亮 / 参考）复用 BALANCE 的 27 段分析，在同一组滤波器上叠加有界修正，不加延迟。**BALANCE 旁通时它们也不生效。** 见[高级面板](/docs/advanced)。

## 几个数字

- 分析：FFT 2048 点（96 kHz 用 4096）、hop 512（≈ 10 ms）、左右取平均谱，同一组增益给两声道，声像不受影响。
- 死区 ±1 dB；每 hop 最多变 1 dB；静音门 −60 dBFS 以下的段不抬。
- 27 个峰值滤波器 Q ≈ 4.3，系数每 1/8 hop 重算（48 kHz 为 64 样本）、中间插值，无拉链噪声。

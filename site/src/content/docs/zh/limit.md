LIMIT 是透明的前瞻真峰值限幅：8× 插值看见采样点之间的峰，在 1× 域施加增益；不超真峰值、不咔哒、不泵、声像不飘。前面可选一级 Clip 软削波。

## 控件

| 控件 | 作用 | 建议 |
|---|---|---|
| **增益 Gain** 0 ～ +24 dB | 往限幅器里加增益：越大越响，GR 表压得越深。 | 从 0 慢慢加，GR 偶尔跳 2 ～ 3 dB 就够；推到 −8 LUFS 一般要 +6 ～ +10 dB。 |
| **上限 Ceiling** −3 ～ 0 dBTP | 限幅器按真峰值检测控制输出上限（dBTP）；不同测量器会有微小读数差异。 | 上流媒体用 −1.0；想更保险用 −1.5。 |
| **削波 Clip** 0 ～ 100 | 在限幅器前先把尖峰轻轻削圆，同样响度下限幅器压得更少。 | 0 ～ 30 很安全；50 以上听得出颗粒感。 |
| **释放 Release** 10 ～ 1000 ms | 压下去之后多快回来：短更响但易失真，长更平滑但易泵。Auto 打开时不起作用。 | 保持 Auto；手动时从 100 ms 起。 |
| **AUTO 自动释放** | 快慢双段释放，并参考持续低音的周期；兼顾鼓点恢复与低频平滑。曲风选 House 类时，慢段释放还跟着宿主速度收紧（不超过一拍的三分之一），见[曲风与交付](/docs/glaze#曲风与交付)。 | 大多数时候保持打开。 |
| **预读 Lookahead** 1 ～ 10 ms | 提前多久看到峰值：越长越透明，延迟也越大。 | 2 ms；鼓很密的歌可试 3 ～ 5 ms。 |
| **限幅衰减 LIMIT GR** | 限幅器此刻压了多少 dB。方案受限时橙色。 | 长时间超过 6 dB 说明 Gain 推太多了。 |
| **电源键** | 只关掉限幅器；延迟不变，切换没有咔哒。 | 对比限幅前后时用。 |

## 耳机 · 试听差值

卡片头电源键左边的耳机：送出去的信号换成 LIMIT 削掉的那部分（增益、削波、限幅一起算，按推响前的电平，不会比原声响）；表、响度与 GLAZE 照常按母带算。

用来听有没有削到不该削的（鼓点变扁、低音发闷）。听原声、旁通 LIMIT 或关掉窗口时自动退出。LIMIT 旁通时不能开。

## 几个承诺

- 输出真峰值 ≤ Ceiling + 0.01 dB（按插件自己的 8× 真峰值表口径），另在限幅增益需求处预留 0.35 dB 重建余量；16× 参考检测在宽带素材上最坏仍低于 Ceiling。
- 不限幅时增益精确为 1.0；限过幅之后也能精确回到 1.0。
- Gain 0、Clip 0、输入峰值低于 Ceiling → 输出与输入零差。
- 「编码余量」（高级 → 发行安全）会把交给限幅器的 Ceiling 再降 0 ～ 1.5 dB。
- 交付选「流媒体」时，交给限幅器的 Ceiling 还会封顶在 −2 dBTP（你设的 Ceiling 减去编码余量更低就照它），与 GLAZE 旋钮在哪里无关；选了「流媒体」就不用再为此把 Ceiling 往下拉，交付留在「标准」时，才照上表的建议。见[曲风与交付](/docs/glaze#曲风与交付)。

> ⚠ Ceiling 设 0 dBTP 交付时要留余量：不同测量器、重采样、有损编码后的真峰值都可能比这里读到的高一点。

瓷器上釉之前要先「修坯」——把坯体修干净、修匀，釉（GLAZE）才挂得好。CLAY 在 BALANCE 之后、COLOR 之前：切掉听不见的次声与直流，按你的需要把低频收成单声道，窄的歌适度加宽。**低切与收单从不让峰值变高**：会抬峰值的瞬间自动让开；加宽不经峰值守护，自动加宽由先试后用把关，运行中还有宽度保护盯着相关度。

## 三行 · 三态

卡片上三行自上而下：低切、收单、加宽。每行 = 灯 + 名字 + 此刻数值 + 「自动 / 关 / 手动」。

| 三态 | 含义 |
|---|---|
| 自动 | 决策器 + 实时保护：只在这首歌真有问题、且试过不会抬高峰值时才动（收单例外：自动态不收单，只在低频反相时亮琥珀灯提醒）；GLAZE 为 0 时不处理 |
| 关 | 永远不处理 |
| 手动 | 严格按手动值，GLAZE 为 0 也生效；自动与保护都不改写它（峰值守护照常：手动的低切 / 收单在会抬峰值的瞬间会被收回，手动值本身不变；低音宽而不相关、峰值密集的歌上收回的可能不少——收回得明显时低切 / 收单灯会变琥珀、气泡写「实际只剩约 N %」；加宽不经峰值守护）。「手动」时数值可拖 |

灯：亮 = 在处理（紫 = 自动，青 = 手动）；收单灯琥珀 = 低频反相提醒（建议回混音检查）；加宽灯琥珀 = 宽度保护介入；低切 / 收单灯琥珀 = 峰值守护把你设的量明显收回去了（手动、自动都报）。悬停灯的气泡第 2 行是实时值，第 3 行会写「本曲试过：低切会抬高峰值或削弱低音，已自动减量」这类代价说明。

## 控件

| 控件 | 作用 | 建议 |
|---|---|---|
| **低切 · 自动 / 关 / 手动** | 自动：只在这首歌真有听不见的次声（16 Hz 以下）、且试过不会抬高峰值或削弱低音才切，播放中若一直抬峰值或削弱低音会自动减量；关：永远不切；手动：按手动频率切，GLAZE 为 0 也生效。 | 一般保持自动；想留住刻意的超低频效果时选「关」。 |
| **低切频率** 10 ～ 60 Hz | 4 阶高通切掉这个频率以下的次声与直流；「自动」时手动值不生效，这里显示的是此刻的实际值。 | 16 ～ 25 Hz 足够；它会转动低频相位，抬高峰值的瞬间峰值守护会把低切让回去，不让限幅器多压；让得太频繁会削弱低音，所以自动会把频率压低或不切。 |
| **收单 · 自动 / 关 / 手动** | 自动：不收单，只在低频反相（单声道播放会丢低音）时亮琥珀灯提醒；关：不收单、不提醒；手动：手动频率以下全部收单。 | 收单只让立体声的低音更集中，改变不了单声道播放；想要更紧的低音时用手动，从 100 ～ 150 Hz 起。 |
| **收单频率** 40 ～ 300 Hz | 这个频率以下的侧声道收成单声道（线性相位，不转动相位）：低频更紧，单声道回放完全不变；「自动」时手动值不生效（自动不收单，这里不显示收单频率）。 | 80 ～ 150 Hz 常用；超过 200 Hz 会把吉他、键盘的声像一起收窄。 |
| **加宽 · 自动 / 关 / 手动** | 自动：只在高频偏窄、且试过不会抬高峰值时适度加宽（最多 +1.5 dB），并盯住相关度防止发虚；关：不加宽；手动：按手动值，负值收窄。加宽不经峰值守护：设多少就是多少。 | 本来就宽的歌自动不会动；想更宽先试手动 +0.5 ～ +1 dB。 |
| **加宽量** −3 ～ +3 dB | 抬高约 2 kHz 以上的侧声道，声像更开阔，单声道回放不变；负值收窄；「自动」时手动值不生效，这里显示的是此刻的实际值。 | ±1 dB 以内就很明显；超过 +2 dB 容易发虚、相位感变重。 |
| **电源键** | 只关掉修坯（低切、收单、加宽）；延迟不变，切换没有咔哒。 | 对比修坯前后时用。 |

> 自动态**不会**自动收单（2026-09-27 试听后拿掉：收单只减立体声低音、单声道回放不变，听感「不自然」）。反相只做提醒；想收单请切「手动」。

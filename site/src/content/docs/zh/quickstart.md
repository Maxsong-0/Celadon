Celadon 的日常用法只有三步：插到总轨、播放、拧 GLAZE。其余旋钮都是底子，GLAZE 在你的设置上按这首歌叠加自动增量。

## 三步

1. **插到母带轨（总轨）的最后**。如果你还有抖动或响度表插件，放在它们之前。宿主会自动补偿延迟（48 kHz 约 28.8 ms）。
2. **播放这首歌**。新实例默认 GLAZE 35 %、风格「自动」。一开播 GLAZE 就开始跟：顶部状态先写「起步 · 还没听到主段落（偏保守）」，主段听够后变成「跟随 · 自动→… · 目标 … LUFS」，播到较轻的段落时写「保持 · 本段较轻」。它一路量这首歌的响度、动态、频谱与起音，方案随之慢慢调整。
3. **拧 GLAZE**。旋钮决定朝「这首歌的理想母带」推多远：0 = 完全不动（全手动；曲风与交付另有两处不看 GLAZE，见[曲风与交付](/docs/glaze#曲风与交付)），越大越响、修正越多、染色越足；动态保护排在响度前面，推到各模块的预算上限就不再加压，状态行里的「目标 … LUFS」随之降低。

> 不用等它「听完」：从第一拍起就在处理，主段没听够时推得保守，听得越多越放开；频谱平衡本身一直在实时跟随。

## 怎么判断好不好

- **A / B**：中层那一排的「处理后 / 原声」。B 走的是与宿主旁通同一条干路，延迟对齐、20 ms 交叉淡化，切换不咔哒。
- **等响**：打开后两边按实测响度对齐——只把较响的一边衰减到另一边，绝不放大。这样比较的是「音色与动态变好没有」，而不是「响了没有」。
- **试听差值**：LIMIT 卡片上的耳机，只听限幅削掉的那部分。鼓点被削扁、低音发闷，一听就知道。

播放几秒后再比较；等响需要时间测出响度差。

## 常用动作

| 想做 | 操作 |
|---|---|
| 换了一首歌 | 不用点任何按钮：GLAZE 会跟着新歌慢慢调整，旧歌的统计逐渐淡出；点「重新计量」清零整体响度与峰值保持 |
| 给 House 做母带，或同一首歌要出流媒体 / 俱乐部两版 | 选 GLAZE 标题两侧的「曲风」（左）与「交付」（右）；House 类曲风按四拍舞曲认主段，前奏里推得保守、drop 来了才放开。每次切换交付后，先从 drop 开始播到「目标 … LUFS」读数稳定再导出。见[曲风与交付](/docs/glaze#曲风与交付) |
| 只想手动 | GLAZE 拧到 0，曲风与交付放回「通用」「标准」；四张卡片上的旋钮就是全部 |
| 某一段不想自动处理 | 把 CLAY 卡片那一行切到「关」或「手动」；「高级」里的推响不刺 / 目标频谱也各有「关」 |
| 准备导出 | 离线导出时「等响」「归一化预听」「听原声」「试听差值」都会自动旁通；实时导出前要手动关掉它们。见[导出前清单](/docs/listening#导出前清单) |
| 界面太大 / 太小 | 顶栏「设置」里选档位，或拖右下角；70 % ～ 200 %，比例随工程保存 |

## 一些默认值

- GLAZE 35 %，风格自动，曲风通用，交付标准；Ceiling −1.0 dBTP；Lookahead 2 ms；Auto 释放开。
- 「高级」里的推响不刺、目标频谱在新实例默认「自动」（随 GLAZE 联动，GLAZE 0 时为零）；旧工程读入时一律关。旧工程的 GLAZE 聆听结果读入时丢弃，声音仍会变，见[保存与重开](/docs/glaze#保存与重开)。
- CLAY 三项默认「自动」：低切与加宽只在这首歌真需要、且试过不会抬高峰值时才动；收单在自动下从不收，只在低频反相时提醒。

GLAZE 不是把所有旋钮同时调大。它**先听这首歌，按它的响度、动态、频谱、起音决定怎么处理、推多少响度**；旋钮只决定「朝这首歌的理想母带推多远」。

## 旋钮的含义

| 值 | 含义 |
|---|---|
| 0 | 完全不动：四张卡片上的手动值就是全部，输出与「没有 GLAZE」逐位相同（有两处例外，都不看 GLAZE：交付选「流媒体」时，LIMIT 的上限仍封顶在 −2 dBTP；曲风选 House 类（Deep / Tech / Melodic）、Release 是 Auto 时，LIMIT 的慢段释放仍跟着宿主速度收紧。想完全手动，就把曲风与交付也放回「通用」「标准」，见[曲风与交付](#曲风与交付)） |
| 35（默认） | 温和：新实例从这里开始 |
| 越大 | 越响、修正越多、染色越足；每项自动增量随 GLAZE 单调，永不超过各模块上限 |
| 受限 | 已达动态保护上限，继续转大不再变响；想保留更多起伏就调低 |

**实际值 = clamp(手动值 + 自动增量)**。手动旋钮是底，GLAZE 在上面叠加；它绝不自动抵消你的修改。界面上青色是你的值、紫色是自动加量。

GLAZE 联动 7 项：BALANCE 的回补 / 抑制、COLOR 的音调 / 粘合 / 热度、LIMIT 的增益 / 削波。CLAY 的三项（收单在「自动」下从不收，只提醒）与「高级」里的自动项也随它走（见下）。

## 它在听什么

播放后自动开始聆听 15 ～ 30 秒：响度（M / S / I / LRA）、峰响比、频谱正负证据、起音密度……得到**画像**（带置信度，一首歌一份，随工程保存）。画像 + 风格 + 曲风 + 交付 + GLAZE + 手动值 → **方案**；方案先按低置信度温和执行，再由**校准器**对齐输入输出响度差、达到目标后结束；锁定后只在基准附近做有界的保护性调整。选了 House 类曲风（Deep / Tech / Melodic）时，聆听按小节记、要听到主段落（drop 这类满编的段落）才锁定，通常要两分钟上下；锁定之后若再听到明显更响的连续小节，还会更新画像，见[House 类曲风怎么聆听](#house-类曲风怎么聆听)。

状态标签：

| 标签 | 意思 |
|---|---|
| 未学习 | 还没播放；播放后自动开始 |
| 聆听中 | 正在攒证据（角标显示「正在聆听 x / 30 秒」）；旧方案（或温和方案）照常生效 |
| 校准中 | 方案已定，正在把实测响度对到目标 |
| 已锁定 | 完成；之后只做有界保护 |
| 受限 | 约束持续超出，保护层慢速退让（最多 −3 dB）；橙色 |
| 已暂停 | 宿主停止播放 |

> 首次画像取的是这一段的特征。极轻 / 极响的段落仍有校准与保护退让；换成另一首歌，点「重新聆听」更新整首歌的画像。

## 重新聆听

重新听一轮再定方案（通用曲风约 15 ～ 30 秒；House 类曲风见本段末）；听的时候旧方案照常生效，听完约 3 秒平滑换过去。换歌或改了混音后点；聆听中再点一次取消。它不会自动重学——只有你点它才重学。例外只在 House 类曲风下：当前画像不是在 House 类曲风下学的（比如原来一直用通用）时，GLAZE 会自己按 House 的方式再听一轮；锁定之后连续听到明显更响的段落，也会自动并进画像重算。见[曲风与交付](#曲风与交付)。House 类曲风下，重新聆听也按小节听：清空已听的小节、从头再数，要重新凑够 64 小节并听到主段落才换方案（通常两分钟上下），这期间旧方案照常生效。

## 风格

| 风格 | 取向 |
|---|---|
| 自动（默认） | 按歌混合三种风格的权重；顶部状态会写出它此刻偏向哪种 |
| 温润 | 厚、圆、不刺 |
| 冲击 | 鼓点有力、更响 |
| 通透 | 清楚、少压缩、留动态 |

风格还决定「高级」里自动目标频谱的形状：温润 → 温暖，通透 → 明亮，自动 / 冲击 → 均衡。选了 House 类曲风时改按曲风定形状，见下一节。

## 曲风与交付

0.1.8.8 起，GLAZE 标题的两侧各有一个选择：**左边是曲风，右边是交付**。它们和上面的「风格」分工不同，三者可以任意组合：

| 选择 | 回答的问题 | 选项 |
|---|---|---|
| **曲风** | 这是什么音乐？管音色目标，也管 GLAZE 怎么听这首歌 | 通用（默认）/ Deep / Tech / Melodic |
| **交付** | 这一版要放到哪里去？管目标响度与真峰值上限 | 标准（默认）/ 流媒体 / 俱乐部 |
| **风格** | 响度花在哪里？管限幅、粘合、染色各占多少 | 自动（默认）/ 温润 / 冲击 / 通透 |

默认是「通用 + 标准」：开播后聆听 15 ～ 30 秒定方案，音色目标按风格定，响度也按风格定，上限照你设的。旧工程没有这两项设置，打开时按「通用 + 标准」读入，已保存的方案与校准照常生效。曲风与交付随工程保存，但不能在宿主里自动化——它们是「这首歌怎么母带」的决定，不是随时间变化的动作。

### 曲风

| 曲风 | 什么时候选 |
|---|---|
| **通用**（默认） | 不是 House，或拿不准：开播后聆听 15 ～ 30 秒定方案，音色目标按风格定 |
| **Deep** | Deep House |
| **Tech** | Tech House |
| **Melodic** | Melodic-Progressive（Melodic House 和 Progressive House 都选它） |

选择器上只写 Deep / Tech / Melodic，悬停气泡里是全名 Deep House / Tech House / Melodic-Progressive。写的是哪种 House 就选哪种，拿不准选最接近的；不是 House 用「通用」。

选了 Deep / Tech / Melodic（下面统称「House 类曲风」）之后，有六处不同：

- **音色目标**：自动音调（COLOR 的 Tone）按 House 的口径对准，往亮的幅度收得比通用更小。「高级 → 目标频谱」选「自动」时，目标形状改按曲风走，不再跟着「风格」：Deep 偏暖，Tech 均衡，Melodic 介于两者之间。三个子类的其余设定都相同，区别只在这个目标形状上——「目标频谱」关着（旧工程读入时是关）或选了固定形状时，Deep、Tech、Melodic 处理起来完全一样。
- **低切**：CLAY 自动低切的目标频率提到 25 Hz（通用按风格取 16 ～ 20 Hz）。切不切仍由这首歌有没有次声决定，而且要先试：会抬高峰值或削弱低音，就自动减量甚至不切。
- **加宽**：CLAY 自动态不再加宽，母带不再往宽拉；手动加宽照常可用。
- **聆听方式**：按小节听，只用主段落（drop 这类满编的段落）定方案，听到主段落才锁定；细节和状态行的写法见本节最后的[House 类曲风怎么聆听](#house-类曲风怎么聆听)。
- **限幅释放**：LIMIT 的 Auto 释放跟着宿主速度收紧：慢段释放不超过一拍的三分之一（124 BPM 约 160 ms）。只在 Release 是 Auto、宿主正在播放、速度在 100 ～ 140 BPM 之间时生效，与 GLAZE 旋钮在哪里无关（GLAZE 为 0 时也一样）；手动 Release 不受影响。
- **反相提示**：主段落里低频左右相位对不上、单声道回放会丢低频时，比通用更灵敏地提示（单声道约丢 1 dB 起就算，但要在主段落里连续 4 小节才亮；宿主没给拍点时 8 秒）：顶栏状态胶囊里的 GLAZE 状态行整行换成琥珀色的「俱乐部单声道会丢低频（约 x dB），请回混音修」（亮着时它占住状态行；校准走到哪一步看 GLAZE 标题旁的阶段标签（待校准 → 校准中 → 已锁定）），CLAY 卡片小图那一格换成两行字「俱乐部单声道会丢低频（约 x dB）」「请回混音修」。只提示，不处理音频；GLAZE 为 0 时不提示。收单救不回单声道回放，要回混音里把低频收窄或对齐相位。

### 交付

交付定「这一版要多响」和「真峰值留多少余量」：

| 交付 | 目标响度 | 真峰值上限 | 什么时候选 |
|---|---|---|---|
| **标准**（默认） | 按风格定 | 你设的 Ceiling（再减编码余量） | 日常使用，或还没想好交付到哪里 |
| **流媒体** | 约 −10 LUFS | 不高于 −2 dBTP；你设的 Ceiling（再减编码余量）更低就照它 | 要上传到流媒体平台的版本 |
| **俱乐部** | 约 −7 LUFS | 你设的 Ceiling（再减编码余量），不会自动抬高 | 给 DJ 和下载店的版本 |

- **表里的响度大致是 GLAZE 拧满（100）时追求的目标**：GLAZE 照常决定朝它推多远，默认的 35 % 只推一部分；想接近这个响度，就把 GLAZE 往上拧。状态行里「目标 … LUFS」写的是此刻实际在追的那个数。混音本身已经接近或超过表里的响度时，见下面第三条。
- **风格在流媒体 / 俱乐部两档里照样起作用**：目标以该档的响度为中心随风格上下浮动（自动风格按权重混合），三种风格之间的差距与标准档相同。动态很大的歌，目标会再压低一点（与标准档相同）。
- **GLAZE 只往上推，不会把已经够响的混音调轻**：混音本身已经比目标响时，成品不会被拉回目标。三档都留着一份「最少推响量」：混音已经接近或超过表里的响度时，GLAZE 仍会温和地再推一点，所以拧满时「目标」可能比表里的数更响。流媒体 / 俱乐部两档另有硬上限（流媒体约 −8、俱乐部约 −5 LUFS），连这份最少推响量也不会越过它，混音本身已经比上限还响时就不再推；标准档没有这道硬上限。
- **目标是方向，不是保证**：动态保护排在响度前面。推到各模块的预算上限就不再推，目标随之降低，状态行里的「目标」会比没受限时低。
- **流媒体的 −2 dBTP 是交给 LIMIT 的有效上限**，与 GLAZE 旋钮在哪里无关（GLAZE 为 0 时也一样），给有损转码多留一点真峰值余量。选了「流媒体」就不用再为此把 Ceiling 往下拉；其余两档不动上限。
- **House 类曲风下，目标响度指主段落（drop）的响度**，不是整首歌的整体响度——后者会被前奏和 breakdown 拉低，要完整播放一遍后才能在 OUT 的整体响度读数里看到（见[表与频谱仪](/docs/meters)）。通用曲风下仍按开播后聆听到的那一段算。

### 切换，以及导出两版母带

- **切换不用点「重新聆听」**：换交付、换曲风都是在学好的画像上重算方案，约 3 秒平滑换过去，然后重新校准（状态行写「校准中」）。只换交付的两版共用同一份画像，音调、BALANCE 与修坯的决策相同（换曲风则会改音色目标、低切与加宽）；差别在推多少增益、真峰值留多少，粘合、热度、削波的分量也随增益与上限重新分摊。
- **House 类曲风下，校准只在主段落里开轮**（已提交的是在 House 类曲风下门控学出的画像时）：切换后若正播到前奏或 breakdown，约 3 秒过渡之后状态会写「已锁定 · 待校准（条件已变，稳定后自动校准）」，播到 drop 才开始校准；已经在走的一轮在主段落之外只是暂停采集，状态仍写「校准中」；停着时切换，状态先写「校准暂停（未播放）」。
- **从通用切到 House 类曲风时**，方案马上按新曲风重算；如果当前画像不是在 House 类曲风下学的（原来一直用通用，或是旧工程），GLAZE 还会自己按 House 的方式再听一轮：旧画像在新画像就绪前照常使用，小节从这一轮开始时重新数（停着时切换，就从下次开播算）。已经在 House 类曲风下学好的画像会保留，所以 House 的子类之间互换、或 House → 通用 → House，都不会重新聆听。
- **同一首歌出两版母带**：
  1. 选好曲风，把歌完整播放一遍，等状态变成「已锁定」（House 类要听到主段落，进度看状态行，见本节最后的[House 类曲风怎么聆听](#house-类曲风怎么聆听)）；GLAZE 拧到你要的程度。
  2. 交付选「流媒体」，从 drop 开始一直播，播到状态回到「已锁定 · … · 目标 … LUFS」（不是「校准中」「校准暂停」「待校准」），导出这一版。中途写「方案受限」时继续播：GLAZE 会自己把方案降一档，再重新校准。House 类曲风亮着反相提示时，状态行被提示占住，看阶段标签回到「已锁定」。
  3. 交付换成「俱乐部」，同样从 drop 开始播到状态回到「已锁定」，再导出第二版。

切换后马上离线导出的话，导出开头一段可能还没校准完，所以先播到状态回到「已锁定 · … · 目标 … LUFS」再导。House 类曲风下，导出前状态也要已经是「已锁定」，否则成品中途会换方案（状态行会提醒）。导出前照常关掉「等响」与「归一化预听」，见[监听方式](/docs/listening#导出前清单)。

### House 类曲风怎么聆听

通用曲风开播后听 15 ～ 30 秒就定方案。House 的前奏常有 16 ～ 32 小节只有鼓、没有低音和铺底，只听开头会把前奏当成整首歌。所以 House 类曲风下 GLAZE 这样听：

1. **按小节记账**：跟着宿主给的位置与拍号，一小节记一笔；同一小节重放只覆盖、不重复计，所以跳着播放也能慢慢补齐整首。宿主没给拍点时改成每 2 秒一笔。
2. **只用主段落定方案**：同时够响、低频也够满的小节才算主段落（drop 这类满编的段落）。门槛是相对的：drop 来之前，当时最响最满的段落（往往就是前奏）也先算作主段落；drop 一来门槛跟着抬高，大部分前奏和 breakdown 的小节随之不再算主段落（底鼓、低音都齐、只比 drop 轻一点的前奏仍可能留在门内），它们仍算「已听」小节。画像、响度、频谱都只按主段落算。
3. **听够才锁定**：三条都满足才校准、锁定——已听的不重复小节 ≥ 64（124 BPM 约 2 分钟；按秒记时 ≥ 124 秒）、主段落累计 ≥ 8 小节（一个乐句；按秒记时 ≥ 16 秒）、通用曲风那套置信度条件。
4. **首次聆听时，锁定之前是暂定方案**：先按已听到的主段落给一个推得更保守的方案，听得越多越放开，期间不校准。有新的变化就重算：一般约 3 秒平滑换过去；新进来的段落比此前听到的响段高 3 LU 以上、低频也够满时（多半是 drop 进来），约 0.5 秒快速换过去，免得 drop 被前奏的方案压着。重新聆听、或从通用切过来自动开的那一轮里没有暂定方案，旧方案照常生效。
5. **锁定之后仍留意**：后面若出现连续 4 小节比画像响 3 LU 以上、低频占比也不低于画像六成的段落（多半是 drop 来得晚），GLAZE 把它们并进画像，约 0.5 秒换方案并重新校准。每份画像最多这样更新 2 次，只往更响的方向更新。

> 整首不到 64 个不重复小节的素材（短循环、片段），House 类曲风凑不够锁定条件：状态行会一直写进度，首次聆听时方案也一直停在推得保守、不校准的暂定方案上。这类素材请选「通用」。

聆听期间，顶栏状态胶囊里的 GLAZE 状态行写进度（GLAZE 标题与状态胶囊的悬停气泡也换成 House 版的说明）：

| 状态行 | 意思 |
|---|---|
| House · 已听 0 / 64 小节 · 还没听到主段落 | 刚开播，还没有小节被算作主段落 |
| House · 已听 41 / 64 小节 · 主段落已听 8 小节 | 主段落已够一个乐句，但小节数没到 64，所以还没锁定 |
| House · 已听 52 / 124 秒（宿主没给拍点） | 宿主没给拍点，改按秒记：要 124 秒 |

门槛是相对的：开播一两小节后前奏就先算作主段落，「主段落已听 x 小节」随之出现；drop 一来这个数可能先变小再往上涨，所以它不表示 drop 有没有来。

行末可能还有两句提醒：「段落账已满，新段不再计入」（最多记 512 小节，约 16 分钟）；「导出时还没学完，成品中途换过方案：先完整播放一遍再导出」。GLAZE 大于 0 时，左下角第二行同时写着「从 drop 开始播放能学得更快」（GLAZE 为 0 时写「GLAZE 为 0：7 项都用手动值」）。条件满足后先校准（状态行写「校准中」），之后才是「已锁定 · … · 目标 … LUFS」；锁定之后校准轮只在主段落里开：播到前奏或 breakdown 时还没开轮，状态行写「已锁定 · 待校准（条件已变，稳定后自动校准）」，播到 drop 才开始校准。

## 与「高级」和 CLAY 的关系

- 推响不刺、目标频谱在「自动」时：强度 = 你设的力度 × GLAZE / 100。GLAZE 0 时为零。
- CLAY 的低切与加宽在「自动」时由方案决定，GLAZE 0 时不处理；收单在「自动」下从不收，只在低频反相时亮琥珀灯提醒（GLAZE 为 0 时连提醒也不亮）；「手动」时 GLAZE 0 也生效；「关」永远不处理。
- 高级设置一变（或手动参数、采样率、风格、曲风、交付变），校准的参考条件就变了，校准会重新对齐。

## 保存与重开

画像、方案、校准、标定快照与执行快照都随工程保存。重开不重学；从同一起点重渲染逐位可复现。离线导出与实时用同一套样本时间学习、校准，切换离线不会停止学习或撤回校准。曲风与交付也随工程保存；House 类曲风的逐小节记录不随工程保存——重开后锁定的画像照常生效，小节从零重新数（锁定后的「留意」要重新听满 64 小节才起作用）。

GLAZE 不是把所有旋钮同时调大。它**边播边听这首歌，按它的响度、动态、频谱、起音一路决定怎么处理、推多少响度**；旋钮只决定「朝这首歌的理想母带推多远」。

## 旋钮的含义

| 值 | 含义 |
|---|---|
| 0 | 完全不动：四张卡片上的手动值就是全部，输出与「没有 GLAZE」逐位相同（有两处例外，都不看 GLAZE：交付选「流媒体」时，LIMIT 的上限仍封顶在 −2 dBTP；曲风选 House 类（Deep / Tech / Melodic）、Release 是 Auto 时，LIMIT 的慢段释放仍跟着宿主速度收紧。想完全手动，就把曲风与交付也放回「通用」「标准」，见[曲风与交付](#曲风与交付)） |
| 35（默认） | 温和：新实例从这里开始 |
| 越大 | 越响、修正越多、染色越足；每项自动增量随 GLAZE 单调，永不超过各模块上限 |
| 再拧也不变响 | 动态保护排在响度前面：推到各模块的预算上限就不再推，状态行里的「目标 … LUFS」随之降低；想保留更多起伏就调低 |

**实际值 = clamp(手动值 + 自动增量)**。手动旋钮是底，GLAZE 在上面叠加；它绝不自动抵消你的修改。界面上青色是你的值、紫色是自动加量。

GLAZE 联动 7 项：BALANCE 的回补 / 抑制、COLOR 的音调 / 粘合 / 热度、LIMIT 的增益 / 削波。CLAY 的三项（收单在「自动」下从不收，只提醒）与「高级」里的自动项也随它走（见下）。

## 它在听什么

播放时 GLAZE 一直在听：响度（M / S / I / LRA）、峰响比、频谱正负证据、起音密度……按**主段**（最响、最满的段落）加权攒成**画像**（随工程保存）。画像 + 风格 + 曲风 + 交付 + GLAZE + 手动值 → **方案**，每秒按最新的画像重算一次；自动增量慢慢升、较快降，走向新方案，播到前奏、breakdown 这类较轻的段落时增益只降不升。主段听得还不够时方案推得保守，听得越多越放开。出口另有一道很慢的修正，把实测响度对到目标，几道守护在约束超出时把增益退回来。没有聆听期，也不会锁定。选了 House 类曲风（Deep / Tech / Melodic）时，主段按四拍舞曲的方式认，见[House 类曲风怎么跟](#house-类曲风怎么跟)。

状态标签（GLAZE 标题旁）与顶栏状态行一一对应，同一时刻只显示一条，从上往下取第一条成立的：

| 标签 | 意思 |
|---|---|
| 受手动 | 橙色，状态行写「受手动设置限制」：你的手动设置本身已超出某个模块的预算（或 LIMIT 旁通），相应的自动增量撤回。GLAZE 为 0 时不显示 |
| 反相 | 琥珀。状态行写「俱乐部单声道会丢低频（约 x dB），请回混音修」。只在 House 类曲风下，见[曲风](#曲风) |
| 导出 | 琥珀。状态行写「导出时主段统计还没热，第一个 drop 可能偏轻：先播放一遍再导出」。离线导出时主段还没听够 |
| 受限 | 橙色，状态行写「受限 · 原因 · 已退 x dB」：播放中守护正在把 GLAZE 的自动增益往回退，或已退到底（−3 dB）仍超出。原因是四者之一：预算（粘合 / 限幅 / 削波超出风格预算）、交付峰值（限幅压得过深）、保对比（成品的响度起伏比原曲收窄太多）、PSR（峰响比低于该档下限）。条件消失后会慢慢回来，状态回到「跟随」。GLAZE 为 0 时不显示 |
| 起步 | 状态行写「起步 · 还没听到主段落（偏保守）」。主段还没听够（刚开播，或一直在前奏里）：方案推得保守，听得越多越放开 |
| 保持 | 状态行写「保持 · 本段较轻」。正播到较轻的段落：增益只降不升，等主段回来 |
| 跟随 | 状态行写「跟随 · 自动→温润 · 目标 −9.6 LUFS」。常态：跟着攒下的画像走；House 类曲风前面加「House ·」 |
| 全手动 | 状态行写「GLAZE 0 · 只用手动设置」。GLAZE 为 0，上面几条都不显示 |

> 画像跟着整首歌一路攒：前奏里推得保守，主段来了才放开，较轻的段落不会把增益往上拉。换一首歌不用点任何按钮，旧歌的统计会在新歌里逐渐淡出。

## 风格

| 风格 | 取向 |
|---|---|
| 自动（默认） | 按歌混合三种风格的权重；顶部状态会写出它此刻偏向哪种 |
| 温润 | 厚、圆、不刺 |
| 冲击 | 鼓点有力、更响 |
| 通透 | 清楚、少压缩、留动态 |

风格还决定「高级」里自动目标频谱的形状：温润 → 温暖，通透 → 明亮，自动 / 冲击 → 均衡。选了 House 类曲风时改按曲风定形状，见下一节。

## 曲风与交付

0.1.8.8 起，GLAZE 标题的两侧各有一个选择：**左边是曲风，右边是交付**。它们和上面的「风格」分工不同，三者可以任意组合：

| 选择 | 回答的问题 | 选项 |
|---|---|---|
| **曲风** | 这是什么音乐？管音色目标，也管 GLAZE 怎么认主段 | 通用（默认）/ Deep / Tech / Melodic |
| **交付** | 这一版要放到哪里去？管目标响度与真峰值上限 | 标准（默认）/ 流媒体 / 俱乐部 |
| **风格** | 响度花在哪里？管限幅、粘合、染色各占多少 | 自动（默认）/ 温润 / 冲击 / 通透 |

默认是「通用 + 标准」：按响度认主段，音色目标按风格定，响度也按风格定，上限照你设的。旧工程没有这两项设置，打开时按「通用 + 标准」读入；旧工程里存的聆听结果、方案与校准读入时一律丢弃，GLAZE 从头跟起，声音会变。曲风与交付随工程保存，但不能在宿主里自动化——它们是「这首歌怎么母带」的决定，不是随时间变化的动作。

### 曲风

| 曲风 | 什么时候选 |
|---|---|
| **通用**（默认） | 不是 House，或拿不准：按响度认主段，音色目标按风格定 |
| **Deep** | Deep House |
| **Tech** | Tech House |
| **Melodic** | Melodic-Progressive（Melodic House 和 Progressive House 都选它） |

选择器上只写 Deep / Tech / Melodic，悬停气泡里是全名 Deep House / Tech House / Melodic-Progressive。写的是哪种 House 就选哪种，拿不准选最接近的；不是 House 用「通用」。

选了 Deep / Tech / Melodic（下面统称「House 类曲风」）之后，有六处不同：

- **音色目标**：自动音调（COLOR 的 Tone）按 House 的口径对准，往亮的幅度收得比通用更小。「高级 → 目标频谱」选「自动」时，目标形状改按曲风走，不再跟着「风格」：Deep 偏暖，Tech 均衡，Melodic 介于两者之间。三个子类的其余设定都相同，区别只在这个目标形状上——「目标频谱」关着（旧工程读入时是关）或选了固定形状时，Deep、Tech、Melodic 处理起来完全一样。
- **低切**：CLAY 自动低切的目标频率提到 25 Hz（通用按风格取 16 ～ 20 Hz）。切不切仍由这首歌有没有次声决定，而且要先试：会抬高峰值或削弱低音，就自动减量甚至不切。
- **加宽**：CLAY 自动态不再加宽，母带不再往宽拉；手动加宽照常可用。
- **认主段的方式**：按四拍舞曲认主段（底鼓、低音都齐的满编段落，比如 drop），画像与目标响度主要按这些段落算；状态行在「跟随」前面加「House ·」。细节见本节最后的[House 类曲风怎么跟](#house-类曲风怎么跟)。
- **限幅释放**：LIMIT 的 Auto 释放跟着宿主速度收紧：慢段释放不超过一拍的三分之一（124 BPM 约 160 ms）。只在 Release 是 Auto、宿主正在播放、速度在 100 ～ 140 BPM 之间时生效，与 GLAZE 旋钮在哪里无关（GLAZE 为 0 时也一样）；手动 Release 不受影响。
- **反相提示**：主段落里低频左右相位对不上、单声道回放会丢低频时，比通用更灵敏地提示（单声道约丢 1 dB 起就算，但要在主段落里连续 4 小节才亮；宿主没给拍点时 8 秒）：顶栏状态胶囊里的 GLAZE 状态行整行换成琥珀色的「俱乐部单声道会丢低频（约 x dB），请回混音修」（亮着时它占住状态行，GLAZE 标题旁的阶段标签写「反相」；只有「受手动设置限制」排在它前面），CLAY 卡片小图那一格换成两行字「俱乐部单声道会丢低频（约 x dB）」「请回混音修」。只提示，不处理音频；GLAZE 为 0 时不提示。收单救不回单声道回放，要回混音里把低频收窄或对齐相位。

### 交付

交付定「这一版要多响」和「真峰值留多少余量」：

| 交付 | 目标响度 | 真峰值上限 | 什么时候选 |
|---|---|---|---|
| **标准**（默认） | 按风格定 | 你设的 Ceiling（再减编码余量） | 日常使用，或还没想好交付到哪里 |
| **流媒体** | 约 −10 LUFS | 不高于 −2 dBTP；你设的 Ceiling（再减编码余量）更低就照它 | 要上传到流媒体平台的版本 |
| **俱乐部** | 约 −7 LUFS | 你设的 Ceiling（再减编码余量），不会自动抬高 | 给 DJ 和下载店的版本 |

- **表里的响度大致是 GLAZE 拧满（100）时追求的目标**：GLAZE 照常决定朝它推多远，默认的 35 % 只推一部分；想接近这个响度，就把 GLAZE 往上拧。状态行里「目标 … LUFS」写的是此刻实际在追的那个数。混音本身已经接近或超过表里的响度时，见下面第三条。
- **风格在流媒体 / 俱乐部两档里照样起作用**：目标以该档的响度为中心随风格上下浮动（自动风格按权重混合），三种风格之间的差距与标准档相同。动态很大的歌，目标会再压低一点（与标准档相同）。
- **GLAZE 只往上推，不会把已经够响的混音调轻**：混音本身已经比目标响时，成品不会被拉回目标。三档都留着一份「最少推响量」：混音已经接近或超过表里的响度时，GLAZE 仍会温和地再推一点，所以拧满时「目标」可能比表里的数更响。流媒体 / 俱乐部两档另有硬上限（流媒体约 −8、俱乐部约 −5 LUFS），连这份最少推响量也不会越过它，混音本身已经比上限还响时就不再推；标准档没有这道硬上限。
- **目标是方向，不是保证**：动态保护排在响度前面。推到各模块的预算上限就不再推，目标随之降低，状态行里的「目标」会比没有预算约束时低。
- **流媒体的 −2 dBTP 是交给 LIMIT 的有效上限**，与 GLAZE 旋钮在哪里无关（GLAZE 为 0 时也一样），给有损转码多留一点真峰值余量。选了「流媒体」就不用再为此把 Ceiling 往下拉；其余两档不动上限。
- **House 类曲风下，目标响度指主段落（drop）的响度**，不是整首歌的整体响度——后者会被前奏和 breakdown 拉低，要完整播放一遍后才能在 OUT 的整体响度读数里看到（见[表与频谱仪](/docs/meters)）。通用曲风下指按响度认出的主段（最响的那些段落）的响度。

### 切换，以及导出两版母带

- **切换不用任何操作**：换交付、换曲风后，GLAZE 马上在当前画像上重算目标，再慢慢升、较快降地走过去。换曲风后目标按新曲风重算并慢慢跟上。播放中换曲风时，认主段的方式在下一次开播时才换。只换交付的两版共用同一份画像，音调、BALANCE 与修坯的决策相同（换曲风则会改音色目标、低切与加宽）；差别在推多少增益、真峰值留多少，粘合、热度、削波的分量也随增益与上限重新分摊。
- **从通用切到 House 类曲风时**，方案马上按新曲风重算；已攒的统计不清空，也不会另开一轮聆听。播放中换曲风时，认主段的方式在下一次开播时才换。
- **同一首歌出两版母带**：
  1. 选好曲风，把歌完整播放一遍，让状态行走到「跟随 · … · 目标 … LUFS」；GLAZE 拧到你要的程度。
  2. 交付选「流媒体」，从 drop 开始一直播，等「目标 … LUFS」读数稳定、状态行回到「跟随」，导出这一版。中途写「受限」时继续播：守护会自己把自动增益往回退（最多 3 dB），条件消失后再慢慢回来，不用你动手。House 类曲风亮着反相提示时，状态行被提示占住，看阶段标签回到「跟随」。
  3. 交付换成「俱乐部」，同样从 drop 开始播，等「目标 … LUFS」读数稳定、状态行回到「跟随」，再导出第二版。

切换后马上离线导出的话，增益可能还在往新目标上走，所以先播到「目标 … LUFS」读数稳定再导。主段还没听够就离线导出时，状态行会写「导出时主段统计还没热，第一个 drop 可能偏轻：先播放一遍再导出」。每次导出都会接着更新统计，所以同一工程连导两次不保证逐位相同。导出前照常关掉「等响」与「归一化预听」，见[监听方式](/docs/listening#导出前清单)。

### House 类曲风怎么跟

House 的前奏常有 16 ～ 32 小节只有鼓、没有低音和铺底。GLAZE 不先听一段再定方案，而是一直按小节记账，按「主段度」给每一段加权：底鼓、低音都齐的满编段落（drop 这类）权重高，前奏和 breakdown 权重低。所以：

- 刚开播、还在前奏里时，状态行写「起步 · 还没听到主段落（偏保守）」，方案推得保守；drop 来了、主段听够了才放开。
- 播到前奏、breakdown 这类较轻的段落时写「保持 · 本段较轻」：增益只降不升，轻的段落不会被推上去。
- 常态写「House · 跟随 · 自动→温润 · 目标 −9.6 LUFS」。
- 跳着播放也行：同一小节重放只覆盖、不重复计。宿主没给拍点时改按秒记。
- 想让它更快放开，就从 drop 开始播一遍。

## 与「高级」和 CLAY 的关系

- 推响不刺、目标频谱在「自动」时：强度 = 你设的力度 × GLAZE / 100。GLAZE 0 时为零。
- CLAY 的低切与加宽在「自动」时由方案决定，GLAZE 0 时不处理；收单在「自动」下从不收，只在低频反相时亮琥珀灯提醒（GLAZE 为 0 时连提醒也不亮）；「手动」时 GLAZE 0 也生效；「关」永远不处理。
- 高级设置一变（或手动参数、风格、曲风、交付变），GLAZE 马上重算目标，再慢慢升、较快降地走过去。

## 保存与重开

GLAZE 攒下的统计（逐小节的记录、画像、正在施加的自动增量、出口修正、各道守护的退让、修坯的自动值）都随工程保存，重开后从保存时的状态接着跟，不重新起步。离线导出与实时播放走同一条处理路径，导出时统计照常更新，所以同一工程连导两次不保证逐位相同。曲风与交付也随工程保存。本版本之前保存的工程：旧的聆听结果、方案与校准读入时丢弃，GLAZE 从头跟起，声音会变；打开时左下角会提示一次「旧的聆听结果已丢弃，声音会变」。

想看算法细节：[GLAZE · 决策与跟随](/algorithms/glaze)。

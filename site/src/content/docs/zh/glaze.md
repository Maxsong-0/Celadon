GLAZE 不是把所有旋钮同时调大。它**边播边听这首歌，按它的响度、动态、频谱、起音一路决定怎么处理、推多少响度**；旋钮只决定「朝这首歌的理想母带推多远」。

## 旋钮的含义

| 值 | 含义 |
|---|---|
| 0 | 完全不动：四张卡片上的手动值就是全部，输出与「没有 GLAZE」逐位相同 |
| 35（默认） | 温和：新实例从这里开始 |
| 越大 | 越响、修正越多、染色越足；每项自动增量随 GLAZE 单调，永不超过各模块上限 |
| 再拧也不变响 | 动态保护排在响度前面：推到各模块的预算上限就不再推，状态行里的「目标 … LUFS」随之降低；想保留更多起伏就调低 |

**实际值 = clamp(手动值 + 自动增量)**。手动旋钮是底，GLAZE 在上面叠加；它绝不自动抵消你的修改。界面上青色是你的值、紫色是自动加量。

GLAZE 联动 7 项：BALANCE 的回补 / 抑制、COLOR 的音调 / 粘合 / 热度、LIMIT 的增益 / 削波。CLAY 的三项（收单在「自动」下从不收，只提醒）与「高级」里的自动项也随它走（见下）。

## 它在听什么

播放时 GLAZE 一直在听：响度（M / S / I / LRA）、峰响比、频谱正负证据、起音密度……按**主段**（最响、最满的段落）加权攒成**画像**（随工程保存）。画像 + 风格 + GLAZE + 手动值 → **方案**，每秒按最新的画像重算一次；自动增量慢慢升、较快降，走向新方案，播到前奏、breakdown 这类较轻的段落时增益只降不升。主段听得还不够时方案推得保守，听得越多越放开。出口另有一道很慢的修正，把实测响度对到目标，几道守护在约束超出时把增益退回来。不用先听完一段再定方案，也不会锁定。怎么认主段、前奏和 breakdown 里怎么办，见[主段怎么跟](#主段怎么跟)。

状态标签（GLAZE 标题旁）与顶栏状态行一一对应，同一时刻只显示一条，从上往下取第一条成立的：

| 标签 | 意思 |
|---|---|
| 受手动 | 橙色，状态行写「受手动设置限制」：你的手动设置本身已超出某个模块的预算（或 LIMIT 旁通），相应的自动增量撤回。GLAZE 为 0 时不显示 |
| 导出 | 橙色，状态行写「导出时主段统计还没热，第一个 drop 可能偏轻：先播放一遍再导出」。离线导出时主段还没听够 |
| 受限 | 橙色，状态行写「受限 · 原因 · 已退 x dB」：播放中守护正在把 GLAZE 的自动增益往回退，或已退到底仍超出（最多退 3 dB）。原因是两者之一：预算（粘合 / 限幅 / 削波超出风格预算）、限幅（限幅压得过深）。条件消失后会慢慢回来，状态回到「跟随」。GLAZE 为 0 时不显示 |
| 预热 | 状态行写「预热 · 还没听到主段落（偏保守）」。主段还没听够（刚开播，或一直在前奏里）：方案推得保守，听得越多越放开 |
| 保持 | 状态行写「保持 · 本段较轻」。正播到较轻的段落：增益只降不升，等主段回来 |
| 跟随 | 状态行写「跟随 · 自动→温润 · 目标 −9.6 LUFS」。常态：跟着攒下的画像走 |
| 全手动 | 状态行写「GLAZE 0 · 只用手动设置」。GLAZE 为 0，上面几条都不显示 |

> 画像跟着整首歌一路攒：前奏里推得保守，主段来了才放开，较轻的段落不会把增益往上拉。换一首歌不用点任何按钮，旧歌的统计会在新歌里逐渐淡出。

## 风格

| 风格 | 取向 |
|---|---|
| 自动（默认） | 按歌混合三种风格的权重；顶部状态会写出它此刻偏向哪种 |
| 温润 | 厚、圆、不刺 |
| 冲击 | 鼓点有力、更响 |
| 通透 | 清楚、少压缩、留动态 |

风格还决定「高级」里自动目标频谱的形状：温润 → 温暖，通透 → 明亮，自动 / 冲击 → 均衡。

## 主段怎么跟

GLAZE 不先听一段再定方案，而是一直分段记账，按「主段度」给每一段加权：最响的那些段落权重高，前奏和 breakdown 这类较轻的段落权重低。所以：

- 刚开播、还在前奏里时，状态行写「预热 · 还没听到主段落（偏保守）」，方案推得保守；主段来了、听够了才放开。
- 播到前奏、breakdown 这类较轻的段落时写「保持 · 本段较轻」：增益只降不升，轻的段落不会被推上去。
- 目标响度（状态行里的「目标 … LUFS」）指主段的响度，不是整首歌的整体响度——后者会被前奏和 breakdown 拉低，要完整播放一遍后才能在整体响度读数里看到（见[表与频谱仪](/docs/meters)）。
- 跳着播放也行：宿主给了拍点时按小节记，同一小节重放只覆盖、不重复计；没给拍点时改按秒记。
- 想让它更快放开，就从 drop（或副歌）开始播一遍。

## 曲风与交付（已取消）

0.1.8.8 ～ 0.1.8.10 的 GLAZE 标题两侧有「曲风」（通用 / Deep / Tech / Melodic）和「交付」（标准 / 流媒体 / 俱乐部）两个选择。0.1.8.11 起两项都取消了，所有歌都按原来「通用 + 标准」的方式处理：按响度认主段，音色目标和目标响度按风格定，真峰值上限就是你设的 Ceiling（再减编码余量）。

- **打开存着 House 类曲风、流媒体或俱乐部的旧工程**：按「通用 + 标准」读入，声音会变，左下角提示一次「曲风与交付已取消，已改回通用 + 标准，声音会变」。存着「通用 + 标准」的旧工程不提示这一条。
- **要上流媒体平台的版本**：原来「流媒体」把上限封顶在 −2 dBTP，现在自己把 Ceiling 往下拉（例如 −2 dBTP），或在「高级」里加编码余量；编码后用独立工具复测真峰值。
- **想要更响的版本**（原来「俱乐部」那一档）：把 GLAZE 往上拧，或把风格换成「冲击」。

## 与「高级」和 CLAY 的关系

- 推响不刺、目标频谱在「自动」时：强度 = 你设的力度 × GLAZE / 100。GLAZE 0 时为零。
- CLAY 的低切与加宽在「自动」时由方案决定，GLAZE 0 时不处理；收单在「自动」下从不收，只在低频反相时亮橙灯提醒（GLAZE 为 0 时连提醒也不亮）；「手动」时 GLAZE 0 也生效；「关」永远不处理。
- 高级设置一变（或手动参数、风格变），GLAZE 马上重算目标，再慢慢升、较快降地走过去。

## 保存与重开

GLAZE 攒下的统计（逐小节的记录、画像、正在施加的自动增量、出口修正、各道守护的退让、修坯的自动值）都随工程保存，重开后从保存时的状态接着跟，不重新预热。离线导出与实时播放走同一条处理路径，导出时统计照常更新，所以同一工程连导两次不保证逐位相同。0.1.8.9（边放边跟）之前保存的工程：旧的预热结果、方案与校准读入时丢弃，GLAZE 从头跟起，声音会变；打开时左下角会提示一次「旧的预热结果已丢弃，声音会变」。

GLAZE 不是把所有旋钮同时调大。它**先听这首歌，按它的响度、动态、频谱、起音决定怎么处理、推多少响度**；旋钮只决定「朝这首歌的理想母带推多远」。

## 旋钮的含义

| 值 | 含义 |
|---|---|
| 0 | 完全不动：四张卡片上的手动值就是全部，输出与「没有 GLAZE」逐位相同 |
| 35（默认） | 温和：新实例从这里开始 |
| 越大 | 越响、修正越多、染色越足；每项自动增量随 GLAZE 单调，永不超过各模块上限 |
| 受限 | 已达动态保护上限，继续转大不再变响；想保留更多起伏就调低 |

**实际值 = clamp(手动值 + 自动增量)**。手动旋钮是底，GLAZE 在上面叠加；它绝不自动抵消你的修改。界面上青色是你的值、紫色是自动加量。

GLAZE 联动 7 项：BALANCE 的回补 / 抑制、COLOR 的音调 / 粘合 / 热度、LIMIT 的增益 / 削波。CLAY 的三项（收单在「自动」下从不收，只提醒）与「高级」里的自动项也随它走（见下）。

## 它在听什么

播放后自动开始聆听 15 ～ 30 秒：响度（M / S / I / LRA）、峰响比、频谱正负证据、起音密度……得到**画像**（带置信度，一首歌一份，随工程保存）。画像 + 风格 + GLAZE + 手动值 → **方案**；方案先按低置信度温和执行，再由**校准器**对齐输入输出响度差、达到目标后结束；锁定后只在基准附近做有界的保护性调整。

状态标签：

| 标签 | 意思 |
|---|---|
| 未学习 | 还没播放；播放后自动开始 |
| 聆听中 | 正在攒证据（角标显示「正在聆听 x / 30 秒」）；旧方案（或温和方案）照常生效 |
| 校准中 | 方案已定，正在把实测响度对到目标 |
| 已锁定 | 完成；之后只做有界保护 |
| 受限 | 约束持续超出，保护层慢速退让（最多 −3 dB）；橙色 |
| 已暂停 | 宿主停止播放 |

> 首次画像取的是这一段的特征。极轻 / 极响的段落仍有校准与保护退让；换成另一首歌，点「重新聆听」更新整首歌的画像。

## 重新聆听

再听 15 ～ 30 秒重新定方案；听的时候旧方案照常生效，听完约 3 秒平滑换过去。换歌或改了混音后点；聆听中再点一次取消。它不会自动重学——只有你点它才重学。

## 风格

| 风格 | 取向 |
|---|---|
| 自动（默认） | 按歌混合三种风格的权重；顶部状态会写出它此刻偏向哪种 |
| 温润 | 厚、圆、不刺 |
| 冲击 | 鼓点有力、更响 |
| 通透 | 清楚、少压缩、留动态 |

风格还决定「高级」里自动目标频谱的形状：温润 → 温暖，通透 → 明亮，自动 / 冲击 → 均衡。

## 与「高级」和 CLAY 的关系

- 推响不刺、目标频谱在「自动」时：强度 = 你设的力度 × GLAZE / 100。GLAZE 0 时为零。
- CLAY 的低切与加宽在「自动」时由方案决定，GLAZE 0 时不处理；收单在「自动」下从不收，只在低频反相时亮琥珀灯提醒（GLAZE 为 0 时连提醒也不亮）；「手动」时 GLAZE 0 也生效；「关」永远不处理。
- 高级设置一变（或手动参数、采样率变），校准的参考条件就变了，校准会重新对齐。

## 保存与重开

画像、方案、校准、标定快照与执行快照都随工程保存。重开不重学；从同一起点重渲染逐位可复现。离线导出与实时用同一套样本时间学习、校准，切换离线不会停止学习或撤回校准。

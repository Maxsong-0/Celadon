所有旋钮手感一致，所有滑条也一致；文案与插件「帮助」面板同源。旋钮分两块：外圈转、点、甩，中间上下拖。

## 调节

| 动作 | macOS | Windows |
|---|---|---|
| 转外圈 | 沿旋钮外圈转动，值跟着角度走；拖进底部缺口会停在来的那一端，不会从最大绕回 0 | 同 |
| 点外圈 | 直接跳到所点的位置 | 同 |
| 快甩 | 在外圈甩一下就松手，还会多滑一段再停稳；停一下再松手就不滑 | 同 |
| 中间上下拖 | 按住旋钮中间上下拖（左右拖也算）；滑条左右拖 | 同 |
| 精调（慢 8 倍） | 按住 ⌘ 拖动或滚动；在外圈按住 ⌘ 改成相对转动：按下不跳，从当前值慢慢挪，拖到一半再按也不跳 | 按住 Ctrl 拖动或滚动；在外圈按住 Ctrl 同样改成相对转动 |
| 回到默认值 | 双击 | 双击 |
| 直接输入数值 | 按住 Option 单击：回车确认、Esc 取消、点别处也算确认；接受中文输入法的全角数字 | 按住 Alt 单击（松开 Alt 不会激活宿主菜单栏） |
| 微调 | 滚轮 | 滚轮 |

转动旋钮时，指示点身后拖一条青色彗尾，转得越快越长越粗。点外圈、双击回默认，或宿主自动化、切预设、撤销改了值时，指针用弹簧走过去，停稳时与参数值完全一致。拖动时控件上方出深色数值气泡（精调时带「精调」小标签）。参数一律经宿主的参数附着：拖一次 = 一个手势（快甩多滑的那一段也在这个手势里），自动化与撤销按手势记。

## 颜色

青色 = 你的设置；紫色 = GLAZE 此刻的自动加量；橙色 = 需要注意（真峰值超限、守护退让「受限 · …」、屏蔽了异常音频块……）。

## 窗口

- 固定 1200 × 820 画布，70 % ～ 200 % 等比缩放。「设置」里五个常用档位 + 滑条 + 按屏幕比例的预览（超出屏幕时提醒）；也可拖右下角，宽高比不变。
- 比例随工程保存；新窗口的默认大小在「设置」里定，跟人走。

## 设置与帮助

- **语言**：中 / EN 一键切换，所有实例同时换。
- **减少动效**：关掉粒子、波纹与裂纹淡入；旋钮不拖彗尾、不回弹，快甩也不多滑；顶栏状态胶囊的圆点也不呼吸。
- **帮助**：上面这些操作提示的原文。

## 悬停气泡

悬停 600 ms 出现，三行：名字 · 作用 / 效果 · 建议。CLAY 三盏灯的气泡第 2 行是实时值（「低切 22 Hz · 未收单 · 高频加宽 +0.8 dB」），第 3 行是本曲的代价说明或旧工程提示；House 类曲风亮着反相提示时，第 3 行改说回混音把低频收窄或对齐相位。

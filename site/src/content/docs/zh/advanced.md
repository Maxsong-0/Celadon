顶栏「高级」打开一块 680 × 440 的面板，三个页签：推响不刺 / 目标频谱 / 发行安全。它们都是宿主参数，能自动化、撤销、随工程保存；切页签不改参数。**日常仍由 GLAZE 一键完成，按需要再展开。**

修坯的低切、收单、加宽不在这里，在主界面的 CLAY 卡片上。

## 推响不刺

减轻 2 ～ 8 kHz 的刺耳频段，同时保留鼓点与瞬态。在 BALANCE 里执行，BALANCE 旁通时无效，不加延迟。

| 控件 | 作用 | 建议 |
|---|---|---|
| **处理方式** 自动 / 关 / 手动 | 通过 BALANCE 抑制刺耳；自动随 GLAZE 缩放，手动用固定力度，关或旁通 BALANCE 时无效。 | 先用自动；只想比较这项的影响时切到关。 |
| **抑制力度** 0 ～ 100 % | 决定高频刺耳抑制的程度；自动模式还会乘以 GLAZE 的力度，关时无效。 | 从 50 % 起；过量会损失空气感，用等响对比判断。 |
| **瞬态保护** 0 ～ 100 % | 在检测到起音时减轻刺耳抑制，保留鼓点与拨弦；自动和手动模式都有效。 | 鼓点发软时提高；高频起音本身刺耳时适当降低。 |

面板里显示「当前抑制 x dB」。每段最多额外削 3 dB（满力度时），与 Tame 叠加后仍受 −8 dB 限。它不是去齿音器，不识别人声或乐器。

## 目标频谱

温和地把 27 段的**形状**往一个目标靠：不复制参考曲的总响度，也不追求逐频点一致。在 BALANCE 里执行，BALANCE 旁通时无效。

| 控件 | 作用 | 建议 |
|---|---|---|
| **模式** 关 / 自动 / 温暖 / 均衡 / 明亮 / 参考 | 自动随 GLAZE 工作；温暖、均衡、明亮与参考是独立手动目标。 | 没有参考时先用预设；参考目标需先从 DAW 外部侧链学习。 |
| **匹配力度** 0 ～ 100 % | 控制 27 个频带向目标靠近的幅度；图中显示实际目标修正，关闭目标时无效。 | 从较小力度起，保留原曲的配器与音色差异，不必让每个频带完全一致。 |
| **当前目标修正 · 27 频带** | 从左到右为低频到高频；向上提升、向下衰减，刻度 ±6 dB；这不是参考曲的原始频谱。 | 先听整体音色，再看曲线；没有目标或没有有效输入时曲线可以是平的。 |

预设形状：温暖 −1.5、均衡 −0.75、明亮 0 dB / 倍频程（以 1 kHz 为零点）。自动模式按 GLAZE 风格参数选形状：温润 → 温暖，通透 → 明亮，自动 / 冲击 → 均衡。曲风选 House 类时改按曲风：Deep −1.5（同温暖）、Tech −0.75（同均衡）、Melodic −1.25（介于两者之间），见[曲风与交付](/docs/glaze#曲风与交付)。

### 学习参考

1. 把参考曲单独接到 Celadon 的外部侧链输入「Reference」（各宿主的侧链路由不同）。
2. 播放参考曲，点**学习参考**。它只读侧链，没有声音会一直等，不拿主输入冒充；参考曲不会混入母带输出。
3. 累计 **10 秒有效非静音**声音后完成（最后一帧有短暂分析尾）。面板显示「正在学习参考 · 已收集 x 秒有效声音」→「参考已就绪 · 选择「参考」应用频谱目标」。
4. 模式切到「参考」，调匹配力度。

**取消学习**：停止本次、保留之前已完成的参考。**清除参考**：移除已学目标；参考模式在没有参考时不施加修正，预设目标不受影响。学到的 27 段随工程保存。

## 发行安全

| 控件 | 作用 | 建议 |
|---|---|---|
| **预听响度** −24 ～ −8 LUFS | 选择监听目标；按预听前的 OUT 整体响度只作衰减，不把小音量母带放大。 | 默认 −14 LUFS；这是通用监听对比，不代表某个平台的精确播放规则。 |
| **开启 / 退出归一化预听** | 按选定 LUFS 衰减监听，不改变母带表头与处理方案；关闭插件窗口时自动退出。 | 与原声或差值试听互斥；离线导出自动关闭，实时导出前请退出预听。 |
| **编码余量** 0 ～ 1.5 dB | 启用 LIMIT 时把输出上限再降低 0 ～ 1.5 dB；旁通 LIMIT 时无效，不模拟编码器或检测编码后峰值。 | 按交付要求预留余量，并在实际编码后用独立工具复测真峰值。 |
| **最终位深抖动** 关 / 16 bit / 24 bit | 为最终 16 或 24 位整数导出加入 TPDF 抖动；默认关闭，浮点中间文件不需要。 | 只在处理链末级开启一次；若 DAW 或后续工具负责抖动，这里保持关闭。 |

> ⚠ 编码余量**没有**做 AAC / MP3 编解码或编码后真峰值检测，不能保证任意编码器不超峰。实时录制或实时导出与正常播放分不出来，开始前必须退出预听。

## 旧工程与默认

加载不含这些参数的旧工程时，推响不刺、目标频谱、编码余量、抖动一律关。新实例默认推响不刺「自动」（力度 50、瞬态 50）、目标频谱「自动」（力度 35）：GLAZE 35 % 时每段最多约 0.53 dB 的刺耳抑制、约 ±0.31 dB 的目标修正；GLAZE 0 时为零。旧工程的 GLAZE 声音为什么会变，见[打开旧工程后声音变了？](/docs/faq#打开旧工程后声音变了)。

COLOR 负责「一挂就更密更响」：Tone 跷跷板、Glue 总线压缩、Heat 电子管染色。饱和把尖峰削圆、压缩把动态收紧，后面的 LIMIT 就能推得更响而不破。固定延迟 64 样本。

## 控件

| 控件 | 作用 | 建议 |
|---|---|---|
| **音调 Tone** −3 ～ +3 dB | 跷跷板式均衡：往右高频提、低频减（更亮），往左相反（更暖）。 | ±1 dB 以内就很明显。 |
| **粘合 Glue** 0 ～ 100 | 总线压缩：把各轨捏在一起、动态更紧；侧链低切减少低频触发的抽吸。 | 20 ～ 40；GR 小表跳 1 ～ 3 dB 最自然。 |
| **热度 Heat** 0 ～ 100 | 保留低频主体的并联电子管染色；两侧采用更轻染色，新增高频谐波过量时自动收敛。 | 20 ～ 50；超过 70 染色明显，可用「等响」对比。 |
| **干湿 Mix** 0 ～ 100 % | 处理后与原声混合；低于 100 % 就是并行处理，保留原来的冲击力。 | 50 ～ 80 % 有「厚而不闷」的效果。 |
| **输出 Output** −6 ～ +6 dB | 调整 Color 送进 Limit 的音量。 | 让 Color 开关前后音量一致，再判断好坏。 |
| **粘合衰减 GLUE GR** | Color 的 Glue 此刻压了多少 dB。 | 1 ～ 3 dB 最自然。 |
| **电源键** | 只关掉 Color；延迟不变，切换没有咔哒。 | 对比染色前后时用。 |

## 三级各是什么

- **Tone**：高搁架 8 kHz +Tone、低搁架 100 Hz −Tone，一个旋钮做跷跷板。
- **Glue**：前馈总线压缩，侧链 100 Hz 高通、左右取大联动、2:1、软拐点 6 dB、攻击 20 ms、自动释放（50 ～ 500 ms）。低（≈ 180 Hz 以下）、高（≈ 5 kHz 以上）两段分开施压，中频直接用联动增益——低、高若自己更轻，增益最多比联动高 3.2 dB，人声一响低音不再跟着躲。表读的仍是联动包络。Glue 为 0 时彻底关闭。
- **Heat**：原声经 64 样本延迟完整保留；染色支路先 150 Hz 高通，只把 8× 过采样电子管非线性产生的**残差**加回原声，低音不驱动中高频的互调。编码为 M/S：M 温和非对称、S 更轻且奇对称，声像不飘。自动响度补偿，转大不会单纯变响。Heat 为 0 是等延迟直通。

## 与 GLAZE

GLAZE 联动音调、粘合、热度三项（紫色）。自动 Heat / Glue 份额会随段落密度缓慢收回（Heat 最多 50 %、Glue 最多 35 %）再恢复，手动部分不受影响。
